立意定好了，接下来是把文章“搭起来”。申论大作文不追求文学性，追求的是**结构清楚、论证扎实**。掌握一个稳定的结构模板，考场上就不会慌。

## 一、“五段式”结构

| 部分 | 字数（1000—1200 字） | 内容 |
|---|---|---|
| 标题 | — | 点明观点，可用主副标题 |
| 开头 | 150 字左右 | 引出话题，提出总论点 |
| 分论点一 | 250—300 字 | 分论点句 + 分析 + 论据 + 小结 |
| 分论点二 | 250—300 字 | 同上 |
| 分论点三 | 250—300 字 | 同上 |
| 结尾 | 100—150 字 | 总结全文，升华号召 |

四川大作文 800—1000 字，各部分按比例压缩，每个分论点段 200 字左右。

## 二、分论点段怎么写

:::key 一段话的四个层次
1. **分论点句**：段落开头一句话亮出观点（“办好身边小事，才能解决群众的‘大难’。”）；
2. **阐释分析**：解释为什么，讲道理（2—3 句）；
3. **论据**：举例子（资料中的事例、现实中的事例）、引名言、用数据；
4. **小结回扣**：一句话收束，回到分论点或总论点。
:::

:::order 把这段话的句子排成正确顺序
- 办好身边小事，才能解决群众的“大难”。
- 群众的“小事”往往关乎衣食住行，看似琐碎，却直接影响着生活质量和幸福感。
- 某市推行“接诉即办”，对群众反映的路灯不亮、垃圾清运不及时等问题限时解决，一年办结诉求上百万件。
- 正是这一件件小事，让群众真切感受到了政府的温度。
- 因此，只有俯下身子办好小事，才能积小胜为大胜，赢得群众的信任。
解析：分论点句 → 阐释（为什么小事重要）→ 论据（事例）→ 对事例的分析 → 小结回扣。
:::

## 三、四种论证方法

:::cards 论证方法
举例论证 :: 用典型事例证明观点，资料里的事例可以改写使用
道理论证 :: 引用名言警句、领导人讲话、古语，增强说服力
对比论证 :: 正反对比（“做到了……则……；反之……则……”），观点更鲜明
比喻论证 :: 用形象的比喻把道理说透（如“小事是一扇窗”）
:::

:::warn 论据的常见问题
- **只堆例子不分析**：举完例子一定要用一两句话说明它证明了什么；
- **例子太长**：一个例子 50—80 字就够，不要讲故事；
- **例子和分论点不对应**：讲“担当”却举了一个“创新”的例子。
:::

## 四、练写一个分论点段

:::write 写一个分论点段 | 300
总论点：为民服务要把群众的“小事”当作“大事”。

请以“**建好回应机制，才能让‘小事’件件有着落**”为分论点，写一个完整的段落（250—300 字），包含分论点句、阐释、论据和小结。
--- 要点
- 开头亮出分论点句
- 阐释：为什么需要机制（靠个人热情不长久、群众诉求多而分散）
- 论据：一个具体事例（如“接诉即办”、网格化、12345 热线等）
- 对事例的分析：说明机制带来了什么效果
- 结尾小结，回扣分论点或总论点
- 字数在 250—300 字之间，语言规范
--- 参考答案
建好回应机制，才能让“小事”件件有着落。群众的诉求多而分散，如果只靠个别干部的热情，难免顾此失彼、时冷时热。只有把为民办事纳入制度轨道，才能让好作风成为常态。一些地方推行“12345 热线 + 网格”联动机制，群众反映的问题由热线统一受理、分派到网格限时办理、办结后回访评价，做到事事有回音、件件有着落。机制管长远，它把群众满意度变成了检验工作的硬指标，倒逼各部门主动担当、快速响应。用制度守护“小事”，为民服务才能久久为功。
:::

:::quiz 小测
下列关于大作文结构的说法，正确的是：
A. 开头要写 400 字以上，充分铺垫
B. 每个分论点段都应以分论点句开头
C. 例子越长越好，越详细越有说服力
D. 结尾可以引入一个全新的观点
答案：B
解析：开头 150 字左右即可；例子要简短并加以分析；结尾应总结升华，不宜引入新观点。
:::

四种论证方法 :: 举例、道理、对比、比喻
