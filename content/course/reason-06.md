逻辑判断是判断推理里最难、也最值钱的部分。第一类是**翻译推理**：把文字翻译成符号，按规则推出结论。规则只有几条，记牢就能做对。

## 一、翻译规则

| 原句 | 翻译 | 记法 |
|---|---|---|
| 如果 A，那么 B | A → B | 前推后 |
| 只要 A，就 B | A → B | 前推后 |
| 所有 A 都是 B | A → B | 前推后 |
| 只有 A，才 B | **B → A** | “才”字后面的放箭头前面 |
| 除非 A，否则不 B | **B → A** | 等同于“只有 A，才 B” |
| A 是 B 的必要条件 | B → A | |
| A 是 B 的充分条件 | A → B | |

:::warn 最容易错的
“只有 A，才 B”翻译成 **B → A**，不是 A → B。

“只有通过考核，才能获得奖金”：获得奖金 → 通过考核。通过了考核不一定能获得奖金（可能还有其他条件）。
:::

:::fill 翻译练习（用 → 连接，键盘上可以输入 -> 代替 →）
如果下雨，就带伞：[[下雨→带伞|下雨->带伞]]
只有努力，才能成功：[[成功→努力|成功->努力]]
所有公务员都要宣誓：[[公务员→宣誓|公务员->宣誓]]
除非报名，否则不能参加考试：[[参加考试→报名|参加考试->报名]]
:::

## 二、推理规则

对于 **A → B**：

- **肯定前件，就能肯定后件**：A 成立 ⇒ B 成立；
- **否定后件，就能否定前件**：B 不成立 ⇒ A 不成立（逆否命题）；
- 否定前件、肯定后件 ⇒ **推不出**必然结论。

:::key 逆否等价
A → B 等价于 ¬B → ¬A（“¬”表示“不”）。

例：“如果是金属，就能导电”等价于“如果不能导电，就不是金属”。
:::

:::match 判断能不能推出（已知：如果下雨，地面就湿）
今天下雨了 :: 能推出地面湿
今天地面没湿 :: 能推出没下雨
今天没下雨 :: 推不出地面湿不湿
今天地面湿了 :: 推不出是否下雨
:::

## 三、且、或、德摩根

- **A 且 B**：两者都成立；
- **A 或 B**：至少一个成立（可以都成立）；
- **要么 A 要么 B**：有且只有一个成立；
- **德摩根定律**：¬(A 且 B) = ¬A 或 ¬B；¬(A 或 B) = ¬A 且 ¬B；
- **A → B 等价于 ¬A 或 B**（这个转换在题目中常用）。

## 四、递推：把条件串起来

几个条件可以首尾相接：A → B，B → C ⇒ A → C。做题时把所有条件翻译出来，找出能串起来的链条。

:::example 翻译推理综合题
某单位安排值班：① 如果小李值班，那么小王也值班；② 只有小张值班，小王才值班；③ 小张没有值班。

由此可以推出：
A. 小李值班　B. 小王值班　C. 小李没有值班　D. 小王和小李都值班
--- 翻译
① 李 → 王；② “只有张，才王”：王 → 张；③ ¬张。
--- 串联
① ② 串起来：李 → 王 → 张。
--- 用已知条件推
③ ¬张，从链条末端否定：¬张 ⇒ ¬王 ⇒ ¬李（否定后件就否定前件）。
--- 答案
小王、小李都没有值班，选 **C**。
:::

:::quiz 练一练
“只有具备专业知识，才能胜任这份工作。”根据这句话，可以推出：
A. 具备专业知识就能胜任这份工作
B. 不具备专业知识就不能胜任这份工作
C. 不能胜任这份工作的人一定不具备专业知识
D. 胜任这份工作的人不一定具备专业知识
答案：B
解析：翻译：胜任 → 专业知识。逆否：¬专业知识 → ¬胜任，即 B。A 是肯定后件，推不出；C 是否定前件，推不出；D 与原句矛盾。
---
“如果天气晴朗，我们就去郊游。”下列哪项与这句话的意思**等价**？
A. 如果不去郊游，那么天气不晴朗
B. 如果天气不晴朗，就不去郊游
C. 如果去郊游，那么天气晴朗
D. 天气晴朗且我们去郊游
答案：A
解析：晴朗 → 郊游，逆否等价：¬郊游 → ¬晴朗。
---
“小王和小李不都去参加培训”等价于：
A. 小王和小李都不去
B. 小王不去或者小李不去
C. 小王去，小李不去
D. 小王和小李都去
答案：B
解析：¬(王 且 李) = ¬王 或 ¬李（德摩根定律）。
:::
