经济常识题一般不难，考的是**基本概念**（GDP、CPI、通货膨胀）和**宏观政策工具**（货币政策、财政政策），常常结合当年的政府工作报告出题。

## 一、微观经济：供求与价格

- **价值决定价格，供求影响价格**：供不应求价格上涨，供过于求价格下降；
- **替代品**（如猪肉和牛肉）：一种涨价，另一种需求增加；**互补品**（如汽车和汽油）：一种涨价，另一种需求减少；
- **需求弹性**：生活必需品（粮食、食盐）弹性小，价格变化对需求影响小；高档耐用品、奢侈品弹性大；
- **机会成本**：为了得到某种东西而放弃的其他东西中价值最高的那个；**沉没成本**：已经发生、无法收回的成本，不应影响决策；
- **边际效用递减**：连续消费同一种物品，每多消费一单位带来的满足感越来越小。

## 二、宏观经济指标

| 指标 | 含义 |
|---|---|
| GDP（国内生产总值） | 一国（地区）**境内**所有常住单位一定时期内生产的最终产品和服务的价值 |
| GNI（国民总收入） | 一国**国民**（常住单位）的收入总和 |
| CPI（居民消费价格指数） | 反映居民购买的消费品和服务价格水平的变动，衡量通货膨胀的主要指标 |
| PPI（工业生产者出厂价格指数） | 反映工业产品出厂价格的变动 |
| 恩格尔系数 | 食品支出占家庭消费总支出的比重，**越低越富裕** |
| 基尼系数 | 衡量收入分配差距，0—1 之间，越大越不平等，国际上常以 **0.4** 为警戒线 |

:::tip 拉动经济增长的“三驾马车”
**消费、投资、出口**。其中消费是经济增长的主要拉动力，扩大内需是战略基点。
:::

## 三、货币政策和财政政策

:::tabs
--- 货币政策（中国人民银行）
| 工具 | 宽松（刺激经济） | 紧缩（抑制过热） |
|---|---|---|
| 存款准备金率 | 降准 | 提高 |
| 利率（含 LPR 贷款市场报价利率） | 降息 | 加息 |
| 再贴现率 | 降低 | 提高 |
| 公开市场操作 | **买入**国债等（投放货币） | **卖出**国债等（回笼货币） |

**降准**：商业银行要交给央行的准备金比例降低 → 银行可贷资金增加 → 市场上的钱变多。
--- 财政政策（财政部）
- 工具：**税收、财政支出（政府投资、转移支付）、国债**；
- **积极的财政政策**：减税降费、扩大支出、发行国债和地方政府专项债，刺激经济；
- 稳健（紧缩）的财政政策：增税、减支，抑制过热。
:::

:::warn 易混
“公开市场操作”是**央行**的货币政策工具；“发行国债”作为筹集资金、扩大支出的手段属于**财政政策**。央行在公开市场上**买卖**国债才是货币政策。
:::

## 四、通货膨胀与通货紧缩

- **通货膨胀**：流通中的货币量超过实际需要，引起货币贬值、物价**全面、持续**上涨。一般 CPI 涨幅超过 3% 就需要警惕；
- **通货紧缩**：物价全面持续下降，往往伴随需求不足、经济下行；
- 应对通胀：紧缩的货币政策和财政政策；应对通缩：宽松的政策。

## 五、常见经济学名词

:::cards 经济学效应
马太效应 :: 强者愈强、弱者愈弱（“凡有的，还要加给他”）
木桶效应 :: 一只木桶能盛多少水，取决于最短的那块木板
鲶鱼效应 :: 引入外部竞争者激活内部活力
破窗效应 :: 不良现象如果被放任，会诱使人们仿效甚至变本加厉
羊群效应 :: 盲目从众
灰犀牛 :: 大概率发生、影响巨大但容易被忽视的风险
黑天鹅 :: 难以预测、不寻常但影响巨大的事件
劣币驱逐良币 :: 信息不对称时，劣质品把优质品挤出市场
:::

:::quiz 小测
为了刺激经济增长，央行可能采取的措施是：
A. 提高存款准备金率
B. 在公开市场上卖出国债
C. 下调贷款市场报价利率（LPR）
D. 提高再贴现率
答案：C
解析：A、B、D 都是紧缩措施。降息、降准、买入国债是宽松措施。

C. 食品价格上涨

A. 存款准备金率
