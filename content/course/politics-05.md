马克思主义哲学几乎每年都考，最常见的考法是**用古诗词、成语、俗语考哲学原理**。掌握“原理 + 对应的例子”，这类题就是送分题。

## 一、哲学基本问题：唯物还是唯心

**思维和存在的关系问题**是哲学的基本问题：

- 谁是第一性的？认为**物质第一性**的是唯物主义，认为**意识第一性**的是唯心主义；
- 思维能否认识存在？认为能的是可知论，认为不能的是不可知论。

:::tabs 唯物主义和唯心主义的形态
--- 唯物主义
| 形态 | 观点 | 例子 |
|---|---|---|
| 古代朴素唯物主义 | 把世界的本原归结为某种具体物质 | “五行说”（金木水火土）、泰勒斯“水是万物的本原” |
| 近代形而上学唯物主义 | 把物质归结为原子，用孤立、静止的观点看问题 | 机械唯物主义 |
| 辩证唯物主义 | 物质是标志客观实在的哲学范畴 | 马克思主义哲学 |
--- 唯心主义
| 形态 | 观点 | 例子 |
|---|---|---|
| 主观唯心主义 | 人的主观精神（感觉、心）是世界的本原 | “心外无物”“吾心即宇宙”“存在就是被感知” |
| 客观唯心主义 | 某种客观精神是世界的本原 | 朱熹“理在气先”、柏拉图“理念”、黑格尔“绝对精神” |
:::

:::tip 快速判断
看到“心”“我”“感觉” → 主观唯心；看到“理”“天命”“绝对精神”“理念” → 客观唯心；看到金木水火土、水、气、原子 → 唯物。
:::

## 二、唯物论：物质与意识

- 物质的唯一特性是**客观实在性**；
- **物质决定意识**，意识是人脑对客观存在的主观映象；意识对物质有**能动的反作用**；
- 方法论：一切从实际出发、实事求是；充分发挥主观能动性，但要**尊重客观规律**。

:::cards 例子和原理
拔苗助长 :: 违背客观规律（规律是客观的）
刻舟求剑 :: 只看到静止，忽视运动（形而上学）
人不能两次踏进同一条河流 :: 运动是绝对的（赫拉克利特，唯物辩证）
人一次也不能踏进同一条河流 :: 否认相对静止，相对主义诡辩
胸有成竹 :: 意识的能动作用（正确的意识指导实践）
画饼充饥、望梅止渴 :: 意识不能代替物质
:::

## 三、唯物辩证法：两个特征 + 三大规律

### 两个总特征

- **联系**：普遍性、客观性、多样性、条件性。例：唇亡齿寒、城门失火殃及池鱼、牵一发而动全身；整体与部分——“三个臭皮匠顶个诸葛亮”（整体大于部分之和）。
- **发展**：发展的实质是新事物的产生和旧事物的灭亡。例：士别三日当刮目相看；沉舟侧畔千帆过，病树前头万木春。

### 三大规律

:::tabs
--- 对立统一（矛盾）
是唯物辩证法的**实质和核心**。

- 矛盾的**同一性和斗争性**：相互依存、相互转化（祸兮福之所倚）；
- 矛盾的**普遍性和特殊性**：具体问题具体分析（对症下药、量体裁衣、因地制宜、因材施教）；
- **主要矛盾和次要矛盾**：抓重点（牵牛要牵牛鼻子、射人先射马、擒贼先擒王）；
- **矛盾的主要方面和次要方面**：看主流（瑕不掩瑜、一俊遮百丑的反面）；
- **内因和外因**：内因是变化的根据，外因是变化的条件（打铁还需自身硬；鸡蛋在适当温度下孵出小鸡，石头不能）。
--- 量变质变
- 量变是质变的必要准备，质变是量变的必然结果；
- 例：千里之堤溃于蚁穴、积土成山、水滴石穿、九层之台起于累土、不积跬步无以至千里；
- **适度原则**：过犹不及、物极必反。
--- 否定之否定
- 事物发展是**前进性和曲折性**的统一：道路是曲折的，前途是光明的；
- 辩证否定是“**扬弃**”：既克服又保留，例如“取其精华、去其糟粕”“推陈出新”。
:::

:::match 把古语和对应的哲学原理连起来
牵牛要牵牛鼻子 :: 抓主要矛盾
对症下药 :: 矛盾的特殊性，具体问题具体分析
千里之堤，溃于蚁穴 :: 量变引起质变
唇亡齿寒 :: 事物是普遍联系的
沉舟侧畔千帆过 :: 新事物必然战胜旧事物
瑕不掩瑜 :: 矛盾的主要方面决定事物性质
打铁还需自身硬 :: 内因是变化的根据
:::

:::quiz 小测
“心外无物”体现的哲学观点是：
A. 朴素唯物主义
B. 主观唯心主义
C. 客观唯心主义
D. 辩证唯物主义
答案：B
---
下列诗句中，体现“量变引起质变”的是：
A. 不识庐山真面目，只缘身在此山中
B. 冰冻三尺，非一日之寒
C. 欲穷千里目，更上一层楼
D. 不畏浮云遮望眼，自缘身在最高层
答案：B
解析：B 是量变积累到质变。A 讲认识受所处位置局限；C 讲站得高才能看得远（实践出真知/认识的条件）；D 讲站在高处不被表象迷惑。
---
“橘生淮南则为橘，生于淮北则为枳”主要说明：
A. 事物的联系是有条件的，外因对事物有影响
B. 意识决定物质
C. 矛盾的同一性
D. 事物发展是前进性和曲折性的统一
答案：A
解析：同一品种在不同环境下结出不同果实，体现联系的条件性、外部条件对事物的影响。
---
“取其精华，去其糟粕”体现的是：
A. 量变质变规律
B. 辩证否定观（扬弃）
C. 主观能动性
D. 整体和部分
答案：B
:::
