成语题的难点是**两个成语意思很像**：“层出不穷”和“屡见不鲜”都表示“多”，“潜移默化”和“耳濡目染”都表示“受影响”。这一课从讲义《25 易混成语 100 词》《常见成语辨析 105 组》《行测言语高频易混词》中挑出**真题考频最高的易混组**，每组只讲一句话的区别。

:::key 辨析易混成语的四把尺子
1. **侧重点**：强调“多”还是“新”，“想”还是“做”；
2. **适用对象**：只用于人？只用于建筑、技艺、文学？
3. **程度轻重**：“无可非议”比“无可厚非”重；
4. **感情色彩**：“处心积虑”贬义，“殚精竭虑”褒义。
:::

## 一、“多”与“常见”

| 成语 | 侧重 |
|---|---|
| **层出不穷** | 接连不断地**出现**，强调持续涌现 |
| **屡见不鲜** | 常常见到，**不新奇** |
| **司空见惯** | 某事**常见**，不足为奇 |
| **习以为常** | 常做常见，**成了习惯** |
| **五花八门** | 繁多而**变化莫测** |
| **林林总总** | 只强调**多**（且杂） |
| **不胜枚举** | 多到**举不完**（用于可以列举的事物） |

## 二、“影响”与“感染”

| 成语 | 侧重 |
|---|---|
| **潜移默化** | **思想、性格**在不知不觉中**发生变化** |
| **耳濡目染** | 经常听到看到而受影响，常指**学会某种技能、习惯** |
| **耳闻目睹** | **亲自**听到看到，不管受没受影响 |
| **春风化雨** | 适宜的**教育**（多指师长对后辈） |

## 三、“重要”与“必不可少”

| 成语 | 侧重 |
|---|---|
| **不可或缺** | 一定要有，**不能缺少**（程度更重） |
| **至关重要** | 非常重要，没有“一定要有”的意思 |
| **举足轻重** | 所处地位**重要**，一举一动影响全局（多用于人或组织的地位） |
| **不可替代** | 不能被别的代替 |

## 四、“准备”与“危险”

| 成语 | 侧重 |
|---|---|
| **未雨绸缪** | 事先做好准备——**已有行动** |
| **居安思危** | 安定时想到危险——**停留在思想上** |
| **防微杜渐** | 在错误、坏事**刚萌芽**时就制止 |
| **危在旦夕** | 危险**近在眼前** |
| **危机四伏** | 危险**多**，到处都是 |
| **岌岌可危** | 非常危险，**快要倾覆** |

## 五、“方法不对”与“态度轻视”

| 成语 | 侧重 |
|---|---|
| **南辕北辙** | 行动与目的**方向相反** |
| **缘木求鱼** | **方法**不对，不可能达到目的 |
| **刻舟求剑** | 拘泥**不知变通**，不懂情况已变化 |
| **不屑一顾** | 认为不值得一看，**不重视** |
| **嗤之以鼻** | 用鼻子冷笑，**鄙视**、瞧不起 |

## 六、“技艺”与“逼真”

| 成语 | 侧重 |
|---|---|
| **出神入化** | **技艺**达到绝妙境界 |
| **炉火纯青** | 技艺、**学问修养**达到纯熟完美（适用范围比出神入化宽） |
| **栩栩如生** | **艺术形象**逼真，像活的一样 |
| **惟妙惟肖** | **描写、模仿**得非常逼真传神 |
| **绘声绘色** | **讲述、描写**生动逼真 |
| **呼之欲出** | 画像、人物刻画逼真；也指某事**即将揭晓** |

## 七、“用心”与“评价”

| 成语 | 侧重 |
|---|---|
| **殚精竭虑** | 用尽精力心思（**褒义**） |
| **处心积虑** | 蓄谋已久（**贬义**，多指做坏事） |
| **苦心孤诣** | 苦心钻研，达到别人达不到的境地（多用于**学问、技艺**） |
| **惨淡经营** | 苦心谋划经营（多用于**事业、商业**） |
| **无可厚非** | 虽有缺点，但**不能过分指责** |
| **无可非议** | 完全没有可指责的（程度更重） |
| **一诺千金** | 说话**守信用** |
| **一言九鼎** | 话的**分量重**，能起决定作用 |

## 八、随堂练习

:::quiz 易混成语小测
近年来，各种新型电信诈骗手段______，令人防不胜防。
A. 屡见不鲜
B. 层出不穷
C. 司空见惯
D. 习以为常
答案：B
解析：强调新手段**接连不断地出现**，用层出不穷。其余三个侧重“常见、不新奇”，与“防不胜防”的语境不符。
---
他的父亲是一名木匠，从小______，他也练就了一手好木工活。
A. 潜移默化
B. 耳濡目染
C. 耳闻目睹
D. 春风化雨
答案：B
解析：经常看到听到而**学会了技能**，用耳濡目染。潜移默化侧重思想性格的变化。
---
面对可能到来的汛期，该县提前加固堤坝、储备物资，做到了______。
A. 居安思危
B. 未雨绸缪
C. 防微杜渐
D. 危机四伏
答案：B
解析：已经有了具体行动（加固、储备），用未雨绸缪；居安思危只停留在思想层面。
---
为了改善家庭生活，他下班后兼职送外卖，这种做法______。
A. 无可非议
B. 无可厚非
C. 不可或缺
D. 举足轻重
答案：A
解析：通过正当劳动改善生活，没有任何可指责之处，用无可非议。无可厚非暗示做法有不妥之处，只是不宜过分指责，放在这里分寸不对。
---
老艺人的剪纸技艺______，剪出的花鸟______。
A. 出神入化　栩栩如生
B. 栩栩如生　出神入化
C. 惟妙惟肖　炉火纯青
D. 炉火纯青　绘声绘色
答案：A
解析：第一空形容技艺，出神入化、炉火纯青都可以；第二空形容作品形象逼真，用栩栩如生。绘声绘色用于讲述、描写，不用于剪纸作品。
:::
