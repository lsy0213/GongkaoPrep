翻译推理的基础课讲了“如果、只有、除非”和逆否、递推。真题会把它们换个说法、串得更长，再加上“**有的**”。这一课讲三件事：**更多关联词的翻译、长推理链的处理、“所有 / 有的”推理**，最后讲翻译推理的“前提型”问法。

## 一、更多关联词的翻译

:::key 翻译的总原则
找出**充分条件**（有它就一定行）放在箭头前，**必要条件**（没它一定不行）放在箭头后。
:::

| 原句 | 翻译 |
|---|---|
| 不 A 就不 B / 没有 A 就没有 B | ¬A → ¬B，等价于 **B → A** |
| A 是 B 的**前提、基础、关键、必要条件** | **B → A** |
| 除非 A，否则 B | **¬A → B** |
| B，除非 A | ¬A → B（同上） |
| 只要 A 就 B / 一旦 A 就 B / 凡是 A 都 B / 任何 A 都 B | A → B |
| A 必须 B / 要 A 就得 B | A → B |
| 谁 A 谁 B | A → B |

:::warn “除非”的两种情况
- “**除非 A，否则不 B**” = B → A（基础课的形式）；
- “**除非 A，否则 B**” = ¬A → B。
记法：**“除非”后面的东西取反，放到箭头前面**；“否则”后面的照抄，放到箭头后面。
:::

:::fill 翻译练习（用 → 连接，¬ 表示“不”，可输入 -> 代替 →）
没有调查就没有发言权：[[发言权→调查|发言权->调查]]
人才是发展的关键：[[发展→人才|发展->人才]]
除非下雨，否则比赛照常进行：[[¬下雨→比赛|¬下雨->比赛|不下雨→比赛|不下雨->比赛]]
:::

## 二、长推理链

条件多达 4—6 个时，按这三步处理：

:::flow 推理链三步
全部翻译 :: 每个条件写成箭头，“或”“且”单独记
首尾相接 :: 把能接上的箭头连成一条长链，必要时先逆否再接
从确定信息出发 :: 题干给出的“事实”（如“小张没有值班”）是起点：肯定前件往后推，否定后件往前推
:::

:::example 逆否后再串联
① 如果开展新项目，就要增加预算；② 只有获得批准，才能增加预算；③ 不获得批准，就要调整计划。已知：没有调整计划。可以推出：
--- 翻译
① 新项目 → 增预算；② 增预算 → 批准；③ ¬批准 → 调整。
--- 串联
① ② 连成：新项目 → 增预算 → 批准。③ 逆否：¬调整 → 批准。
--- 从事实出发
已知 ¬调整 ⇒ 批准。“批准”是链条的后件，**肯定后件推不出前件**：能否增预算、是否开展新项目都不确定。
--- 结论
只能推出“**获得了批准**”。
:::

### 二难推理

**A 或 B；A → C；B → C ⇒ C**。两条路都通向同一个结论，结论就一定成立。

例：要么加班，要么把工作带回家；加班就不能陪孩子；带回家也不能陪孩子 ⇒ 不能陪孩子。

## 三、“所有”与“有的”

| 句子 | 含义 | 能否推出 |
|---|---|---|
| **所有 A 都是 B** | A → B | 可以逆否：不是 B 的都不是 A；**不能换位**（不能推出所有 B 是 A） |
| **有的 A 是 B** | 至少存在一个 A 是 B（可能所有 A 都是 B） | 可以**换位**：有的 B 是 A；**不能逆否** |
| **有的 A 不是 B** | 至少有一个 A 不是 B | |

:::key “有的”串联规则
“有的”**必须放在链条的最前面**，后面接“所有”的箭头：
有的 A 是 B，所有 B 都是 C ⇒ **有的 A 是 C**。
反过来“所有 A 是 B，有的 B 是 C”**推不出**任何关于 A 和 C 的结论。
:::

:::example “有的”推理
已知：有的党员是教师；所有教师都具有大学学历。可以推出：

A. 所有党员都具有大学学历　B. 有的党员具有大学学历　C. 有的具有大学学历的人不是党员　D. 所有具有大学学历的人都是教师
--- 串联
有的党员 → 教师 → 大学学历。“有的”在最前面，可以串。
--- 结论
**有的党员具有大学学历**，选 **B**。A 把“有的”扩大成“所有”；C、D 推不出。
:::

:::tip 矛盾关系（真假推理常用）
- “所有 A 是 B” 与 “有的 A 不是 B” 矛盾；
- “所有 A 不是 B” 与 “有的 A 是 B” 矛盾；
- “A 且 B” 与 “¬A 或 ¬B” 矛盾；“A → B” 与 “A 且 ¬B” 矛盾。
:::

## 四、前提型：补一个条件

问法：“**要使上述推理成立，必须补充的前提是**”。做法是“**搭桥**”：找出论据和结论中**没有连上的两个概念**，补一个箭头把它们连起来。

例：“小王是公务员，所以小王要遵守职业道德。”论据有“公务员”，结论有“遵守职业道德”，补上“**所有公务员都要遵守职业道德**”即可。

## 五、随堂练习

:::quiz 翻译进阶小测
“没有规矩，不成方圆”可以翻译为：
A. 规矩 → 方圆
B. 方圆 → 规矩
C. ¬方圆 → ¬规矩
D. 规矩 → ¬方圆
答案：B
解析：¬规矩 → ¬方圆，逆否得 方圆 → 规矩。
---
“除非天气恶劣，否则航班正常起飞”，下列一定为真的是：
A. 天气恶劣，航班一定不起飞
B. 航班没有正常起飞，说明天气恶劣
C. 天气不恶劣，航班可能不起飞
D. 航班正常起飞，说明天气不恶劣
答案：B
解析：翻译为 ¬恶劣 → 正常起飞；逆否：¬正常起飞 → 恶劣。A、D 都是从后件或否定前件推，推不出。C 与条件矛盾。
---
已知：所有的科学家都是勤奋的；有的科学家是音乐爱好者。可以推出：
A. 所有勤奋的人都是科学家
B. 有的音乐爱好者是勤奋的
C. 所有音乐爱好者都是勤奋的
D. 有的科学家不是勤奋的
答案：B
解析：“有的科学家是音乐爱好者”换位为“有的音乐爱好者是科学家”，再接“科学家 → 勤奋”：有的音乐爱好者是勤奋的。
---
已知“所有的鸟都会飞”为假，则下列一定为真的是：
A. 所有的鸟都不会飞
B. 有的鸟会飞
C. 有的鸟不会飞
D. 鸵鸟不会飞
答案：C
解析：“所有 A 是 B”为假，则它的矛盾命题“有的 A 不是 B”为真。D 是常识，但不能由题干推出。
---
“只要坚持锻炼，身体就会健康。小李身体健康。”下列说法正确的是：
A. 小李一定坚持锻炼了
B. 小李一定没有坚持锻炼
C. 不能确定小李是否坚持锻炼
D. 小李坚持锻炼了但方法不对
答案：C
解析：锻炼 → 健康，肯定后件推不出前件。
:::
