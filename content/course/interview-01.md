笔试过了，就进入面试。面试在总成绩里占 40%—50%，**逆袭和被逆袭都很常见**。这一课先了解面试的形式、评分标准和礼仪。

## 一、面试形式

:::tabs
--- 结构化面试（最常见）
- 国考多数职位、四川省考普遍采用；
- 一般 **3—4 道题**，总时间 **15—20 分钟**，题目由考官读或给题本；
- 考官 5—7 人，去掉最高分和最低分后取平均；
- 每题没有标准答案，但有评分要点。
--- 结构化小组面试
- 几名考生同组，依次答题，再互相点评、补充；
- 部分国考部门、部分省份采用。
--- 无领导小组讨论
- 5—8 名考生围绕一个问题讨论，考官不参与，观察每个人的表现；
- 考查组织协调、沟通、团队合作；
- 部分国考部门和部分省份采用，具体看招录机关的面试公告。
:::

## 二、评分要素

| 要素 | 对应题型 |
|---|---|
| 综合分析能力 | 综合分析题（社会现象、政策理解、观点） |
| 计划组织协调能力 | 组织计划题（调研、宣传、活动） |
| 应急应变能力 | 应急应变题 |
| 人际交往的意识与技巧 | 人际关系题 |
| 言语表达能力 | 所有题目 |
| 自我情绪控制 | 所有题目，尤其是压力题 |
| 求职动机与拟任职位匹配 | 自我认知、岗位匹配题 |
| 举止仪表 | 全程 |

## 三、面试当天的流程

:::flow
报到 :: 按时到达，交手机，验证身份
抽签 :: 抽取面试顺序号
候考 :: 在候考室等待，不能交流题目
进场 :: 引导员带入考场
答题 :: 按顺序回答 3—4 道题
退场 :: 答完离场，有的考场当场宣分
:::

## 四、礼仪要点

:::key 礼仪清单
- **着装**：深色正装（西装 / 职业套装），干净整洁，不戴夸张饰品；
- **进场**：跟随引导员进入，走到考生席，向考官问好：“各位考官好，我是 × 号考生。”（**不得透露姓名**等个人信息）；
- **坐姿**：坐椅子的 2/3，背挺直，双手自然放在桌上或腿上；
- **答题**：眼神照顾到所有考官，以主考官为主；答完说“**回答完毕**”；
- **离场**：起身说“谢谢各位考官”，把椅子归位，草稿纸和题本按要求留下。
:::

:::warn 不要做的事
- 透露姓名、毕业院校、家庭背景等可能影响公平的信息；
- 答题时看天花板、低头念稿纸；
- 和考官争辩，或者答完后追问“我答得怎么样”。
:::

:::quiz 小测
结构化面试进场后，向考官问好的正确方式是：
A. “各位考官好，我叫张三，毕业于××大学。”
B. “各位考官好，我是 5 号考生。”
C. 不说话，直接坐下
D. “大家好，我准备好了，请出题吧。”
答案：B
解析：面试中不得透露姓名、院校等信息，用抽签号代替。
---
下面哪项**不是**结构化面试常见的评分要素？
A. 综合分析能力
B. 计划组织协调能力
C. 家庭背景
D. 言语表达能力
答案：C
:::
