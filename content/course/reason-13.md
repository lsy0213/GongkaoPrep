类比推理的难点不在“一级关系”（大多数人都能看出是因果、是功能），而在**二级辨析**：几个选项都是因果关系时，谁的原因是人为的？几个选项都是原材料时，是直接原材料还是间接原材料？这一课按讲义《类比推理必会对应关系》的专题，把每种关系**怎么辨析**讲清楚，最后补充常识类比。

## 一、二级辨析的总思路

:::key 一级关系相同时，从这些角度继续比
- **必然 / 或然**：金属一定导电（必然），冬天不一定严寒（或然）；
- **主要 / 次要**：灯的主要功能是照明，装饰是次要功能；
- **直接 / 间接**：豆子直接做豆腐；茶树要先产出茶叶，才能做茉莉花茶（间接）；
- **人为 / 自然**：汽车尾气导致酸雨（人为原因）；
- **好 / 坏**：知足不辱（好结果）；
- **同一主体 / 不同主体**：构思—写作—修改是同一个人；点菜—烹饪—上菜是三个人；
- **物理变化 / 化学变化**：玉石雕琢成玉器（物理）；牛奶发酵成酸奶（化学）；
- **褒贬、词性、结构**：最后才看，用来排除剩下的两个选项。
:::

## 二、必会对应关系

:::tabs
--- 因果
**辨析点**：原因是人为还是自然；结果是好是坏；必然还是可能。
- 玻璃幕墙 ∶ 光污染（人为原因）——汽车尾气 ∶ 酸雨；
- 知足 ∶ 不辱（好结果）——知止 ∶ 不殆；
- 诗句、成语中也有因果：“风雪夜归人”是因，“柴门闻犬吠”是果。
--- 原材料与工艺
**辨析点**：直接 / 间接原材料；必然 / 或然原材料；物理 / 化学变化。
- 玉石 ∶ 雕琢 ∶ 玉器（物理变化）——蚕丝 ∶ 织造 ∶ 丝绸；
- 茶树 ∶ 茉莉花茶（间接）——螃蟹 ∶ 蟹黄包；
- 藤条 ∶ 藤椅（必然：藤椅一定用藤条）；竹子 ∶ 桌子（或然：桌子不一定用竹子）。
--- 功能与属性
**功能**辨析主要 / 次要功能：白醋 ∶ 消毒（次要功能，主要是调味）——汽油 ∶ 去渍。
**属性**辨析必然 / 或然：物体 ∶ 惯性（必然）——液体 ∶ 流动性。
--- 先后顺序
**辨析点**：主体是否一致。
- 学习菜谱 ∶ 下厨烹饪 ∶ 总结经验（同一主体）——通过安检 ∶ 车站候车 ∶ 登上列车；
- 售卖假货 ∶ 举报维权 ∶ 上门调查（三个不同主体）——点菜下单 ∶ 烹饪菜肴 ∶ 传送菜品。
--- 方式与目的
用“为了”造句。**辨析点**：方式是否合理、能否达到目的。
- 声东 ∶ 击西——围魏 ∶ 救赵（有效的方式）；
- 刻舟 ∶ 求剑——掩耳 ∶ 盗铃、缘木 ∶ 求鱼（错误的方式，达不到目的）。
--- 场所与职业
- 质证 ∶ 法庭——监考 ∶ 考场（动作发生地）；
- 图书馆 ∶ 著作 ∶ 收藏——咖啡厅 ∶ 饮品 ∶ 制作；
- 职业—场所—工作：医生 ∶ 医院 ∶ 诊疗。
--- 其他对应
| 关系 | 例子 |
|---|---|
| **食物链** | 蚜虫 ∶ 七星瓢虫 ∶ 小麦（小麦被蚜虫吃，蚜虫被瓢虫吃） |
| **反比** | 速度 ∶ 时间（路程一定）；供给 ∶ 价格 |
| **充分 / 必要条件** | 年满 18 周岁 ∶ 选举权（必要条件之一） |
| **动力来源** | 风车 ∶ 风能；帆船 ∶ 风 |
| **工具** | 听诊器 ∶ 医生；锄头 ∶ 农民 |
| **物理单位** | 电流 ∶ 安培；功率 ∶ 瓦特；力 ∶ 牛顿 |
| **配套使用** | 锁 ∶ 钥匙；笔 ∶ 墨 |
| **依据** | 判决 ∶ 法律；诊断 ∶ 症状 |
| **载体** | 文字 ∶ 书籍；信息 ∶ 光盘 |
| **研究对象** | 天文学 ∶ 天体；昆虫学 ∶ 昆虫 |
:::

## 三、语义关系的进阶考法

- **近义词还要比褒贬**：“推敲 ∶ 斟酌”都是中性；“鼓吹 ∶ 宣传”一贬一中；
- **成语之间的关系**：近义（车水马龙 ∶ 门庭若市）、反义、因果（瓜熟 ∶ 蒂落 → 水到渠成）、方式目的（围魏 ∶ 救赵）；
- **比喻、象征**：鸽子 ∶ 和平，松柏 ∶ 坚贞，梅花 ∶ 傲骨，筚路蓝缕 ∶ 艰辛（成语的含义）；
- **字词拆分**：两个词拆开后的语法关系相同（如“地震”“海啸”都是主谓结构）。

## 四、常识类比

题干两个词是“**作品与作者、人物与事件、地点与特产、诗句与主题**”时，需要一点常识：

:::cards 常识类比积累
《西游记》∶ 吴承恩 :: 作品与作者（同类：《警世通言》∶ 冯梦龙）
三顾茅庐 ∶ 刘备 :: 典故与人物
泰山 ∶ 山东 :: 名胜与所在地（大明湖也在山东）
“春蚕到死丝方尽” :: 主题：奉献、思念（李商隐《无题》）
“落红不是无情物” :: 主题：奉献（龚自珍）
欧姆 ∶ 电阻 :: 物理单位
焦耳 ∶ 能量 :: 物理单位
赫兹 ∶ 频率 :: 物理单位
帕斯卡 ∶ 压强 :: 物理单位
:::

## 五、随堂练习

:::quiz 类比进阶小测
金属 ∶ 导电
A. 冬天 ∶ 下雪
B. 黄连 ∶ 苦涩
C. 苹果 ∶ 红色
D. 学生 ∶ 近视
答案：B
解析：导电是金属的必然属性。苦涩是黄连的必然属性；A、C、D 都是或然属性。
---
豆子 ∶ 豆腐
A. 棉花 ∶ 布鞋
B. 茶树 ∶ 绿茶
C. 葡萄 ∶ 葡萄干
D. 竹子 ∶ 桌子
答案：C
解析：豆子是豆腐的直接、必然原材料。葡萄直接晒干成葡萄干，也是直接、必然原材料。A、B 是间接原材料；D 是或然原材料（桌子不一定用竹子）。
---
刻舟 ∶ 求剑
A. 围魏 ∶ 救赵
B. 卧薪 ∶ 尝胆
C. 缘木 ∶ 求鱼
D. 闻鸡 ∶ 起舞
答案：C
解析：用错误的方式求达不到的目的。A 是有效的方式；B、D 不是方式与目的。
---
构思 ∶ 写作 ∶ 修改
A. 点菜 ∶ 烹饪 ∶ 上菜
B. 播种 ∶ 施肥 ∶ 收割
C. 报案 ∶ 侦查 ∶ 审判
D. 投稿 ∶ 审稿 ∶ 发表
答案：B
解析：先后顺序，且三个动作可以是同一主体。B 都可以是农民；A、C、D 主体不同。
---
白醋 ∶ 消毒
A. 汽油 ∶ 去渍
B. 冰箱 ∶ 冷藏
C. 雨伞 ∶ 挡雨
D. 电话 ∶ 通话
答案：A
解析：消毒是白醋的次要功能（主要是调味）；去渍是汽油的次要功能（主要是燃料）。B、C、D 都是主要功能。
:::
