笔试结束不等于可以休息。从笔试到面试一般只有 **2—3 个月**，而面试准备至少需要 4 周。这一课讲笔试后的时间线和要做的事。

## 一、笔试后的时间线（国考为例）

:::flow
笔试结束 :: 11 月底—12 月初
估分 :: 对照公布的答案大致估算
出成绩 :: 次年 1 月中旬，同时公布合格线
进面名单 :: 成绩公布后陆续公布
资格复审 :: 一般在面试前，按通知准备材料
面试 :: 次年 2—3 月
:::

:::tip 什么时候开始准备面试
**不要等进面名单出来再准备**。如果估分在往年进面线附近，笔试结束一两周后就可以开始学面试；成绩出来后进了面试，就能从容准备；没进面，也为下一次考试积累了经验。
:::

## 二、查成绩与进面

- 国考笔试成绩在国家公务员局网站查询；四川省考在四川人事考试网查询；
- 合格分数线只是门槛，能否进面看**本职位排名**（按面试比例，如 3∶1）；
- 进面名单通常会公布**本职位进面最低分**，可以据此判断竞争情况。

## 三、调剂（国考）

国考在面试前一般会组织**调剂**：部分职位报考人数不足或进面人数不够，会面向全体达到合格线的考生补充招录。

- 调剂公告一般在成绩公布后发布，报名时间很短（几天），**要随时关注**；
- 调剂要求考生**符合调剂职位的报考条件**，笔试成绩达到相应合格线；
- 没进面的考生可以通过调剂争取机会。

## 四、资格复审

:::check 资格复审常见材料（以通知为准）
- 本人身份证、学生证或工作证原件
- 准考证
- 学历学位证书（应届生提供学校出具的就业推荐表等材料）
- 报名登记表
- 职位要求的其他材料：政治面貌证明、基层工作经历证明、相关资格证书等
- 在职人员：所在单位同意报考的证明
:::

:::warn 复审不通过的常见原因
专业不符、学历学位不符、基层工作经历年限不够、政治面貌不符、证明材料缺失或不规范。**报名时如实填写、提前准备材料**，就能避免这些问题。
:::

## 五、面试准备计划（4—6 周）

| 时间 | 内容 |
|---|---|
| 第 1 周 | 学完面试课程，了解六类题型的框架 |
| 第 2—3 周 | 每天 3—5 道题计时作答，录音回听；积累事例和规范表达 |
| 第 4 周 | 了解报考单位和岗位职能；准备岗位匹配类题目 |
| 第 5—6 周 | 每周 2—3 次完整模拟（找同伴扮考官），调整仪态和心态 |

:::cards 本课记忆卡
笔试到面试的时间 :: 一般 2—3 个月
什么时候开始准备面试 :: 估分接近进面线时就开始，不等名单
国考调剂 :: 成绩公布后发布公告，面向合格线以上符合条件的考生，报名时间短
资格复审不通过的常见原因 :: 专业、学历、基层年限、政治面貌不符，材料缺失
:::
