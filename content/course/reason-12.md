三步法（读问法 → 拆要件 → 比选项）能解决大部分定义判断。剩下的失分来自三个地方：**要件拆不全**（漏了“主动”“无偿”这种小词）、**被陷阱骗**（选项和定义“看起来一样”但主体或方向变了）、**定义读不懂**（心理学、经济学、法律术语）。这一课逐个解决，并把讲义（《判断推理 88 页》定义必知词汇）里的高频定义整理成卡片。

## 一、要件拆细：最容易漏的小词

:::key 这些词出现时，一定单独标出来
- **主观**：“故意”“主动”“自愿”“有意识地”“无意识地”；
- **范围**：“仅”“只”“全部”“部分”“未经……”“在……期间”；
- **方式**：“无偿”“公开”“秘密”“通过网络”“以……为手段”；
- **程度、结果**：“导致”“足以”“严重”“造成……损失”；
- **否定**：“不”“非”“未”“没有”（常常是定义的核心，如“非过失性”“未经许可”）。
:::

## 二、常见陷阱

| 陷阱 | 例子 |
|---|---|
| **主体偷换** | 定义要求“行政机关”，选项是“村委会”（基层群众自治组织）；定义要求“家庭成员”，选项是“志愿者” |
| **方向颠倒** | 定义是“年轻一代教年长一代”，选项是“父亲教儿子” |
| **缺一个要件** | 定义要求“已经造成损失”，选项只是“可能造成” |
| **用常识判断** | 选项在常识上“当然是对的”，但不符合题目的定义——以定义为准 |
| **同构选项** | 两个选项的结构一模一样（如都是“A 向 B 借钱”），单选题里它们要么都对、要么都错，可以一起排除 |
| **举例当定义** | 定义后面附了“如……”的例子，选项和例子很像但缺少要件 |

:::tip “不属于”题怎么做
先**找出三个符合的**，剩下的就是答案。如果有一个选项明显缺要件，可以直接选，但最好用另外三个验证一下。
:::

## 三、多定义题

:::key 多定义的三种问法
1. **问其中一个定义**：只读那个定义，其余跳过；
2. **问“全部符合 / 都不符合”**：每个选项都要和对应定义逐个比对；
3. **问“对应关系正确的是”**：每个选项给出“某某属于某定义”，用排除法，先排除最明显错的。
:::

:::example 多定义：外显学习与内隐学习
**外显学习**：有意识的、需要付出努力并遵循明确规则的学习。
**内隐学习**：无意识地获得刺激环境中复杂知识的过程，学习者往往说不清自己学到了什么规则。

下列属于**内隐学习**的是：
A. 小明每天背 50 个英语单词
B. 孩子在母语环境中自然学会了说话的语法规则，却讲不出任何语法术语
C. 小李照着说明书学会了使用单反相机
D. 学生学习数学公式后反复做练习题
--- 只看“内隐学习”
要件：① **无意识地**获得；② 复杂知识；③ 说不清学到的规则。
--- 逐项比对
A、C、D 都是**有意识**、有明确规则的学习，属于外显学习；
B：在环境中**自然**习得，说不出规则 → 符合。
--- 答案
**B**。
:::

## 四、高频定义速览

真题里的定义每年都不同，但**领域**很固定：法律、心理效应、管理与经济、营销、逻辑谬误、修辞、地理。熟悉这些领域的“老面孔”，读题时会快很多。

:::tabs
--- 心理与管理效应
| 效应 | 一句话 |
|---|---|
| **羊群效应** | 从众心理导致盲从 |
| **南风效应** | 温和、讲方法比强硬手段更有效 |
| **鲶鱼效应** | 引入竞争者激发整体活力 |
| **青蛙现象** | 对渐变的危机失去警觉 |
| **罗森塔尔效应**（皮格马利翁效应） | 他人的期望使人朝期望方向发展 |
| **德西效应** | 外在奖励反而削弱了原本的内在兴趣 |
| **晕轮效应**（光环效应） | 由一个突出特点推断全部特点 |
| **首因效应 / 近因效应** | 第一印象 / 最近的印象影响最大 |
| **马太效应** | 强者越强、弱者越弱 |
| **破窗效应** | 不良现象被放任会诱使更多人效仿 |
| **登门槛效应** | 先接受小要求，更容易接受大要求 |
| **超限效应** | 刺激过多、过强或作用时间过久，引起逆反 |
| **社会懈怠**（社会惰化） | 群体一起工作时个人付出的努力比单干时少 |
| **社会促进**（结伴效应） | 有他人在场或一起活动时效率提高 |
| **地板效应 / 天花板效应** | 测验太难，分数都挤在低端 / 太容易，都挤在高端 |
--- 法律类
| 定义 | 关键要件 |
|---|---|
| **过于自信的过失** | 已经预见可能发生，但**轻信能够避免** |
| **疏忽大意的过失** | 应当预见而**没有预见** |
| **商标在先使用权** | 他人**申请注册之前**已经善意连续使用 → 可在原范围内继续使用 |
| **无过失性辞退** | 劳动者**非过失**、客观情况变化 → 用人单位**提前 30 日通知或额外支付 1 个月工资**后解除 |
| **过错推定** | 受害人证明因果关系后，加害人**不能证明自己无过错**就推定有过错 |
| **离婚冷静期** | 协议离婚时，登记机关收到申请之日起 **30 日内**任何一方可撤回 |
--- 逻辑谬误
| 谬误 | 一句话 |
|---|---|
| **德克萨斯神枪手** | 先射击再画靶：从结果里挑出巧合，硬说有规律 |
| **诉诸自然** | “天然的就是好的” |
| **基因谬误**（起源谬误） | 根据来源而不是内容判断好坏 |
| **诉诸情感** | 用激发情绪代替讲道理 |
| **罪恶关联** | “坏人也支持它，所以它是坏的” |
| **错误归因** | 把相关或先后关系当成因果关系 |
| **沉没成本谬误** | 因为已投入无法收回的成本而继续错误的事 |
| **稻草人谬误** | 歪曲对方观点再加以攻击 |
--- 营销类
| 营销 | 一句话 |
|---|---|
| **直复营销** | 不经中间商，直接与顾客沟通并获得可测量的回应（邮件、电话、电视购物） |
| **饥饿营销** | 故意限量供应，制造供不应求 |
| **话题营销** | 制造话题，借舆论传播 |
| **公益营销** | 与公益事业结合，提升品牌形象 |
| **社群营销** | 依托社群（粉丝群、兴趣群）开展营销 |
| **漏洞营销** | 利用对手产品或服务的漏洞突出自己 |
:::

## 五、随堂练习

:::quiz 定义判断进阶小测
**德西效应**是指在某些情况下，当人们获得外在报酬时，原本由兴趣驱动的内在动机反而减弱的现象。

下列属于德西效应的是：
A. 小王业绩突出获得加薪，此后工作更加努力
B. 小明原本喜欢画画，父母开始按幅给零花钱后，一旦不给钱他就不画了
C. 小李讨厌跑步，公司规定跑步可以换取奖金后他才开始跑步
D. 小张为了评优，主动加班完成任务
答案：B
解析：要件：① 原本有内在兴趣；② 获得外在报酬；③ 内在动机减弱。只有 B 三项全符合。C 原本就没有兴趣。
---
**行政指导**是指行政机关在其职能、职责或管辖事务范围内，为实现行政目的，采用说服、建议、劝告等**非强制性**方式，引导相对人自愿作出或不作出某种行为。

下列属于行政指导的是：
A. 村委会建议村民统一种植某种经济作物
B. 市场监管局对违法经营的商户处以罚款
C. 农业农村局向农户推荐优良品种并提供技术咨询，由农户自愿选择
D. 税务局强制扣缴企业拖欠的税款
答案：C
解析：A 主体是村委会（基层群众自治组织），不是行政机关；B、D 是强制性的行政处罚、行政强制。
---
**社会懈怠**是指群体一起完成一件工作时，个人所付出的努力比单独完成时偏少的现象。

下列**不属于**社会懈怠的是：
A. 拔河比赛中，每个人用的力气比单独拉绳时小
B. 小组作业时，有的组员觉得反正有别人做，就不太出力
C. 有同事在旁边时，小李打字的速度比独自一人时更快
D. 集体大扫除时，有人觉得少扫一点没人发现
答案：C
解析：C 是他人在场提高了效率，属于社会促进，与社会懈怠方向相反。
---
做多定义题时，题目问“下列属于定义②的是”，正确的做法是：
A. 把所有定义都仔细读一遍再看选项
B. 只读定义②，拆出要件后比对选项
C. 先看选项，再根据常识判断
D. 先读定义①，因为定义②一般与定义①相反
答案：B
:::
