上一课讲的是“对外说”的文种（讲话、倡议、宣传、编者按）。这一课讲“**对内办事**”的文种：**调研报告、情况报告、简报、工作方案、工作建议、信函**。它们的共同特点是**书面、客观、条理清楚**，答案的结构往往直接决定得分。

## 一、调研报告 / 情况报告

:::key 四部分结构
**基本情况**（调研对象、时间、方式，或事件概况）→ **主要做法与成效** 或 **存在问题** → **原因分析** → **对策建议**。
题目只要求其中几部分时（如“写一份反映问题的情况报告”），就只写那几部分，不要硬凑。
:::

- **语言**：客观陈述，多用数据，少用形容词和感叹句；
- **标题**：《关于××的调研报告》《关于××情况的报告》；
- **调研报告和情况报告的区别**：调研报告是主动去调查研究得出结论；情况报告是向上级如实反映某件事的情况，常含建议。

## 二、简报

简报是机关内部**交流情况、通报工作**的简短报道，有固定的三部分：

| 部分 | 内容 |
|---|---|
| **报头** | 简报名称（如“××工作简报”）、期数、编发单位、日期 |
| **报核**（正文） | 标题 + 导语（概述）+ 主体（做法、成效）+ 结尾（下一步打算，可省略） |
| **报尾** | 报送单位、发送单位、印发份数 |

答题时**报核是重点**，报头报尾按格式简要写出即可。

## 三、工作方案

:::flow 工作方案的结构
标题 :: 《关于开展××工作的方案》
目的与依据 :: 为什么开展（一两句）
目标 :: 要达到什么效果（可量化更好）
组织领导 :: 成立工作小组、明确责任单位
主要措施 / 工作步骤 :: 分阶段或分条写（准备阶段、实施阶段、总结阶段）——要点最多的部分
保障措施 :: 经费、宣传、督查考核
:::

:::write 工作方案（主要措施部分） | 350 | 20
**给定资料**

某市计划在全市推广“15 分钟便民生活圈”。前期试点发现：一些社区周边买菜、修鞋、配钥匙的小店因房租上涨陆续关门；新建小区配套商业用房被改成了售楼处、办公室；居民希望家门口有早餐店、药店、快递点、养老托育服务，但不清楚应该向谁反映。试点区的做法是：由街道牵头对社区商业网点“摸家底”，列出缺什么；把闲置的社区用房低价租给便民业态；对早餐店、修补店等给予租金补贴；开通“便民圈”小程序，居民可以“点单”提需求。

**作答要求**：请为该市“15 分钟便民生活圈”推广工作方案拟写“主要措施”部分。要求：措施具体可行，条理清晰，不超过 350 字。
--- 要点
- 摸清底数：街道牵头排查社区商业网点，列出业态缺口清单
- 盘活空间：闲置社区用房低价租给便民业态；纠正配套商业用房挪作他用
- 政策扶持：对早餐店、修补店等给予租金补贴，稳住小店
- 补齐业态：重点补充早餐、药店、快递、养老托育等服务
- 畅通需求表达：开通小程序，居民“点单”，街道“接单”
- 分步推进、督促落实（可作为补充）
--- 参考答案
主要措施：
一、摸清底数。由街道牵头，对社区周边商业网点开展排查，形成业态缺口清单，做到“缺什么补什么”。
二、盘活空间。清理闲置社区用房，以低租金优先提供给便民业态；对新建小区配套商业用房被挪作售楼处、办公室的，限期整改，恢复便民用途。
三、扶持小店。对早餐店、修鞋配钥匙等微利业态给予租金补贴，稳住基本便民服务。
四、补齐短板。重点引进早餐店、药店、快递点和养老托育服务，满足居民日常需求。
五、畅通渠道。推广“便民圈”小程序，居民“点单”提出需求，街道“接单”跟进落实，定期公开办理情况。
六、分步推广。先在试点区总结经验，再分批在全市推开，纳入街道年度考核。
:::

## 四、工作建议 / 建议书

- **对象**：向上级或有关部门提建议；
- **结构**：标题 + 主送（“××局：”）+ 开头（简要说明问题和提建议的缘由）+ **建议事项**（分条，每条“建议 + 理由或具体做法”）+ 结尾（“以上建议，供参考。”）+ 落款；
- **语气**：谦和、务实，“建议……”“可以考虑……”。

## 五、信函：公开信、回复函

| 文种 | 要点 |
|---|---|
| **公开信 / 一封信** | 面向特定群体（“致全市家长朋友的一封信”）：称谓要亲切；说明背景 → 讲清事项（做什么、怎么做）→ 表达感谢或期望 |
| **回复函 / 答复** | 回应群众来信或询问：先感谢关注 → 逐条回应对方的问题（政策依据、目前进展、下一步打算）→ 欢迎继续监督；**问什么答什么，不能回避** |
| **慰问信** | 表达关心慰问：肯定贡献 → 表达慰问 → 提出希望 |

:::warn 回复函最常丢分的地方
没有**逐条回应**对方提出的问题。答题前先把对方的问题列出来（“一问停车难、二问噪音扰民”），答案按同样顺序一一回应。
:::

## 六、随堂练习

:::quiz 文种小测
简报的三个组成部分是：
A. 标题、正文、落款
B. 报头、报核、报尾
C. 导语、主体、结尾
D. 背景、事项、号召
答案：B
---
工作方案中要点最多、分值最高的部分通常是：
A. 标题
B. 组织领导
C. 主要措施或工作步骤
D. 落款日期
答案：C
---
写回复群众来信的答复函，最重要的是：
A. 多写套话表示重视
B. 逐条回应对方提出的问题
C. 只介绍政府的工作成绩
D. 篇幅越长越好
答案：B
---
调研报告和情况报告相比，调研报告更强调：
A. 主动调查研究、得出结论
B. 向上级请求批准
C. 号召公众行动
D. 对外宣传
答案：A
:::

调研报告四部分 :: 基本情况 → 做法成效或问题 → 原因 → 对策建议
报告的语言 :: 客观、多用数据、少用形容词
简报三部分 :: 报头、报核、报尾（报核是重点）
工作方案结构 :: 目的 → 目标 → 组织领导 → 主要措施 → 保障措施
工作建议的语气 :: 谦和务实，“建议……”
公开信 :: 背景 → 事项 → 感谢或期望，称谓亲切
回复函 :: 感谢 → 逐条回应 → 欢迎监督
