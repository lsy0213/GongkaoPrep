分析推理（讲义里也叫“排列组合”“日常推理”）给出一组人、物、位置和若干条件，问谁对应谁、谁排第几、谁一定入选。它不需要逻辑符号，但条件多、容易乱。这一课按题型讲四种方法：**代入排除、最大信息、列表、画图**。

## 一、四种方法怎么选

:::key 方法选择
- **代入排除**：选项给出**完整的对应方案**（如“甲—北京—医生”全部列出）→ 拿条件逐条排除选项，最快；
- **最大信息**：选项不完整，条件中**某个对象出现次数最多** → 从它入手；
- **列表法**：**两组或三组**对象之间的匹配（人—城市—职业）→ 画表格，确定的打 ✓，排除的打 ×；
- **画图 / 画位置**：**排序、座位、楼层**类 → 画一排格子或一个圆桌。
:::

:::tip 条件的优先级
先用**确定信息**（“E 排第 3”“甲是医生”），再用**相对信息**（“A 在 B 前面”“C、D 相邻”），最后用**假设**（只剩两种可能时，假设一种，推出矛盾就是另一种）。
:::

## 二、排序题：画格子

:::example 排队
A、B、C、D、E 五人排成一列。已知：① A 排在 B 前面（不一定相邻）；② D 紧跟在 C 后面；③ E 排在第 3 位；④ B 不排在最后。
排在最后的是谁？

A. A　B. B　C. C　D. D
--- 画格子，先放确定信息
_ _ **E** _ _
--- 处理“C、D 相邻”
C、D 必须占相邻两格，且 C 在前：只能是第 1、2 位或第 4、5 位。
--- 分情况
若 C、D 在 1、2 位，则 A、B 在 4、5 位，A 在 B 前 → B 在第 5 位，与 ④ 矛盾。
所以 C、D 在第 4、5 位，A、B 在第 1、2 位：**A B E C D**。
--- 答案
最后是 **D**，选 **D**。
:::

## 三、匹配题：列表

:::example 三组对象
甲、乙、丙三人分别来自北京、上海、广州，职业分别是医生、教师、律师（各不相同）。已知：① 甲不是北京人，也不是医生；② 医生是上海人；③ 乙不是上海人，也不是律师。
三人的职业分别是？
--- 列表
| | 北京 | 上海 | 广州 | 医生 | 教师 | 律师 |
|---|---|---|---|---|---|---|
| 甲 | × | | | × | | |
| 乙 | | × | | | | × |
| 丙 | | | | | | |
--- 用“医生是上海人”
甲不是医生，乙不是上海人（所以乙也不是医生）→ **丙是医生**，丙是上海人。
--- 继续排除
甲不是北京、不是上海 → 甲是**广州**人，乙是**北京**人。
乙不是律师、不是医生 → 乙是**教师**，甲是**律师**。
--- 答案
甲：广州、律师；乙：北京、教师；丙：上海、医生。
:::

## 四、选人题：条件翻译 + 代入

选人、安排值班这类题，常把条件写成“如果……就……”“……和……不能同时”，可以先翻译，再结合选项代入：

| 条件 | 含义 |
|---|---|
| A、B **不能都选** | 选 A → 不选 B（选 B → 不选 A） |
| 选 C **必须**选 D | C → D |
| E、F **至少选一个** | ¬E → F |
| D、F **不能同时选** | D → ¬F |

:::example 一定入选
从 A、B、C、D、E、F 六人中选 3 人。已知：① A、B 不能都选；② 选 C 必须选 D；③ E、F 至少选一个；④ D、F 不能同时选。若 A 一定入选，那么除 A 外，一定入选的还有：

A. C　B. D　C. E　D. F
--- 用 A 入选
由 ①，B 不选。还要从 C、D、E、F 中选 2 人。
--- 枚举
C 入选 → D 也入选（②），C、D 已满 2 人，E、F 都没选，违反 ③。所以 **C 不选**。
剩 D、E、F 中选 2 人：{D, F} 违反 ④；可以是 {D, E} 或 {E, F}。
--- 答案
两种方案都有 **E**，选 **C**。
:::

## 五、数量类分析推理

题干出现“**共有几个**”“**每人至少**”“**各不相同**”时，用数量关系做约束：

- **总数守恒**：5 人分 3 项任务、每项至少 1 人，只可能是 3 + 1 + 1 或 2 + 2 + 1；
- **最大最小**：几个人得分各不相同且总分固定，先算可能的最高、最低值；
- **比赛积分**：单循环赛每场分出胜负共产生 3 分（胜 3 平 1 时），总分可以反推平局数。

## 六、随堂练习

:::quiz 分析推理小测
甲、乙、丙、丁四人住在一栋四层楼里，每人一层。已知：甲住得比乙高，丙住在丁的正下方，乙不住一楼，丁不住四楼。住在一楼的是：
A. 甲
B. 乙
C. 丙
D. 丁
答案：C
解析：丙在丁正下方，丁不住四楼，所以（丙, 丁）是（1, 2）或（2, 3）。若为（2, 3），甲乙在 1、4 楼，甲比乙高 → 乙住 1 楼，与条件矛盾。所以丙 1 楼、丁 2 楼，乙 3 楼、甲 4 楼。
---
小王、小李、小张三人中，一人是教师，一人是医生，一人是工程师。已知：小王比工程师年龄大；小李和医生不同岁；医生比小张年龄小。则：
A. 小王是工程师
B. 小李是医生
C. 小张是教师
D. 小王是教师
答案：C
解析：小张不是医生（医生比小张小），小李不是医生（与医生不同岁）→ 小王是医生。小王比工程师大，又比小张小（医生比小张小）→ 小张比工程师还大，小张不是工程师 → 小张是教师，小李是工程师。
---
某单位安排周一至周五值班，每天一人，共甲、乙、丙、丁、戊五人。已知：甲在周三值班；乙在丙的前一天值班；乙不在周四值班；丁不在周一也不在周五。则戊在哪天值班？
A. 周一
B. 周二
C. 周四
D. 周五
答案：D
解析：甲占周三，乙丙要连续两天，只能是周一二或周四五；乙不在周四，所以乙周一、丙周二。剩周四、周五给丁和戊，丁不在周五 → 丁周四，戊周五。
（如果去掉“乙不在周四”，乙丙也可以在周四五，戊就可能在周一——条件不足时答案不唯一，做“一定为真”的题要检查所有情况。）
:::
