位置、样式、属性、数量都试过了还是没规律？剩下的就是这一课的内容：**图形间关系**（相交、相切、相离）、**功能元素**（小黑点、箭头在标记什么）、**黑块移动轨迹**、**汉字图形**，以及**分组分类、九宫格**这些题型结构的看法。

## 一、图形间关系

图形由两个及以上独立的图形组成、而且它们**挨在一起**时，看它们怎么“挨”：

| 关系 | 细分考法 |
|---|---|
| **相离** | 图形之间互不接触 |
| **相交** | 交于一**点**（数交点个数）；交于一条**线**（看公共边的数量、长短、曲直）；交于一个**面**（看重叠部分的形状、个数） |
| **相切** | 曲线与直线、曲线与曲线相切 |
| **内含 / 外包** | 一个图形完全在另一个里面 |

:::tip 公共边的进阶考法
公共边**数量**没规律时，看公共边是**直线还是曲线**、是**整条边还是边的一部分**、公共边在图形的**哪个位置**（上下、左右）。
:::

## 二、功能元素：小黑点、箭头、小圆圈

图形里出现一个与整体风格不搭的**小黑点、小白圈、箭头、短线**，它多半是在“**标记**”什么：

- 标记的是**交点、端点还是切点**；
- 标记在**最大面、最小面**，还是在**曲线、直线**上；
- 标记在**对称轴**上，或与对称轴的位置关系；
- 箭头指向的方向是否依次**旋转**、指向**开口**还是封闭处。

## 三、黑白块：叠加运算还是移动

:::key 先分清两类题
- 黑块**数量相同、位置不同** → **移动**；
- 黑块数量**突增突减** → **黑白叠加运算**（基础课讲的“黑 + 黑 = 白”等规则，前两个图按位置叠加得第三个）。
:::

### 黑块移动的四种轨迹

:::tabs
--- 内外圈分开跑
有明显的内圈、外圈：先把最外一圈“画出去”，看中间的黑块数量是否变化。**内部黑块数量不变 → 内外圈分开跑**（各自顺时针或逆时针移动若干格）。
--- 就近走
内部黑块数量变化，说明不是分圈跑：每个黑块**找离它最近的位置**去，可能上下、左右平移，也可能对角线移动，路径常像“旋涡”。
--- 平移
- 单纯上下移动 → **竖着看每列**黑块数不变；
- 单纯左右移动 → **横着看每行**黑块数不变；
- 走到头从另一头出来，或者拐弯。
--- 整体移动
黑块较多时，先找**能绑在一起的一组黑块**（如“F”形），这一组整体移动多少格；也可以比较首尾两图：第 1 个图转 180° 就是第 5 个图。
:::

:::tip 参照思想
移动题常有周期：第 1 个图和第 4 个图某部分位置一样，那么第 2 个和第 5 个也应一样。用它来**排除选项**最快。
:::

## 四、汉字图形

汉字题是近年省考的热门，考点几乎覆盖全部规律：

| 看到什么 | 考什么 |
|---|---|
| 有明显封闭区域（如“日”“回”“品”） | **面数** |
| 结构明显（“国”包围、“忐忑”上下、“们”左右） | **汉字结构** |
| 有独立小块（“川”“心”“三”） | **部分数** |
| 两两之间有相同部件 | **加减同异**、共同部件（如都有草字头） |
| 杂乱无章，和字母、数字混在一起 | **笔画数**（按一笔画数，而不是书写笔画） |
| 很多横、竖（“品”“下”“天”） | **横线、竖线数** |
| 十字交叉多（“丰”“井”） | **十字交叉点** |
| 其他 | 对称性、曲直性（汉字都是直线）、封闭开放；冷门：拼音字母数、含数词（一二三、个十百）、第一笔是横还是竖 |

## 五、题型结构怎么看

:::tabs
--- 一组式
五个图 + 问号：先**依次**看（逐个变化），不行看**间隔**（1、3、5 一组，2、4 一组），再看**首尾**对称。
--- 两组式
第一组三个图给出规律，第二组前两个 + 问号：规律可能是**组内相同**（每组都有某特征），也可能是**组间变化**（第二组的数量 = 第一组 + 1）。
--- 九宫格
先横看（每行规律相同），再竖看，然后对角线、“S”形、“米”字形（中心对称位置成对）；**整体看**：九个图都有某个共同特征。
--- 分组分类
六个图分成两组，每组三个：先看**属性**（对称、曲直、开闭——最快），再看**数量**，然后是**特殊规律**。选项是“①③⑤，②④⑥”这样的分法，可以用选项**代入排除**：先找最明显的两个图的共同点。
:::

:::cards 图形特征口诀（出自《判断推理 88 页》）
位置规律 :: 基本相同看位置，再看元素往哪儿走
遍历 :: 元素重复看遍历，缺啥你就补个啥
加减同异 :: 线条重复求同异，结合位置别忘记
黑白运算 :: 颜色数量不相同，轮廓相同看运算
中心对称 :: N 形 Z 形 S 形，还有平行四边形，原地旋转 180°
曲直性 :: 单一线条看曲直，曲直共存别忘记
开闭性 :: 遇到开口看开闭，全开封闭都可行
交点 :: 大树杈子非常多，别忘交点数起来
笔画 :: 端点日田领着头，交圆切圆傍地走
角 :: 折线折出多个角，横平竖直多垂直，直角数量来试试
面 :: 多个窟窿入眼帘，数面考点灵光现
素 :: 多个小图形出现，先数种类和数量，实在不行找相同
图形间关系 :: 封闭空间很明显，图形关系成考点
功能元素 :: 相同元素每图有，看看标记在哪里
黑白块 :: 位置样式行不通，对称部分数笔画，黑块面积来比较，实在不行相邻比
:::

## 六、随堂练习

:::quiz 特殊规律小测
一组图形中黑块的数量都是 3 个，只是位置不同，最先考虑：
A. 黑白叠加运算
B. 黑块移动
C. 曲直性
D. 笔画数
答案：B
解析：数量相同、位置不同 → 移动；数量突增突减才考虑叠加运算。
---
每个图形都由两个图形相交组成，公共边的数量依次为 1、1、1、1，没有变化，下一步最应该看：
A. 公共边是直线还是曲线
B. 元素种类
C. 黑白运算
D. 封闭开放
答案：A
解析：公共边数量没规律时，看公共边的曲直、长短、位置。
---
一组汉字“品、回、田、目、日”，最可能考查的是：
A. 拼音字母数
B. 面数
C. 汉字结构
D. 第一笔
答案：B
解析：这些字都有明显的封闭区域：品 3、回 2、田 4、目 3、日 2，属于“面”的图形特征。
---
六个图分成两组，最先尝试的规律通常是：
A. 黑块移动
B. 属性规律（对称、曲直、开闭）
C. 功能元素
D. 立体拼合
答案：B
解析：分组分类题先看属性，最快能区分两组。
---
每个图形中都有一个小黑点，且小黑点的位置看不出移动规律，应考虑：
A. 小黑点标记的是交点、端点还是在最大面中
B. 小黑点的数量
C. 图形的笔画数
D. 九宫格对角线
答案：A
解析：与整体风格不搭的小黑点多半是功能元素，看它“标记”了什么。
