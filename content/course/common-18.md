近现代史是常识历史题的大头：**不平等条约的内容**、**近代化探索的几次尝试**、**辛亥革命前后的人物与事件**，以及新中国的**重大建设成就**。党史部分在政治理论课已经讲过，这一课侧重 1840—1919 年的旧民主主义革命时期和新中国建设成就，并标出与四川相关的考点（保路运动、四川籍名人）。

## 一、近代中国的主线

:::key 一句话框架
1840 年鸦片战争后，中国逐步沦为**半殖民地半封建社会**；1901 年《辛丑条约》签订，标志着中国**完全**沦为半殖民地半封建社会。

面对危机，各阶级先后进行了探索：**地主阶级**（洋务运动）→ **农民阶级**（太平天国、义和团）→ **资产阶级维新派**（戊戌变法）→ **资产阶级革命派**（辛亥革命）→ **新文化运动** → 五四运动后进入**新民主主义革命**。
:::

## 二、两次鸦片战争

### 1. 第一次鸦片战争（1840—1842）

- 1839 年**林则徐虎门销烟**；林则徐被誉为“**开眼看世界的第一人**”，主持编译《四洲志》；**魏源**编《海国图志》，提出“**师夷长技以制夷**”；
- **《南京条约》**（1842 年，中英）：中国近代史上第一个不平等条约。

:::cards 《南京条约》的内容
割地 :: 割**香港岛**给英国
赔款 :: 2100 万银元
通商 :: 开放广州、厦门、福州、宁波、上海五处为通商口岸
关税 :: 英商应纳进出口货税，中国须同英国商定（协定关税）
后续附约 :: 《虎门条约》使英国取得领事裁判权、片面最惠国待遇等
:::

### 2. 第二次鸦片战争（1856—1860）

- 英法联军发动，1860 年攻入北京，**火烧圆明园**；
- 签订《天津条约》《北京条约》：《北京条约》割**九龙司地方一区**给英国；
- 沙俄趁机通过《**瑷珲条约**》《北京条约》等，割占我国东北和西北 **150 多万平方公里**领土（其中《瑷珲条约》割占黑龙江以北、外兴安岭以南 60 多万平方公里）。

## 三、近代化的探索

### 1. 太平天国运动（1851—1864）

- 1851 年**洪秀全**在广西**金田**起义，1853 年定都**天京**（南京）；
- 《**天朝田亩制度**》：以解决土地问题为中心，反映了农民对平均分配土地的渴望，但具有空想性；
- 《**资政新篇**》（**洪仁玕**）：中国近代第一个比较系统地发展资本主义的方案，未能实施；
- 1864 年天京陷落，运动失败。

### 2. 洋务运动（19 世纪 60—90 年代）

| 项目 | 内容 |
|---|---|
| 代表人物 | 中央**奕訢**；地方**曾国藩、李鸿章、左宗棠、张之洞** |
| 口号 | 前期“**自强**”（办军事工业），后期“**求富**”（办民用工业） |
| 指导思想 | “**中学为体，西学为用**” |
| 军事工业 | 安庆内军械所（第一个）、**江南制造总局**（规模最大）、福州船政局 |
| 民用工业 | 轮船招商局、开平矿务局、汉阳铁厂等 |
| 新式学堂 | **京师同文馆**（第一所新式学堂） |
| 海军 | 北洋、南洋、福建水师 |
| 失败标志 | 甲午中日战争中北洋舰队全军覆没 |

:::tip 洋务时期的边疆危机
- **左宗棠**收复新疆（1876—1878 年），**1884 年新疆建省**；
- 中法战争（1883—1885 年）：**冯子材**取得**镇南关大捷**，但清政府“不败而败”；**1885 年台湾建省**。
:::

### 3. 甲午中日战争（1894—1895）

- 黄海海战中，致远舰管带**邓世昌**壮烈殉国；威海卫战役后**北洋舰队全军覆没**；
- **《马关条约》**（1895 年）：割**辽东半岛**（后被“赎回”）、**台湾全岛及所有附属各岛屿和澎湖列岛**给日本；赔款白银 **2 亿两**；开放沙市、**重庆**、苏州、杭州为商埠；允许日本在通商口岸**开设工厂**。

### 4. 戊戌变法（1898）

- 1895 年康有为等发动“**公车上书**”；
- 1898 年 6 月 11 日光绪帝颁布“明定国是”诏书，变法持续 103 天，史称“**百日维新**”；
- 9 月 21 日慈禧发动政变，变法失败；**戊戌六君子**遇害（谭嗣同、林旭、**杨锐**、**刘光第**、杨深秀、康广仁，其中杨锐、刘光第是**四川人**）；
- 唯一保留下来的成果：**京师大学堂**（北京大学前身）。

### 5. 义和团与八国联军侵华

- 义和团提出“**扶清灭洋**”口号；
- 1900 年八国联军侵华；
- **《辛丑条约》**（1901 年）：赔款白银 **4.5 亿两**（“庚子赔款”）；划定北京东交民巷为**使馆界**，允许各国驻兵保护，不准中国人居住；**拆毁大沽炮台**，允许外国派兵驻扎北京到山海关铁路沿线要地；清政府保证**严禁人民参加反帝活动**。

:::match 条约和标志性内容
《南京条约》 :: 割香港岛，五口通商
《北京条约》（中英） :: 割九龙司地方一区
《瑷珲条约》 :: 沙俄割占黑龙江以北 60 多万平方公里
《马关条约》 :: 割台湾、澎湖，允许日本在华设厂
《辛丑条约》 :: 使馆界、驻兵，标志完全沦为半殖民地半封建社会
:::

## 四、辛亥革命与新文化运动

### 1. 辛亥革命（1911）

- 1894 年孙中山在檀香山建立**兴中会**；1905 年在东京成立**中国同盟会**，第一个全国性的资产阶级革命政党，提出“驱除鞑虏，恢复中华，创立民国，平均地权”的纲领，孙中山将其阐发为**三民主义**（民族、民权、民生），机关报《**民报**》；
- 1911 年**四川保路运动**：清政府宣布“铁路国有”出卖川汉、粤汉铁路修筑权，引发四川人民大规模保路运动，成为**武昌起义的导火线**；
- 1911 年 10 月 10 日**武昌起义**；
- 1912 年 1 月 1 日**中华民国**在南京成立，孙中山任临时大总统；3 月颁布《**中华民国临时约法**》，是中国历史上第一部资产阶级共和国性质的宪法文件；
- 意义：推翻了统治中国两千多年的**君主专制制度**，使民主共和观念深入人心；但没有改变半殖民地半封建社会的性质。

### 2. 民国初年

- 袁世凯窃取革命果实，接受日本“**二十一条**”，复辟帝制；
- **蔡锷**在云南发动**护国运动**（1915 年）；
- 孙中山发动二次革命、护法运动。

### 3. 新文化运动（1915）

- 1915 年**陈独秀**在上海创办《**青年杂志**》（后改名《新青年》），新文化运动兴起；
- 口号：提倡**民主与科学**（“德先生”和“赛先生”），反对专制和迷信；提倡新道德、反对旧道德；提倡新文学、反对旧文学；
- 代表人物：陈独秀、李大钊、**胡适**（倡导白话文，《文学改良刍议》）、**鲁迅**（1918 年《**狂人日记**》，第一篇现代白话小说）；
- 后期：李大钊《庶民的胜利》《布尔什维主义的胜利》，宣传马克思主义；
- 1919 年**五四运动**爆发，标志新民主主义革命的开端。
