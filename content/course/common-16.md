管理学和公文是常识里“小而稳”的两块：每年一两道，考法固定。管理学考的是**人名—理论**对应和几个著名定律；公文考的是 **15 种文种的用途**和**格式规则**。公文这一块还会在申论贯彻执行题、面试里反复用到，值得学扎实。

## 一、管理的职能

- **法约尔**提出管理的五大职能：**计划、组织、指挥、协调、控制**；
- 现代通常概括为四大职能：**计划、组织、领导、控制**；
- **管理幅度与管理层次成反比**：每个管理者直接管辖的人越多（幅度越大），组织层级就越少（扁平化）。

## 二、管理学理论：人名和理论对上号

| 人物 | 理论 | 一句话 |
|---|---|---|
| **泰勒** | 科学管理理论 | “**科学管理之父**”，标准化作业、计件工资 |
| **法约尔** | 一般管理理论 | “管理过程理论之父”，14 条管理原则 |
| **韦伯** | 行政组织理论（官僚制、科层制） | “**组织理论之父**” |
| **梅奥** | **霍桑实验**、人际关系学说 | 工人是“**社会人**”，非正式组织影响效率 |
| **马斯洛** | **需求层次理论** | 生理 → 安全 → 社交（归属与爱）→ 尊重 → 自我实现 |
| **赫茨伯格** | **双因素理论** | **保健因素**（工资、工作条件）只能消除不满；**激励因素**（成就、认可、责任）才能带来满意 |
| **麦格雷戈** | **X 理论—Y 理论** | X：人天生懒惰，需要强制；Y：人愿意承担责任，需要激发 |
| **弗鲁姆** | **期望理论** | 激励力 = 效价 × 期望值 |
| **亚当斯** | **公平理论** | 人们会把自己的付出—回报比与他人比较 |
| **德鲁克** | **目标管理** | “现代管理学之父” |
| **西蒙** | 决策理论 | “**管理就是决策**”，有限理性 |
| **勒温** | 领导风格理论 | 专制型、民主型、放任型 |

:::order 马斯洛需求层次（由低到高）
- 生理需求
- 安全需求
- 社交需求（归属与爱）
- 尊重需求
- 自我实现需求
:::

:::reveal 想一想：属于保健因素还是激励因素？
1. 提高工资  2. 改善办公环境  3. 给予晋升机会  4. 公开表彰  5. 完善规章制度
---
保健因素：1、2、5（与工作环境、条件有关，只能防止不满）；
激励因素：3、4（与工作内容本身、成就和认可有关，能产生满意）。
:::

:::cards 管理学定律
彼得原理 :: 在层级组织中，每个员工都趋向于晋升到他不能胜任的职位
帕金森定律 :: 机构会不断膨胀，人员增加，效率下降（人浮于事）
墨菲定律 :: 凡是可能出错的事，最终都会出错
霍桑效应 :: 当人们知道自己被关注、被观察时，会改变行为表现
鲶鱼效应 :: 引入外来竞争者激发内部活力
破窗效应 :: 环境中的不良现象被放任，会诱使人们仿效
木桶效应 :: 整体水平取决于最短的那块板
蘑菇定律 :: 新人往往被放在不受重视的部门，自生自灭
马太效应 :: 强者愈强，弱者愈弱
皮格马利翁效应 :: 期望和赞美能产生奇迹（期望效应）
SWOT 分析 :: 优势（S）、劣势（W）、机会（O）、威胁（T），用于战略分析
波特五力模型 :: 现有竞争者、潜在进入者、替代品、供应商议价能力、购买者议价能力

## 三、公文：15 种法定文种

依据《**党政机关公文处理工作条例**》（2012 年 7 月 1 日起施行），党政机关公文共 **15 种**：

**决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。**

| 文种 | 用途 | 行文方向 |
|---|---|---|
| 决议 | **会议讨论通过**的重大决策事项 | 下行 |
| 决定 | 对重要事项作出决策和部署、奖惩有关单位和人员、变更或撤销下级机关不适当的决定事项 | 下行 |
| 命令（令） | 公布行政法规和规章、宣布施行重大强制性措施、批准授予和晋升衔级、嘉奖有关单位和人员 | 下行 |
| 公报 | 公布重要决定或者重大事项 | 下行（对外公布） |
| **公告** | 向**国内外**宣布重要事项或者法定事项 | 下行（对外） |
| **通告** | 在**一定范围内**公布应当遵守或者周知的事项 | 下行 |
| 意见 | 对重要问题提出见解和处理办法 | **上行、下行、平行均可** |
| 通知 | 发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文 | 下行（也可平行） |
| **通报** | **表彰先进、批评错误、传达重要精神和告知重要情况** | 下行 |
| **报告** | 向上级机关汇报工作、反映情况，回复上级机关的询问 | 上行 |
| **请示** | 向上级机关请求指示、批准 | 上行 |
| 批复 | 答复下级机关请示事项 | 下行 |
| 议案 | 各级人民政府按照法律程序向**同级人大或人大常委会**提请审议事项 | 上行（特殊） |
| **函** | **不相隶属机关之间**商洽工作、询问和答复问题、请求批准和答复审批事项 | 平行 |
| 纪要 | 记载会议主要情况和议定事项 | 多向 |

:::warn 五组最易混的文种
- **公告 vs 通告**：公告面向国内外、事项重大；通告在一定范围内、要求遵守或周知（如交通管制通告）；
- **请示 vs 报告**：请示**事前**行文、需要批复、**一文一事**；报告事中或事后、**不需要批复**，报告中**不得夹带请示事项**；
- **通知 vs 通报**：通知要求“办什么”；通报是“表扬谁、批评谁、告知什么情况”；
- **决议 vs 决定**：决议必须经**会议讨论通过**；决定可以由领导机关直接作出；
- **函**：向**不相隶属**的主管部门请求批准，用“函”而不是“请示”。例如某县教育局向县财政局申请经费，应当用**函**。
:::

:::example 选对文种
1. 某市政府拟向市人大常委会提请审议一项地方性法规草案；
2. 某区公安分局决定某路段实行临时交通管制，需告知社会公众；
3. 某县政府办公室对在防汛中表现突出的单位进行表扬；
4. 某乡政府向县政府申请拨付灾后重建资金。
--- 判断
1. 政府向同级人大常委会提请审议 → **议案**；
2. 在一定范围内公布应当遵守的事项 → **通告**；
3. 表彰先进 → **通报**；
4. 向有隶属关系的上级请求批准 → **请示**。
:::

## 四、公文格式与行文规则

### 1. 公文格式三部分

- **版头**：份号、密级和保密期限、紧急程度、**发文机关标志**、**发文字号**、签发人（上行文才标）；
- **主体**：标题、主送机关、正文、附件说明、发文机关署名、**成文日期**、印章、附注、附件；
- **版记**：抄送机关、印发机关和印发日期。

:::key 格式里的高频细节
- 公文用纸为 **A4**；一般每面排 **22 行**、每行排 **28 个字**；
- 标题一般用 **2 号小标宋体**，正文用 **3 号仿宋体**；
- 发文字号由**发文机关代字、年份、发文顺序号**组成，如“国发〔2026〕5 号”：年份用**六角括号**〔〕，序号**不编虚位**（写 5 不写 05）、**不加“第”字**；
- 成文日期用**阿拉伯数字**将年、月、日标全（如 2026 年 3 月 12 日），以负责人签发的日期为准；
- 正文结构层次序数依次为：**“一、”“（一）”“1.”“（1）”**。
:::

### 2. 行文规则

- 行文应当确有必要、讲求实效、注重针对性和可操作性；
- 一般不得**越级行文**，特殊情况需要越级行文的，应当同时**抄送被越过的机关**；
- **请示**应当一文一事，一般只写**一个主送机关**，需要同时送其他机关的应当用抄送形式，但**不得抄送其下级机关**；
- 除上级机关负责人直接交办事项外，不得以本机关名义向上级机关负责人报送公文，不得以本机关负责人名义向上级机关报送公文；
- 党委、政府的部门依据职权可以相互行文；部门内设机构除办公厅（室）外不得对外正式行文。

:::order 正文的结构层次序数
- 一、
- （一）
- 1.
- （1）
:::
