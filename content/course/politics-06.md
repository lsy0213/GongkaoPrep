这一课讲马克思主义哲学的后两块——**认识论**和**唯物史观**，再梳理党史上最常考的会议节点。

## 一、认识论：实践和认识

:::key 实践对认识的决定作用
实践是认识的**来源**、认识发展的**动力**、检验认识真理性的**唯一标准**、认识的**目的**。
:::

- “纸上得来终觉浅，绝知此事要躬行” → 实践是认识的来源；
- “不登高山，不知天之高也” → 实践出真知；
- “实践是检验真理的唯一标准” → 1978 年真理标准问题大讨论；
- 认识过程：**感性认识 → 理性认识**（第一次飞跃）→ **理性认识 → 实践**（第二次飞跃，意义更重大）；
- 认识具有反复性、无限性、上升性；
- 真理具有**客观性**、**具体性**（具体的、有条件的）、**绝对性和相对性**的统一。

:::tip 诗句里的认识论
- “不识庐山真面目，只缘身在此山中”：认识受主体所处位置的局限；
- “横看成岭侧成峰”：认识具有多样性，从不同角度看事物结果不同；
- “问渠那得清如许，为有源头活水来”：实践（或读书学习）是认识的源泉。
:::

## 二、唯物史观

| 原理 | 内容 |
|---|---|
| 社会存在和社会意识 | 社会存在决定社会意识，社会意识对社会存在有反作用，且具有相对独立性 |
| 生产力和生产关系 | 生产力决定生产关系，生产关系反作用于生产力（适合则促进，不适合则阻碍） |
| 经济基础和上层建筑 | 经济基础决定上层建筑，上层建筑反作用于经济基础 |
| 人民群众的作用 | 人民群众是历史的创造者，是物质财富、精神财富的创造者，是社会变革的决定力量 |
| 人生价值 | 价值在于对社会的责任和贡献；评价人生价值主要看贡献 |

:::cards 记忆卡
社会基本矛盾 :: 生产力和生产关系、经济基础和上层建筑之间的矛盾
人类社会的基础 :: 物质资料的生产方式
历史的创造者 :: 人民群众
生产力中最活跃的因素 :: 劳动者（人）
“仓廪实而知礼节” :: 社会存在决定社会意识
:::

:::tabs
--- 新民主主义革命时期
| 时间 | 会议或事件 | 意义 |
|---|---|---|
| 1921.7 | 中共一大（上海—嘉兴南湖） | 中国共产党成立 |

| 1927.8 | 八七会议 | 确定土地革命和武装反抗国民党反动派的总方针，“枪杆子里面出政权” |
| 1927.9 | 三湾改编 | “支部建在连上”，党对军队绝对领导的开端 |
| 1929.12 | 古田会议 | 思想建党、政治建军 |
| 1935.1 | 遵义会议 | 党的历史上生死攸关的转折点 |
| 1938 | 六届六中全会 | 毛泽东提出“马克思主义中国化”的命题 |
| 1945 | 中共七大 | 确立毛泽东思想为党的指导思想 |
| 1949.3 | 七届二中全会 | “两个务必”（谦虚谨慎、不骄不躁；艰苦奋斗） |
--- 社会主义革命和建设时期
| 时间 | 会议或事件 | 意义 |
|---|---|---|
| 1954 | 一届全国人大一次会议 | 通过第一部《中华人民共和国宪法》 |
| 1956 | 三大改造基本完成 | 社会主义基本制度确立 |
| 1956 | 中共八大 | 指出国内主要矛盾已经是人民对于经济文化迅速发展的需要同当前经济文化不能满足人民需要的状况之间的矛盾 |
| 1964—1965 | 三届全国人大一次会议 | 正式提出“四个现代化”宏伟目标 |
--- 改革开放和新时代
| 时间 | 会议或事件 | 意义 |
|---|---|---|
| 1978.12 | 十一届三中全会 | 伟大转折，开启改革开放和社会主义现代化建设新时期 |
| 1987 | 中共十三大 | 系统阐述社会主义初级阶段理论，提出“一个中心、两个基本点” |
| 1992 | 南方谈话、中共十四大 | 确立建立社会主义市场经济体制的改革目标 |
| 1997 | 中共十五大 | 邓小平理论写入党章 |
| 2002 | 中共十六大 | “三个代表”重要思想写入党章 |
| 2007 | 中共十七大 | 科学发展观写入党章 |
| 2012 | 中共十八大 | 中国特色社会主义进入新时代的起点 |
| 2017 | 中共十九大 | 新思想写入党章，作出“中国特色社会主义进入新时代”的重大政治论断 |
| 2021 | 十九届六中全会 | 通过党的第三个历史决议 |
| 2022 | 中共二十大 | 系统阐述中国式现代化 |
