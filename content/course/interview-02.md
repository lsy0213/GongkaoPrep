综合分析题几乎每场面试必考，往往是第一题。它考的是**看问题的深度和角度**：你能不能把一个现象、一项政策、一句话讲清楚、讲透彻。

## 一、四种类型

| 类型 | 例子 |
|---|---|
| 社会现象 | “有的年轻人选择‘反向旅游’，避开热门景点去小城市，你怎么看？” |
| 政策理解 | “很多地方推行‘高效办成一件事’，你怎么理解？” |
| 名言观点 | “有人说‘基层是最好的课堂’，谈谈你的理解。” |
| 漫画哲理 | 描述一幅漫画或一个寓言，谈启示 |

## 二、万能框架：观点 → 分析 → 落实

:::key 三步答题
1. **亮观点**（30 秒）：一句话表明态度或点明本质。正面现象表示肯定，负面现象表示担忧，有争议的辩证看待；
2. **多角度分析**（1.5 分钟）：原因、意义、影响、问题，用“一方面……另一方面……”或“从政府看、从社会看、从个人看”展开，**要有具体例子**；
3. **谈落实**（1 分钟）：怎么办，最后**结合自己报考的岗位**说一句。
:::

:::tip 让分析有深度的角度
- **主体角度**：政府、企业、社会组织、群众个人；
- **领域角度**：经济、政治、文化、社会、生态；
- **时间角度**：过去为什么这样、现在怎么样、未来怎么办；
- **辩证角度**：好处是什么，可能的问题是什么。
:::

## 三、开口练

:::speak 综合分析（社会现象）
近年来，不少年轻人选择“反向旅游”——避开热门景区，去一些小众的县城、乡村旅游。对此你怎么看？
--- 参考思路
**观点**：“反向旅游”体现了年轻人追求个性化、高性价比旅行的新需求，也为小城镇带来了发展机遇，值得肯定，同时也要看到需要补齐的短板。

**分析**：
- 原因：热门景区人多、价格高、体验差；年轻人更看重松弛感和独特体验；社交媒体让小众目的地被看见；
- 意义：分流热门景区压力；带动县城、乡村的消费和就业，助力乡村振兴；推动旅游业多元化发展；
- 问题：一些小众地方接待能力不足，交通、住宿、卫生等配套跟不上；“一夜爆红”后容易出现宰客、过度开发。

**落实**：地方政府要抓住机遇，完善交通、住宿等配套设施，挖掘本地文化特色，加强市场监管，让游客“来了还想再来”；游客也要文明出游、尊重当地风俗。

**结合岗位**：如果我有幸成为一名基层工作人员，会积极关注本地的文旅资源，做好服务和监管工作。
:::

:::speak 综合分析（名言观点）
有人说：“基层是最好的课堂，群众是最好的老师。”谈谈你的理解。
--- 参考思路
**观点**：这句话道出了年轻干部成长的规律：只有扎根基层、向群众学习，才能真正增长才干。

**分析**：
- 为什么基层是课堂：基层直接面对群众，问题最真实、最复杂，能锻炼解决实际问题的能力；
- 为什么群众是老师：群众中蕴藏着丰富的经验和智慧，很多好办法来自群众的创造；
- 反面看：一些干部“坐办公室、拍脑袋”，政策脱离实际，群众不满意。

**落实**：作为即将走上工作岗位的年轻人，我会主动到一线去，多听群众意见、多向老同志请教，把书本知识和实践结合起来，在基层这所大学校里磨炼本领。
:::

:::quiz 小测
回答综合分析题，第一步应该：
A. 先讲一个长故事
B. 一句话亮明观点
C. 先背诵相关政策文件
D. 先说“这个问题很难”
答案：B
---
下列哪种分析方式更有深度？
A. “这个现象很好，我很支持。”
B. 从原因、意义、存在的问题三个方面展开，并举具体例子
C. 反复强调这个现象的重要性
D. 只说自己的个人经历
答案：B
:::

:::cards 本课记忆卡
综合分析题框架 :: 亮观点 → 多角度分析 → 谈落实（结合岗位）
分析的角度 :: 主体（政府、企业、社会、个人）、领域、时间、辩证
负面现象怎么表态 :: 表示担忧，分析危害和原因，提出解决办法
有争议的现象 :: 辩证看待，既看到积极面也看到问题
:::
