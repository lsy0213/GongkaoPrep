教程课文格式说明
================

每一课是一个 Markdown 文件：content/course/<课 id>.md，课程目录在 index.json。
正文支持：## 小标题、**加粗**、==高亮==、`代码`、表格、列表、> 引用、[链接](#/practice)。
互动块用“:::类型 参数”开头、单独一行“:::”结尾，块里不能再嵌套块。

:::tip 标题        提示框（绿色：技巧）。还有 warn（红：易错）、key（黄：要记住）、note（蓝：说明）
正文（Markdown）
:::

:::quiz 标题       随堂测验。多道题用一行“---”隔开；答案写多个字母就是多选
题干
A. 选项
B. 选项
答案：B
解析：……（可多行）
:::

:::example 标题    分步例题。第一段是题目，之后每段是一步，“--- 步骤名”
题目
--- 第一步：……
内容
--- 答案
内容
:::

:::reveal 按钮文字  想一想。“---”前是问题，后是答案（只有一段时整段都是答案）

:::cards 标题      记忆卡，每行“正面 :: 背面”。学完本课后自动进入“教程知识卡”卡组

:::fill 标题       填空。答案写成 [[答案]]，多个可接受答案用 | 隔开：[[十八|18]]

:::order 标题      排序。按正确顺序写“- 选项”，可以在最后加一行“解析：……”

:::match 标题      连线。每行“左 :: 右”

:::drill 类型 | 题数   速算小练。类型：mul div base inc share frac（与速算训练相同）

:::calc 名称       计算器：growth annual interval share average perm score

:::practice 模块 | 题型 | 题数 | 来源   真题演练。题型写“全部”表示不限；来源可省略（all / 国考 / 四川 / 千题册）
一句说明（可省略）
:::

:::write 标题 | 字数 | 分值   申论动笔写。第一段是材料和题目，“--- 要点”下面写“- 要点”，“--- 参考答案”下面写示范
:::speak 题型      面试开口练。第一段是题目，之后“--- 参考思路”
:::check 标题      清单，每行“- 事项”，勾选状态会保存
:::flow 标题       流程步骤条，每行“步骤 :: 说明”
:::tabs 标题       标签页，每个标签以“--- 标签名”开头
:::figure 说明     插图，内容为 SVG 原样输出（颜色用 currentColor 或 var(--ink) 等主题变量，深色模式才看得清）

知识导图
========

每门课一张导图：content/course/maps/<课程 id>.txt；总导图是 maps/all.txt。显示在教程首页入口、课程页底部和 #/learn/map。
第一行“# 标题”是根节点，下面每行“- 节点”，每深一级多缩进两个空格。
节点末尾写“@课 id”（如 @math-03）链接到那一课；总导图里写“@课程 id”（如 @math）链接到那门课的导图。
每门课的每一课都要在它的导图里至少链接一次；改完运行 python tools/check_course.py 检查。

本课思维导图：每节课一张 maps/lessons/<课 id>.txt，写法同上（第一行标题会被换成课名，可以随便写）。显示在课文开头，可收起。
一级节点尽量用课文 ## 小标题的原文（不带“一、”序号；括号里的内容和冒号后半截可以省略），这样点节点后的 → 能跳到那一节。
新增一课时，可以先运行 python tools/draft_lesson_maps.py <课 id> 按课文起草一张草稿（只建不存在的文件），再手工删改精炼。
