## 二、古代政治制度的演变

| 朝代 | 制度 | 意义 |
|---|---|---|
| 西周 | 分封制、宗法制 | 以血缘为纽带 |
| 秦 | 皇帝制度、三公九卿、**郡县制**；统一文字、货币、度量衡 | 中央集权的开端 |
| 汉 | 汉武帝“罢黜百家，独尊儒术”，颁布推恩令；刺史制度 | 儒学成为正统 |
| 隋 | **科举制**创立（隋炀帝设进士科） | 打破门第选官 |
| 唐 | **三省六部制**（中书省起草、门下省审议、尚书省执行） | 相权分割 |
| 宋 | 重文轻武，加强中央集权 | |
| 元 | **行省制度** | 今天省级行政区的源头 |
| 明 | 废丞相，设内阁；八股取士 | 君主专制加强 |
| 清 | 雍正设**军机处** | 君主专制达到顶峰 |

## 三、古代科技与文化成就

:::cards 四大发明与科技
造纸术 :: 西汉已有，东汉蔡伦改进
印刷术 :: 唐代雕版印刷；北宋毕昇发明活字印刷
火药 :: 唐代用于军事
指南针 :: 战国“司南”；北宋用于航海
《九章算术》 :: 汉代数学著作
祖冲之 :: 南北朝，把圆周率精确到小数点后第七位
《齐民要术》 :: 北魏贾思勰，现存最早最完整的农书
《本草纲目》 :: 明代李时珍，药物学巨著
《天工开物》 :: 明代宋应星，被誉为“中国 17 世纪的工艺百科全书”
张衡 :: 东汉，发明地动仪
:::

:::tip 丝绸之路与对外交流
- 西汉**张骞**出使西域，开辟丝绸之路；
- 唐代玄奘西行求法、鉴真东渡日本；
- 明代**郑和下西洋**（1405—1433 年，七次），最远到达非洲东海岸和红海沿岸。
:::

## 五、世界史要点

- **文艺复兴**（14—16 世纪，发源于意大利）：人文主义，代表人物但丁、达·芬奇、米开朗基罗、莎士比亚；
- **新航路开辟**：1492 年哥伦布到达美洲；麦哲伦船队完成环球航行；
- **英国资产阶级革命**（1640 年开始），1689 年《权利法案》确立君主立宪制；
- **美国独立战争**（1775 年），1776 年《独立宣言》；
- **法国大革命**（1789 年），《人权宣言》；
- **第一次工业革命**（18 世纪 60 年代，英国）：瓦特改良蒸汽机，人类进入“蒸汽时代”；
- **第二次工业革命**（19 世纪 70 年代）：电力广泛应用，进入“电气时代”；
- 第一次世界大战 1914—1918 年，第二次世界大战 1939—1945 年。
