# 面试
- 形式、评分与礼仪 @interview-01
  - 结构化面试：一般 3—4 题、15—20 分钟
  - 评分要素
    - 综合分析、计划组织协调、应急应变、人际交往
    - 言语表达、情绪控制、求职动机与职位匹配、举止仪表
  - 礼仪：深色正装；问好不透露姓名；坐椅子 2/3；答完说“回答完毕”
- 综合分析
  - 万能框架 @interview-02
    - 亮观点 → 多角度分析 → 谈落实（结合岗位）
    - 正面肯定、负面担忧、争议辩证
    - 分析角度：主体、领域、时间、辩证
  - 政策理解 @interview-08
    - 表态概括 → 讲意义 → 落实中的问题 → 落实措施
    - 误区：只唱赞歌；否定政策本身
  - 名言哲理 @interview-08
    - 解释含义 → 正面论证 → 反面论证 → 联系自身
  - 漫画寓言 @interview-08
    - 描述画面 → 揭示寓意 → 分析 → 对策启示
- 组织计划
  - 框架 @interview-03
    - 目的 → 准备 → 实施（重点）→ 总结
    - 针对性：先分析对象特点和需求
    - 实施环节：做什么、怎么做、为什么，设计亮点
  - 逐类练 @interview-09
    - 得分点：针对性 > 可操作性 > 完整性
    - 调研：问卷 + 座谈 + 实地走访 + 查阅资料
    - 宣传：分对象、选渠道、做通俗内容、看效果
    - 会议：会前准备、会中控制议程、会后纪要落实
    - 培训：训前需求调查、训中互动实操、训后考核反馈
- 人际关系 @interview-04
  - 四原则：工作为重、尊重理解、主动沟通、反思自身
  - 框架：态度 → 分析（先找自身原因）→ 解决 → 总结
  - 与领导意见不一致：私下委婉提，先执行再反馈
  - 亲友请托违规：坚守原则，提供合法帮助
- 应急应变 @interview-05
  - 原则：稳定情绪、控制局面；人身安全第一；及时汇报；事后总结
  - 五字框架：稳 → 分 → 解 → 报 → 总
  - 措施具体到动作，不说空话
- 情景模拟与自我认知 @interview-06
  - 情景模拟：直接进入角色，用“您”说话
  - 四步：共情 → 讲道理 → 给办法 → 结尾
  - 报考动机：个人经历 + 岗位认识 + 匹配点 + 决心
  - 说缺点：真实但不致命，说明怎样改进
- 小组面试 @interview-10
  - 无领导小组：阅读 → 个人陈述 → 自由讨论 → 总结陈词
  - 排序题先统一标准
  - 反对意见对事不对人
  - 结构化小组：轮流作答 → 互相点评 → 回应
  - 点评三句式：先肯定 → 再补充 → 表示学习
- 表达与心态 @interview-07
  - 语速每分钟 180—220 字；每题 2.5—3.5 分钟
  - 结构词：第一、第二；一方面、另一方面
  - 草稿只写关键词和框架
  - 遇到不会的题：请求思考片刻，从熟悉的角度分析
  - 练法：计时答题 + 录音回听 + 定期模拟
