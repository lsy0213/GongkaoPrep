# 资料分析
- 核心概念 @data-01
  - 增长
    - 基期 = 现期 ÷ (1 + r)
    - 增长量 = 现期 − 基期 = 现期 × r ÷ (1 + r)
    - 同比（上年同期）vs 环比（上一统计周期）
    - 百分点：两个百分数之差
  - 比重、倍数、平均数
    - A 比 B 多几倍 = A ÷ B − 1
  - 拉动增长 = 部分增长量 ÷ 整体基期量
  - 贡献率 = 部分增长量 ÷ 整体增长量
- 速算技巧
  - 截位直除 @data-02
    - 选项首位不同截 2 位；首位相同第二位不同截 3 位
    - 截位时四舍五入
  - 百化分 @data-02
    - 1/6 = 16.7%、1/7 = 14.3%、1/8 = 12.5%、1/9 = 11.1%
    - 1/11 = 9.1%、1/12 = 8.3%、1/13 = 7.7%
    - 增长量 n+1 法：r ≈ 1/n 时，增长量 = 现期 ÷ (n + 1)
  - 分数比较 @data-03
    - 一大一小：分子大、分母小的大
    - 同大同小：比较分子分母的增幅
    - 差分法
  - 估算 @data-03
    - r 很小时：现期 ÷ (1 + r) ≈ 现期 × (1 − r)
    - 选项差距大于 5% 大胆估算
    - × 1.05 = A + A ÷ 20
- 增长类
  - 基础计算 @data-04
    - 增长量比较：大大则大
    - 年均增长率：总增长率 ÷ n 偏大
    - 混合增长率介于两部分之间，偏向基期量大的一方
  - 间隔增长 @data-08
    - 间隔增长率 r = r₁ + r₂ + r₁ × r₂ @data-04
    - 间隔基期 = 现期 ÷ (1 + r)
  - 混合增长反求 @data-08
    - 十字交叉：基期量之比 = (r − b)∶(a − r)
  - 年均增长 @data-08
    - “A 年—B 年”的 n = B − A
    - 五年规划期间：以规划前一年为基期，n = 5
    - 1.07⁵ ≈ 1.40、1.08⁵ ≈ 1.47、1.1⁵ ≈ 1.61
  - 乘积增长率 @data-08
    - A = B × C → a = b + c + bc
    - 相除的量：(b − c) ÷ (1 + c)
  - 现期预测 @data-08
    - 保持增长率：现期 × (1 + r)ⁿ
    - 保持增长量：现期 + n × 增长量
- 比重、平均数、倍数
  - 比重 @data-05
    - 升降：部分增速 a > 整体增速 b 则上升
    - 变化幅度一定小于 |a − b|
  - 基期值 @data-09
    - 基期比重 / 平均数 / 倍数 = 现期值 × (1 + b) ÷ (1 + a)
    - a > b 时修正系数小于 1，基期比现期小
  - 两期比重 @data-09
    - 变化量 = 现期比重 × (a − b) ÷ (1 + a)
    - 负增长仍比较 a、b 大小
  - 平均数 @data-09
    - “A 的平均 B” = B ÷ A
    - 平均数增长率 = (a − b) ÷ (1 + b) @data-05
  - 倍数 @data-09
    - 倍数变化：a > b 时变大
- 统计术语 @data-10
  - 三次产业：第二产业含采矿、制造、电热燃气水、建筑业
  - 增加值 = 总产出 − 中间投入
  - 拉动 = 贡献率 × 整体增长率
  - 价格指数：CPI 102.3 = 上涨 2.3%；定基可跨年比，同比不可
  - PMI 荣枯线 50%
  - 规模以上工业企业：年主营业务收入 2000 万元及以上
  - 翻 n 番 = 2ⁿ 倍；三成 = 30%
- 读材料与做题 @data-06
  - 每篇约 5 分钟，读材料不超过 40 秒 @data-11
  - 文字材料：扫段首，圈时间、指标、单位
  - 表格：标题、单位、表头、注释；图形：横纵轴、图例 @data-11
  - 先易后难，综合分析题放最后
  - 一题 2 分钟没结果就跳
- 整套材料演练 @data-11
  - 先判断问的是哪类量，再定公式
  - 只给增速、不给总量，不能比较总量大小
  - 增长量最多 ≠ 增速最快
- 常见陷阱 @data-07
  - 时间陷阱：材料 2024 年问 2022 年，用间隔增长率
  - 单位陷阱：1 亿 = 10000 万
  - 问法陷阱
    - “增加最多”比增长量，“增长最快”比增长率
    - “是几倍”A ÷ B，“多几倍”A ÷ B − 1
    - “提高了多少”是百分点
  - 主体陷阱：看清统计口径和对象
  - 负增长的基期比现期大
