# 三大方法：代入排除、数字特性、方程
- 代入排除
  - 条件多、列式麻烦、选项是具体数值时用
  - 年龄、人数、多位数、余数、不定方程
  - 问最大从大选项代，问最小从小选项代
- 数字特性
  - 奇偶特性
    - a + b 与 a − b 奇偶相同
    - 不定方程：7x + 4y = 52 → x 是偶数
  - 倍数特性
    - a∶b = m∶n → a + b 是 m + n 的倍数
    - 整除判定：3、9 看各位和；4 看末两位
  - 尾数特性
    - 选项尾数不同时只算尾数
- 方程法
  - 问什么设什么
  - 麻烦时设中间量（每份、效率、单价）
  - 有比例设每份为 x
