# 增长进阶：间隔、混合、年均、乘积增长与现期预测
- 间隔增长率进阶
  - 间隔增长率 r = r₁ + r₂ + r₁r₂
  - 间隔基期 = 现期 ÷ (1 + r)
  - 间隔增长量 = 现期 × r ÷ (1 + r)
  - 负增长时乘积项变号
  - 两个增速都在 10% 以内可先忽略乘积项
- 混合增长率进阶
  - 十字交叉：基期量之比 = (r − b)∶(a − r)
  - 混合的是基期量，不是现期量
- 年均增长
  - n 怎么数
    - “2020 年到 2024 年”：n = 4
    - 五年规划期间：以规划前一年为基期，n = 5
  - 年均增长率怎么估
    - 1.05⁵ ≈ 1.28、1.07⁵ ≈ 1.40
    - 1.08⁵ ≈ 1.47、1.1⁵ ≈ 1.61
  - 年均增长量
    - (末期 − 初期) ÷ n
- 乘积增长率
  - A = B × C → a = b + c + bc
  - 相除的量：(b − c) ÷ (1 + c)
- 现期预测与追赶
  - 保持增长率：现期 × (1 + r)ⁿ
  - 保持增长量：现期 + n × 增长量
  - 追赶：差距 ÷ 每年增长量之差
