# 行程进阶：流水、扶梯、火车过桥、多次相遇与环形
- 流水行船进阶
  - 漂流物速度 = 水速
  - 同河两船相遇或追及：水速抵消
- 扶梯问题
  - 顺行：级数 = (人速 + 梯速) × 时间
  - 逆行：级数 = (人速 − 梯速) × 时间
- 火车过桥与错车
  - 过桥：桥长 + 车长；完全在桥上：桥长 − 车长
  - 错车：车长和 = 速度和 × 时间
  - 超车：车长和 = 速度差 × 时间
  - 经过站着的人：路程 = 车长
- 直线多次相遇
  - 两端出发
    - 第 n 次相遇共走 (2n − 1) 个全程
    - 全程 = 3d₁ − d₂（第二次距 B 地）
    - 单岸型：(3d₁ + d₂) ÷ 2
  - 同端出发
    - 第 n 次迎面相遇共走 2n 个全程
- 环形跑道多次相遇
  - 反向：第 n 次相遇合走 n 圈
  - 同向：第 n 次追上多跑 n 圈
