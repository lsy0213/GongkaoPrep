# 逻辑判断①：翻译推理
- 翻译规则
  - 如果 A 那么 B、只要 A 就 B、所有 A 是 B：A → B
  - 只有 A 才 B：B → A
  - 除非 A 否则不 B：B → A
  - 必要条件放箭头后，充分条件放箭头前
- 推理规则
  - 肯前必肯后，否后必否前
  - 否前、肯后推不出
  - 逆否等价：A → B = ¬B → ¬A
- 且、或、德摩根
  - 或：至少一个；要么……要么：有且只有一个
  - ¬(A 且 B) = ¬A 或 ¬B
  - ¬(A 或 B) = ¬A 且 ¬B
  - A → B = ¬A 或 B
- 递推
  - 把条件首尾相接串起来
