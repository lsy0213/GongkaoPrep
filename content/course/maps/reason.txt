# 判断推理
- 图形推理
  - 第一眼判断 @reason-01
    - 元素组成相同 → 位置规律
    - 元素组成相似 → 样式规律
    - 元素组成不同 → 属性或数量规律
    - 九宫格：先横后竖，再看对角线、S 形
  - 位置规律 @reason-01
    - 平移、旋转、翻转
  - 样式规律 @reason-01
    - 叠加：直接叠加、去同存异、去异存同、黑白运算
    - 遍历：元素重复看遍历，缺啥补啥
  - 属性规律 @reason-02
    - 对称性：轴对称、中心对称（N、Z、S 形）
    - 曲直性、开闭性
  - 数量规律 @reason-02
    - 点：交点（顶点、切点算，端点不算） @reason-09
    - 线：直线、曲线、横竖线分开数 @reason-09
    - 笔画：奇点数为 0 或 2 可一笔画；笔画数 = 奇点数 ÷ 2
    - 面：封闭区域；最大面形状、边数 @reason-09
    - 角：多折线、五角星、直角 @reason-09
    - 素：元素种类、个数、部分数 @reason-09
  - 特殊规律 @reason-10
    - 图形间关系：相离、相交（点、线、面）、相切、内含
    - 功能元素：小黑点、箭头标记的位置
    - 黑白块：数量不变看移动，数量突变看叠加运算
    - 汉字图形：面、结构、部分、笔画
    - 题型结构：一组式、九宫格、分组分类
  - 空间重构 @reason-03
    - 相对面：同行或同列隔一个；Z 字形两端
    - 相对面不能同时看到、不能相邻
    - 时针法：公共点三个面的顺时针顺序要一致
    - 画边法：特殊面的特殊边顺时针编号 @reason-11
    - 四面体没有相对面，靠公共边和公共点 @reason-11
  - 截面、三视图与立体拼合 @reason-11
    - 正方体截面最多六边形，三角形只能是锐角三角形
    - 圆柱截面没有三角形；球的截面只能是圆
    - 三视图：长对正、高平齐、宽相等
    - 数小方块：俯视图定位置，主视、左视定高度
    - 立体拼合：先数块数；零件能旋转不能镜像
- 定义判断
  - 三步法 @reason-04
    - 读问法 → 拆要件 → 逐项比对
    - 关键要素：主体、客体、方式、目的、原因条件、结果
    - 最大误区：用常识代替定义
  - 陷阱与多定义 @reason-12
    - 必须标出的小词：主观、范围、方式、结果、否定
    - 主体偷换；同构选项同对同错
    - “不属于”题：先找出三个符合的
    - 多定义：问哪个读哪个
    - 高频定义：德西效应、罗森塔尔效应、晕轮效应、登门槛效应
- 类比推理
  - 词语关系与造句 @reason-05
    - 逻辑关系：全同、种属、组成、交叉、矛盾、反对
    - 语义关系：近义、反义、象征比喻
    - 对应关系：功能、材料、工具对象、职业场所、因果、时间先后
    - 语法关系：主谓、动宾、偏正
    - 核心方法：造句，把选项代进同一句话
  - 二级辨析与常识类比 @reason-13
    - 必然 / 或然、主要 / 次要、直接 / 间接
    - 人为 / 自然、同一主体 / 不同主体、物理 / 化学变化
    - 最后看褒贬、词性、结构
    - 常识类比：作品作者、典故人物、物理单位
- 逻辑判断
  - 翻译推理 @reason-06
    - 如果 A 就 B：A → B；只有 A 才 B：B → A
    - 肯前必肯后，否后必否前；否前、肯后推不出
    - 逆否等价：A → B = ¬B → ¬A
    - 德摩根：¬(A 且 B) = ¬A 或 ¬B
  - 翻译进阶 @reason-14
    - 充分条件放箭头前，必要条件放箭头后
    - 推理链：从确定事实出发
    - 二难推理：A 或 B；A → C；B → C ⇒ C
    - “有的”能换位不能逆否；“所有”能逆否不能换位
    - “有的”必须放在链条最前面
  - 真假推理 @reason-07
    - 三步：找矛盾 → 推其余 → 得结论
    - 矛盾：“所有 S 是 P”↔“有的 S 不是 P”；A → B ↔ A 且 ¬B
    - 反对关系至少一假；下反对关系至少一真
  - 分析推理 @reason-15
    - 选项是完整方案：代入排除 @reason-07
    - 某对象出现最多：最大信息法
    - 两三组对象匹配：列表
    - 排序、座位、楼层：画格子或圆桌
    - 条件使用顺序：确定信息 → 相对信息 → 假设
  - 加强削弱与归纳 @reason-08
    - 第一步：找论点和论据，话题不一致是无关项
    - 归纳推理：不超出材料范围，答案往往保守
  - 论证专项 @reason-16
    - 削弱力度：否定论点 ≈ 拆桥 > 他因 / 因果倒置 > 削弱论据
    - 加强：搭桥、排除他因、说明作用机制
    - 前提假设：搭桥；否定代入看论证是否垮掉
    - 解释题：让两个看似矛盾的事实同时成立
    - 按论证类型削弱：调查看样本、类比看差异、方法看可行
  - 科学推理 @reason-17
    - 主要是广东、上海考；国考和四川不考
    - 力：惯性只由质量决定；平衡力 vs 相互作用力
    - 压强 p = F ÷ S；液体压强 ρgh；浮力 F浮 = ρ液 g V排
    - 物态变化：熔化、汽化、升华吸热
    - 凸透镜成像：照相机、投影仪、放大镜
    - 电磁：发电机电磁感应、电动机通电导体受力
