# 申论
- 申论总览 @essay-01
  - 五类题：归纳概括、综合分析、提出对策、贯彻执行、文章写作
  - 小题采点给分：要点全、要点准、条理清
  - 答题五步：审题 → 找要点 → 加工 → 组织 → 誊写
  - 国考 180 分钟、大作文 35 分；四川 150 分钟、大作文 40 分
- 读材料找要点 @essay-02
  - 问题：难、不足、缺乏、滞后、不健全
  - 原因：由于、导致、造成、根源在于
  - 对策：要、应该、通过、建立、完善
  - 意义效果：有利于、促进、提升了
  - 去掉例子、数据、修饰语；人物话语常藏要点
- 归纳概括 @essay-03
  - 格式：总括句 + 分条要点（概括词 + 具体内容）
  - 要点数 ≈ 分值 ÷ 2.5，每条 25—40 字
  - 做法 vs 经验：经验更概括、可推广
  - 五种对象 @essay-11
    - 问题：从对策反推（“要加强培训”→ 培训不足）
    - 原因：按主体或主客观分类
    - 做法、变化（从 A 到 B）、特点（形容词或名词短语）
  - 三化：要点化、条理化、概括化 @essay-11
- 综合分析 @essay-04
  - 四种类型：解释、评价、比较、启示
  - 通用结构：亮观点 → 分析 → 落脚 @essay-12
  - 每一句都要有资料依据
  - 进阶 @essay-12
    - 启示：找做法 → 提炼 → 转化为“要……”
    - 评价：肯定合理 + 指出不足 + 提出正确做法
    - 比较：先同后异，不同点成对写
    - 影响分有利有弊；意义只写积极面
- 提出对策 @essay-05
  - 四个来源：资料直接给出、他地经验、从问题反推、常识补充
  - 一条好对策：主体 + 措施 + 目的
  - 三个毛病：太空、不对应、主体错
  - 每个问题至少对应一条对策
- 贯彻执行
  - 三要素：身份、对象、目的 @essay-06
  - 写作四步：定格式 → 提内容 → 搭结构 → 调语言 @essay-07
  - 内容全部来自资料 @essay-07
  - 评分：格式 10%—20%、要点 60%—70%、语言 10%—20% @essay-13
  - 常见文种
    - 讲话稿：缘由 → 意义或问题 → 做法要求 → 表态致谢 @essay-13
    - 倡议书：背景意义 → 分条倡议 → 号召，不用命令口吻 @essay-13
    - 宣传稿：倒金字塔，导语写清时地人事效果 @essay-13
    - 编者按：介绍、评价、引导 @essay-13
    - 调研报告：基本情况 → 做法或问题 → 原因 → 建议 @essay-14
    - 简报：报头、报核、报尾 @essay-14
    - 工作方案：目的 → 目标 → 组织领导 → 措施 → 保障 @essay-14
    - 公开信、回复函 @essay-14
  - 语言贴合对象：给群众亲切通俗，给领导简洁客观 @essay-07
- 大作文
  - 审题立意 @essay-08
    - 立意三步：抓关键词 → 找关系 → 定总论点
    - 立意标准：准确、深刻、积极
    - 谈“关系”的题：两个关键词都要谈到
  - 结构与论证 @essay-09
    - 五段式：开头 + 三个分论点段 + 结尾
    - 分论点段：分论点句 → 阐释 → 论据 → 小结回扣
    - 论证方法：举例、道理、对比、比喻
  - 开头结尾与卷面 @essay-10
    - 标题：观点式、对仗式、主副标题
    - 开头约 150 字：引话题、亮总论点
    - 结尾：总结升华、展望号召、首尾呼应
    - 列提纲 8—10 分钟
  - 分论点段落 @essay-15
    - 好分论点：紧扣总论点、是判断句、形式工整
    - 三种结构：并列式、递进式、对策式
    - 段落五步：分论点 → 阐释 → 论据 → 分析 → 回扣
    - 三大毛病：例子堆砌、只叙不议、偏离分论点
  - 热点主题框架 @essay-16
    - 县乡卷：民生服务、基层治理、乡村振兴、行政执法
    - 省市卷：营商环境、科技创新、绿色发展、产业升级、数字经济、文化自信
    - 通用分论点思路：主体式、递进式、关系式
- 规范表达 @essay-17
  - 对策句四要素：主体 + 动词 + 对象 + 目的
  - 政策提法：党委领导、政府负责、社会协同、公众参与；高效办成一件事
  - 金句：一篇 3—4 句，引完要分析
  - 人物素材：焦裕禄、谷文昌、黄文秀、张桂梅、南仁东、樊锦诗
- 全卷实战 @essay-18
  - 先看所有题目，带着题目读材料
  - 小题用时 ≈ 分值 × 1 分钟
  - 大作文至少：国考 65 分钟、四川 55 分钟
  - 草稿：小题只列关键词，大作文只列提纲
  - 答题卡：一字一标点各占一格，超字数不计分
