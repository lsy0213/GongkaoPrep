人文常识包括文学、传统节日、古代文化常识等，考点很散，但**高频内容就那么多**。这一课把最常考的整理成卡片，靠反复刷来记。

## 一、文学常识

:::tabs
--- 先秦两汉
- 《**诗经**》：我国第一部诗歌总集，分“风、雅、颂”，表现手法“赋、比、兴”；
- 《**楚辞**》：屈原开创的楚辞体，代表作《离骚》，与《诗经》并称“风骚”；
- 诸子百家：儒家（孔子、孟子、荀子）、道家（老子、庄子）、法家（韩非子）、墨家（墨子，兼爱非攻）；
- 《**史记**》：西汉司马迁，第一部**纪传体通史**，鲁迅称其“史家之绝唱，无韵之《离骚》”；
- 《汉书》：班固，第一部纪传体断代史。
--- 唐诗宋词
| 诗人 | 称号 |
|---|---|
| 李白 | 诗仙 |
| 杜甫 | 诗圣（其诗称“诗史”） |
| 王维 | 诗佛 |
| 李贺 | 诗鬼 |
| 白居易 | 诗魔（新乐府运动） |

- 宋词**豪放派**：苏轼、辛弃疾（“苏辛”）；**婉约派**：柳永、李清照；
- **唐宋八大家**：韩愈、柳宗元（唐），欧阳修、苏洵、苏轼、苏辙、王安石、曾巩（宋）。
--- 元明清
- 元曲四大家：关汉卿（《窦娥冤》）、马致远、郑光祖、白朴；
- 明清小说：《三国演义》（罗贯中）、《水浒传》（施耐庵）、《西游记》（吴承恩）、《红楼梦》（曹雪芹）；
- 《聊斋志异》：蒲松龄，文言短篇小说集；《儒林外史》：吴敬梓，讽刺小说。
:::

## 二、传统节日与节气

| 节日 | 日期（农历） | 习俗和相关诗句 |
|---|---|---|
| 春节 | 正月初一 | 贴春联、守岁；“爆竹声中一岁除” |
| 元宵节 | 正月十五 | 赏灯、吃元宵；“东风夜放花千树” |
| 清明节 | 公历 4 月 5 日前后（节气） | 扫墓、踏青；“清明时节雨纷纷” |
| 端午节 | 五月初五 | 赛龙舟、吃粽子，纪念屈原 |
| 七夕 | 七月初七 | 乞巧；“纤云弄巧，飞星传恨” |
| 中秋节 | 八月十五 | 赏月、吃月饼；“但愿人长久，千里共婵娟” |
| 重阳节 | 九月初九 | 登高、插茱萸、赏菊；“遥知兄弟登高处，遍插茱萸少一人” |

:::tip 二十四节气
“春雨惊春清谷天，夏满芒夏暑相连，秋处露秋寒霜降，冬雪雪冬小大寒。”二十四节气是根据**地球公转**（太阳在黄道上的位置）划分的，2016 年列入联合国教科文组织人类非物质文化遗产代表作名录。
:::

## 三、古代文化常识

:::cards 年龄称谓
而立 :: 30 岁（“三十而立”）
不惑 :: 40 岁
知天命 :: 50 岁
花甲 :: 60 岁
古稀 :: 70 岁（“人生七十古来稀”）
耄耋 :: 八九十岁
期颐 :: 100 岁
弱冠 :: 男子 20 岁
及笄 :: 女子 15 岁
豆蔻 :: 女子十三四岁
:::

- **科举**：童试（秀才）→ 乡试（举人，第一名**解元**）→ 会试（贡士，第一名**会元**）→ 殿试（进士，前三名**状元、榜眼、探花**）；连中解元、会元、状元称“连中三元”；
- **文房四宝**：笔、墨、纸、砚，名品为湖笔、徽墨、宣纸、端砚；
- **书法**：王羲之《兰亭序》被誉为“天下第一行书”，颜真卿《祭侄文稿》为“天下第二行书”；楷书四大家：颜真卿、柳公权、欧阳询、赵孟頫；
- **京剧**被称为“国粹”，角色分生、旦、净、丑。
