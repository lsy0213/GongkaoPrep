找到对应关系后，常常还剩两三个意思差不多的词。这时候要**辨析词语的细微差别**：看不同的那个字、看搭配、看轻重、看范围、看感情色彩。

## 一、语素分析：看不同的那个字

两个词只差一个字，意思的差别就在这个字上。

:::cards 高频易混词
截止 / 截至 :: 截止：到某时停止（“报名已截止”，后面一般不接时间）；截至：到某时为止（“截至 10 月底”，后面接时间）
必须 / 必需 :: 必须：副词，一定要（“必须遵守”）；必需：动词，不可缺少（“生活必需品”）
反应 / 反映 :: 反应：对刺激的回应（“化学反应”“反应迅速”）；反映：把情况告诉上级或体现出来（“反映问题”“反映现实”）
制定 / 制订 :: 制定：定出（法律、政策、规章，偏正式定型）；制订：创制拟订（计划、方案，偏过程）
权利 / 权力 :: 权利：法律赋予的利益（“公民的权利”）；权力：支配、强制的力量（“国家权力”“权力滥用”）
度过 / 渡过 :: 度过：用于时间（“度过假期”）；渡过：用于空间或难关（“渡过长江”“渡过难关”）
启用 / 起用 :: 启用：开始使用（设备、印章）；起用：重新任用或提拔（人）
化妆 / 化装 :: 化妆：修饰容貌使美丽；化装：改变装束以隐藏身份或扮演角色
:::

:::match 选对词语
报名将于明天下午五点______ :: 截止
______到目前，已有三万人报名 :: 截至
这份调查报告真实______了群众的诉求 :: 反映
新办公楼下周正式______ :: 启用
同心协力______难关 :: 渡过
依法保障公民的合法______ :: 权利
:::

## 二、固定搭配：看和谁搭

很多词语有习惯的搭配对象：

- “**提高**水平 / **增强**意识 / **改善**条件 / **扩大**范围 / **降低**成本”——不能说“提高意识”“增强水平”；
- “**履行**职责 / **发挥**作用 / **贯彻**方针 / **落实**政策”；
- “**严峻**的形势 / **严重**的后果 / **严格**的要求 / **严厉**的处罚”。

:::example 搭配辨析
面对复杂______的国际形势，我们要保持战略定力。

A. 严格　B. 严峻　C. 严厉　D. 严肃
--- 看搭配对象
修饰的是“形势”。
--- 辨析
“严峻”常与“形势、考验、挑战”搭配；“严格”搭配“要求、标准”；“严厉”搭配“处罚、批评”；“严肃”搭配“态度、处理”。
--- 答案
**B**。
:::

## 三、程度轻重与范围大小

- 程度：轻视 < 蔑视；损坏 < 毁坏；批评 < 斥责；失望 < 绝望；
- 范围：事件（具体一件事） < 事情 < 事业；边疆（国家边境一带） vs 边境（靠近边界的地方）。

**原则**：和上下文的程度保持一致。原文说“严重”“彻底”“根本”时要选重的词；说“略有”“初步”时要选轻的词。

## 四、感情色彩

- 褒义：成果、鼓舞、团结、果断；
- 贬义：后果、煽动、勾结、武断；
- 中性：结果、鼓动、联合。

:::warn 最常见的错误
把贬义词用在正面语境（“他的坚持终于酿成了好结果”——“酿成”多用于坏事），或者把褒义词用在负面语境（“犯罪团伙的分工非常周密，可谓匠心独运”）。
:::

:::fill 根据语境填词（从括号中选）
1. 这次改革取得了显著的[[成果]]。（成果 / 后果）
2. 由于疏忽大意，这次事故造成了严重的[[后果]]。（成果 / 后果）
3. 我们要[[增强]]安全意识。（提高 / 增强）
4. 学校的办学条件得到了明显[[改善]]。（改善 / 改进）
5. 春节期间，许多人选择回老家[[度过]]假期。（度过 / 渡过）
:::

:::quiz 练一练
各地要______责任，确保各项惠民政策落到实处。
A. 履行
B. 压实
C. 发挥
D. 加强
答案：B
解析：“压实责任”是固定搭配，强调把责任落到具体的人，与“确保……落到实处”呼应。A“履行”的对象一般是职责、义务；C“发挥”搭配作用；D“加强”一般不说“加强责任”。
---
他对待工作极其认真，即使是一份普通的通知，也要______地修改好几遍。
A. 字斟句酌
B. 咬文嚼字
C. 吹毛求疵
D. 刻舟求剑
答案：A
解析：“字斟句酌”是褒义，形容写作或说话态度慎重；“咬文嚼字”多含贬义，指过分斟酌字句、死抠字眼；“吹毛求疵”是故意挑毛病，贬义。语境是赞扬“认真”，选 A。
---
这家企业通过技术改造，生产成本______了 20%。
A. 降低
B. 减轻
C. 缩小
D. 减弱
答案：A
解析：“降低成本”是固定搭配；“减轻”搭配负担，“缩小”搭配差距、范围，“减弱”搭配力量、势头。
:::
