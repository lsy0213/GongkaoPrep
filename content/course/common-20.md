“中国地理”一课讲了我国的地形、气候和区划。这一课向外扩展到**世界地理**（大洲大洋、世界之最、海峡运河、气候类型）、**地球本身**（圈层、板块、地震、时区）和**宇宙**（太阳系、日月食、潮汐），最后整理**天气与自然现象**的成因。这类题很多可以用原理推出来，理解比死记更重要。

## 一、大洲大洋与分界线

- **七大洲**按面积从大到小：**亚洲**、非洲、北美洲、南美洲、**南极洲**、欧洲、**大洋洲**；
- **四大洋**按面积从大到小：**太平洋**（最大最深）、大西洋、印度洋、**北冰洋**（最小最浅最冷）；
- **南极洲**是平均海拔最高的大洲。

|---|---|
| 亚洲—欧洲 | **乌拉尔山脉**、乌拉尔河、里海、大高加索山脉、黑海、土耳其海峡 |
| 亚洲—非洲 | **苏伊士运河** |

:::

## 三、世界主要气候类型

| 气候类型 | 特点 | 典型地区 |
|---|---|---|
| 热带雨林气候 | 全年高温多雨 | 亚马孙平原、刚果盆地 |
| 热带草原气候 | 全年高温，分干湿两季 | 非洲大部 |
| 热带沙漠气候 | 全年炎热干燥 | 撒哈拉、阿拉伯半岛 |
| 热带季风气候 | 全年高温，分旱雨两季 | 印度、中南半岛、我国海南南部 |
| **亚热带季风气候** | 夏季高温多雨，冬季温和少雨 | 我国秦岭—淮河以南 |
| 温带季风气候 | 夏季高温多雨，冬季寒冷干燥 | 我国华北、东北 |
| **地中海气候** | **夏季炎热干燥，冬季温和多雨**（雨热不同期） | 地中海沿岸 |
| **温带海洋性气候** | 全年温和湿润 | **西欧** |
| 温带大陆性气候 | 冬冷夏热，降水少 | 我国西北、中亚 |
| 高原山地气候 | 气温低，垂直变化明显 | 青藏高原 |

:::warn 地中海气候是唯一“雨热不同期”的
大多数气候类型雨季在夏季（雨热同期），只有**地中海气候**是夏季干燥、冬季多雨。
:::

## 四、地球本身

### 1. 地球的结构

- 地球平均半径约 **6371 千米**，赤道周长约 **4 万千米**；
- 内部圈层：**地壳—地幔—地核**（以莫霍面、古登堡面为界）；
- **大气层**（由下往上）：**对流层**（天气现象都发生在这一层）→ **平流层**（大气平稳，适合**飞机飞行**；有**臭氧层**吸收紫外线）→ 高层大气（**电离层**能反射无线电短波）。

### 2. 板块与地震

- 全球分为**六大板块**：亚欧板块、非洲板块、美洲板块、太平洋板块、印度洋板块、南极洲板块；板块交界处地壳活跃，多火山地震；
- **喜马拉雅山**是**印度洋板块与亚欧板块**碰撞挤压形成的；
- 地震的**震级**表示能量大小，**一次地震只有一个震级**；**烈度**表示地面受破坏程度，一次地震在不同地方有**不同烈度**；
- 地震波中**纵波**传播快、**横波**传播慢，所以地震时人先感到**上下颠簸**、后感到**左右摇晃**；
- 地震自救：室内就近躲在坚固家具旁或内墙角的“**三角区**”，不要乘电梯、不要跳楼；室外远离高楼、电线杆。

### 3. 经纬度与时区

- 南北回归线约在 **23°26′**，南北极圈约在 **66°34′**；太阳直射点在南北回归线之间来回移动；极圈以内有**极昼极夜**现象；
- 全球分为 **24 个时区**，经度每差 **15°**，时间相差 **1 小时**，东边的时间比西边早；
- **北京时间**是**东八区**的区时，即东经 **120°** 的地方时（不是北京的地方时）；
- **国际日期变更线**大致沿 **180° 经线**：自西向东越过，日期**减一天**；自东向西越过，日期**加一天**。

:::example 时差计算
北京时间 2026 年 3 月 1 日 20:00，位于西五区的纽约是几点？
--- 区时差
东八区与西五区相差 8 + 5 = **13** 个时区，即 13 小时。
--- 东早西晚
纽约在西边，时间更晚：20:00 − 13 小时 = **7:00**。
--- 答案
纽约当地时间 **3 月 1 日 7:00**。
:::

## 五、宇宙与太阳系

:::key 八大行星
按离太阳由近及远：**水星、金星、地球、火星、木星、土星、天王星、海王星**（口诀“水金地火木土天海”）。2006 年**冥王星**被重新划为**矮行星**。

- **木星**：体积、质量最大；
- **土星**：有明显的光环；
- **金星**：表面温度最高（浓厚的二氧化碳大气造成强烈温室效应），是天空中除太阳、月亮外最亮的天体；
- **火星**：“红色星球”，我国“天问一号”2021 年着陆火星；
- **水星**：离太阳最近。
:::

- **太阳活动**：**黑子**是太阳活动强弱的标志，**耀斑**是太阳活动最激烈的显示；太阳活动会引起地球**磁暴**、高纬度地区出现**极光**、干扰**无线电短波通信**；
- **月球**：自转周期与公转周期相同，所以**总是以同一面朝向地球**；
- **月相**：农历初一为**新月（朔）**，农历十五、十六前后为**满月（望）**；
- **日食**：月球运行到太阳和地球之间（**日—月—地**），只能发生在**朔日**（农历初一）；**月食**：地球运行到太阳和月球之间（**日—地—月**），只能发生在**望日**（农历十五、十六）；
- **潮汐**：主要由**月球引力**引起，农历初一、十五前后出现**大潮**；
- **光年**是**距离**单位（光在一年中走的距离），不是时间单位。

:::order 八大行星由近及远排好
- 水星
- 金星
- 地球
- 火星
- 木星
- 土星
- 天王星
- 海王星
:::

## 六、天气与自然现象

| 现象 | 成因 |
|---|---|
| **雾凇**（树挂） | 空气中的水汽遇冷直接**凝华**成冰晶附着在树枝上 |
| 霜 | 水汽**凝华** |
| 露、雾 | 水汽**液化** |
| 雨凇 | 过冷却雨滴落到温度低于 0℃ 的物体上冻结 |
| **冰雹** | 强对流天气中，水滴在积雨云里被上升气流反复托举、冻结增大 |
| **焚风** | 气流越过山脉后沿背风坡下沉，**增温变干** |
| 城市**热岛效应** | 城市人口密集、建筑和道路吸热、人为热排放多，市区气温高于郊区 |
| **酸雨** | 二氧化硫、氮氧化物溶于雨水，**pH 小于 5.6** |
| 臭氧层空洞 | 氟利昂等含氯氟烃破坏臭氧 |
| **厄尔尼诺** | 赤道中东太平洋海水**异常升温**（拉尼娜是异常降温） |
| **梅雨** | 初夏冷暖空气在江淮流域相持形成准静止锋 |

:::tip 天气谚语
- “**朝霞不出门，晚霞行千里**”：早晨东方有霞，说明西方（上游）有云雨移来；傍晚西方有霞，说明西方天晴；
- “**东虹日头西虹雨**”：彩虹出现在东边，说明西边（来向）天晴；
- “**月晕而风，础润而雨**”：月亮周围出现光环预示刮风，柱子的石墩潮湿预示下雨；
- “**燕子低飞要下雨**”：下雨前空气湿度大，昆虫飞得低，燕子低飞捕食。
:::
