“五位一体”里，经济建设单独讲过了（第 10 课），这一课讲**政治（民主与法治）、文化、社会**三块。它们的考法和经济一样：记住**定位性表述**（“本质属性”“根本保障”“灵魂”“主线”），再记一批**提出时间**。

## 一、全过程人民民主

:::key 全过程人民民主
- 2019 年 11 月，习近平在**上海虹桥街道**考察时首次提出“人民民主是一种全过程的民主”；
- 二十大报告：全过程人民民主是**社会主义民主政治的本质属性**，是**最广泛、最真实、最管用**的民主；
- 实现了过程民主和成果民主、程序民主和实质民主、直接民主和间接民主、人民民主和国家意志相统一。
:::

**我国的政治制度体系**：

| 类型 | 内容 |
|---|---|
| 根本政治制度 | **人民代表大会制度** |
| 基本政治制度 | 中国共产党领导的**多党合作和政治协商制度**、**民族区域自治制度**、**基层群众自治制度** |
| 国体 | 工人阶级领导的、以工农联盟为基础的人民民主专政 |

- **协商民主**是实践全过程人民民主的重要形式，是我国社会主义民主政治的**特有形式和独特优势**；
- **人民政协**是社会主义协商民主的**重要渠道和专门协商机构**；
- **爱国统一战线**是党凝聚人心、汇聚力量的重要法宝；
- 民族工作：以**铸牢中华民族共同体意识**为新时代党的民族工作的**主线**；
- 宗教工作：坚持我国**宗教中国化**方向。

:::warn 易错
- “根本政治制度”只有人民代表大会制度一个；“基本政治制度”有三个——题目说“民族区域自治制度是根本政治制度”就是错的；
- 基层群众自治制度包括城市**居民委员会**、农村**村民委员会**和企事业单位**职工代表大会**等。
:::

## 二、全面依法治国与习近平法治思想

- 2020 年 11 月**中央全面依法治国工作会议**首次明确提出**习近平法治思想**，并明确为全面依法治国的指导思想；
- 全面依法治国**总目标**：建设中国特色社会主义法治体系，建设社会主义法治国家；
- **新十六字方针**（十八大）：**科学立法、严格执法、公正司法、全民守法**（旧十六字方针是“有法可依、有法必依、执法必严、违法必究”）；
- 坚持法治国家、法治政府、法治社会**一体建设**；坚持依法治国、依法执政、依法行政**共同推进**；
- 全面依法治国最广泛、最深厚的基础是**人民**；
- 党的领导是社会主义法治**最根本的保证**；
- 2014 年起，每年 **12 月 4 日**为**国家宪法日**；2015 年起实行宪法宣誓制度。

:::cards “十一个坚持”（习近平法治思想的核心要义，挑几个最常考的）
坚持党对全面依法治国的领导 :: 第一条
坚持以人民为中心 :: 全面依法治国的根本立场
坚持中国特色社会主义法治道路 :: 唯一正确道路
坚持依宪治国、依宪执政 :: 依法治国首先是依宪治国
坚持建设德才兼备的高素质法治工作队伍 :: 法治工作队伍
坚持抓住领导干部这个“关键少数” :: 领导干部带头尊法学法守法用法
:::

:::match 新旧“十六字方针”
科学立法、严格执法、公正司法、全民守法 :: 新十六字方针（十八大）
有法可依、有法必依、执法必严、违法必究 :: 旧十六字方针（十一届三中全会）
:::

## 三、文化建设

### 1. 社会主义核心价值观（24 字）

| 层面 | 内容 |
|---|---|
| 国家层面 | 富强、民主、文明、和谐 |
| 社会层面 | 自由、平等、公正、法治 |
| 个人层面 | 爱国、敬业、诚信、友善 |

:::fill 填一填
社会主义核心价值观的社会层面是：自由、[[平等]]、公正、[[法治]]；个人层面是：爱国、[[敬业]]、诚信、[[友善]]。
:::

### 2. 习近平文化思想与文化使命

- 2023 年 10 月**全国宣传思想文化工作会议**首次提出**习近平文化思想**；
- **新时代新的文化使命**：在新的起点上继续推动文化繁荣、建设文化强国、**建设中华民族现代文明**（2023 年 6 月文化传承发展座谈会）；
- **中华文明的五个突出特性**：**连续性、创新性、统一性、包容性、和平性**；
- “**第二个结合**”是又一次的思想解放；
- 意识形态工作是党的一项**极端重要**的工作；
- 到 2035 年建成**文化强国**。

:::match 中华文明的突出特性和它“决定了”什么
连续性 :: 中华民族必然走自己的路
创新性 :: 中华民族守正不守旧、尊古不复古的进取精神
统一性 :: 各民族文化融为一体、国家统一永远是核心利益
包容性 :: 中华文明对世界文明兼收并蓄的开放胸怀
和平性 :: 中国始终是世界和平的建设者、全球发展的贡献者、国际秩序的维护者
:::

## 四、社会建设与民生

:::key 民生“七有”
**幼有所育、学有所教、劳有所得、病有所医、老有所养、住有所居、弱有所扶**（十九大提出）。
:::

| 领域 | 定位表述 |
|---|---|
| 就业 | **最基本的民生**；实施就业优先战略 |
| 教育 | 教育是**国之大计、党之大计**；教育、科技、人才是全面建设社会主义现代化国家的**基础性、战略性支撑**；到 2035 年建成**教育强国** |
| 健康 | 把保障人民健康放在**优先发展**的战略位置，推进健康中国建设 |
| 社会保障 | 社会保障是保障和改善民生、维护社会公平、增进人民福祉的**基本制度保障** |
| 人口 | 以人口高质量发展支撑中国式现代化；积极应对人口老龄化上升为国家战略 |
| 收入 | 增加低收入者收入，扩大中等收入群体，规范收入分配秩序 |

:::tip 延迟法定退休年龄（2025 年 1 月 1 日起）
用 **15 年**时间，逐步将男职工的法定退休年龄从 60 周岁延迟至 **63** 周岁，将女职工的法定退休年龄从 50 周岁、55 周岁分别延迟至 **55**、**58** 周岁。坚持**小步调整、弹性实施、分类推进、统筹兼顾**的原则。
:::

### 社会治理

- 建设**共建共治共享**的社会治理制度；
- 新时代“**枫桥经验**”：源于 1963 年浙江诸暨枫桥镇，核心是“**小事不出村，大事不出镇，矛盾不上交**”，就地化解矛盾；
- 健全城乡基层治理体系，推进基层减负。

## 五、随堂练习

:::quiz 小测
全过程人民民主是：
A. 社会主义民主政治的特有形式
B. 社会主义民主政治的本质属性
C. 我国的根本政治制度
D. 人民政协的根本任务
答案：B
解析：A 说的是协商民主。
---
下列属于我国基本政治制度的是：
A. 人民代表大会制度
B. 民族区域自治制度
C. 社会主义市场经济体制
D. 国家监察制度
答案：B
---
首次明确提出“习近平法治思想”的是：
A. 十八届四中全会
B. 中央全面依法治国工作会议
C. 二十大
D. 全国人大会议
答案：B
---
中华文明的五个突出特性不包括：
A. 连续性
B. 统一性
C. 开放性
D. 和平性
答案：C
解析：五个突出特性是连续性、创新性、统一性、包容性、和平性。

按照渐进式延迟退休改革，原法定退休年龄为 55 周岁的女职工，最终将延迟至：
A. 57 周岁
B. 58 周岁
C. 60 周岁
D. 63 周岁
答案：B
---
“小事不出村，大事不出镇，矛盾不上交”说的是：
A. 浦江经验
B. 枫桥经验
C. 千万工程
D. 晋江经验
