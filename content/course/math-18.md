数字推理给出一列数，找规律填出下一个（或中间缺的）数。**国考和四川省考从 2018 年度起已经不考数字推理**（题库里最后一批是 2017 年的 10—15 道），但部分省份的省考、事业单位职测、选调和国企考试仍然会考，而且它训练的“数感”对数量关系和资料分析都有用。这一课用最短的篇幅把六大类规律讲完。

:::note 学不学这一课
只考国考或四川省考，可以把这一课当作选学，快速浏览即可；报了事业单位或其他省份考试，务必练熟。
:::

## 一、看数列的顺序

拿到一列数，按这个顺序试：

:::flow 数字推理五步观察
看趋势 :: 递增、递减还是忽大忽小（忽大忽小先考虑多重数列）
看特征数 :: 有没有平方数、立方数附近的数，有没有分数、小数
作差 :: 相邻两项相减，看差是否有规律（最常见）
作商 :: 增长很快（翻倍以上）时相邻两项相除
递推 :: 前两项（或三项）之间是否有和、积、倍数关系
:::

## 二、多级数列（作差、作商）

:::tabs
--- 作差
2, 5, 10, 17, 26, (　)
作差：3, 5, 7, 9 → 下一个差是 11，答案 **37**。

（也可以看出是 n² + 1。）
--- 二次作差得等比
1, 3, 7, 15, 31, (　)
作差：2, 4, 8, 16 → 下一个差 32，答案 **63**。
--- 作商
2, 2, 4, 12, 48, (　)
作商：1, 2, 3, 4 → 下一个商 5，答案 48 × 5 = **240**。
:::

## 三、递推数列

后面的项由前面的项算出来：

| 规律 | 例子 | 下一项 |
|---|---|---|
| 前两项之和 | 1, 2, 3, 5, 8, 13, (　) | 21 |
| 前两项之积 | 2, 3, 6, 18, 108, (　) | 108 × 18 = 1944 |
| 前一项 × 2 + 1 | 3, 7, 15, 31, 63, (　) | 127 |
| 前一项 × 2 + 再前一项 | 1, 1, 3, 7, 17, 41, (　) | 41 × 2 + 17 = 99 |

:::tip 递推的信号
数列增长速度**越来越快**、而作差作商都没有规律时，试递推。看最后几项：用前两项能否通过“和、积、倍数 ± 常数”凑出后一项。
:::

## 四、多重数列

项数较多（7 项以上）或者数字**忽大忽小**时：

- **交叉数列**：奇数项一组、偶数项一组，各有规律。例：1, 10, 3, 9, 5, 8, 7, (　) → 奇数项 1, 3, 5, 7；偶数项 10, 9, 8, (7)，答案 **7**；
- **分组数列**：两两一组，组内有和、差、积、商关系。例：2, 4, 3, 9, 4, 16, (　), (　) → 每组后项是前项的平方，答案 5、25。

## 五、幂次数列

先熟记常见幂次数：

:::cards 必背幂次数
11² ~ 20² :: 121, 144, 169, 196, 225, 256, 289, 324, 361, 400
1³ ~ 10³ :: 1, 8, 27, 64, 125, 216, 343, 512, 729, 1000
2 的 1 ~ 10 次方 :: 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024
3 的 1 ~ 6 次方 :: 3, 9, 27, 81, 243, 729
特殊的数 :: 64 = 2⁶ = 4³ = 8²；81 = 3⁴ = 9²；256 = 2⁸ = 4⁴ = 16²；729 = 3⁶ = 9³ = 27²
:::

修正幂次数列：在幂次数附近 ±1、±2：

- 0, 7, 26, 63, (　) → 1³ − 1, 2³ − 1, 3³ − 1, 4³ − 1，答案 5³ − 1 = **124**；
- 2, 9, 28, 65, (　) → n³ + 1，答案 **126**。

## 六、分数数列

- 先**通分或反约分**，让分子、分母各自有规律；
- 分子分母**交替关联**：1/2, 2/3, 3/5, 5/8, (　) → 下一项分子 = 上一项分母，分母 = 上一项分子 + 分母，答案 **8/13**。

## 七、随堂练习

:::quiz 数字推理小测
3, 4, 7, 12, 19, (　)
A. 26
B. 28
C. 30
D. 31
答案：B
解析：作差 1, 3, 5, 7，下一个差 9，19 + 9 = 28。
---
1, 2, 6, 24, 120, (　)
A. 240
B. 360
C. 600
D. 720
答案：D
解析：作商 2, 3, 4, 5，下一个商 6，120 × 6 = 720（即 n!）。
---
0, 2, 6, 12, 20, 30, (　)
A. 36
B. 40
C. 42
D. 48
答案：C
解析：作差 2, 4, 6, 8, 10，下一个差 12，30 + 12 = 42（也是 n² − n）。
---
2, 3, 5, 8, 13, 21, (　)
A. 29
B. 32
C. 34
D. 36
答案：C
解析：前两项之和：13 + 21 = 34。
---
1, 8, 27, 64, (　)
A. 81
B. 100
C. 121
D. 125
答案：D
解析：立方数列，5³ = 125。
:::

:::cards 本课记忆卡
数字推理观察顺序 :: 趋势 → 特征数 → 作差 → 作商 → 递推
忽大忽小或项数多 :: 先考虑交叉或分组的多重数列
增长越来越快 :: 试作商或递推
修正幂次 :: 幂次数 ± 1、± 2
分数数列 :: 通分或反约分，看分子分母各自规律
国考 / 四川是否考数字推理 :: 2018 年度起不考；部分省考、事业单位、选调仍考
