国考和四川省考近年的言语题以逻辑填空、片段阅读、语句表达为主，**病句题已经很少单独出现**；但部分省考、事业单位和选调考试仍会考病句、歧义、标点和修辞，而且这些知识直接关系到**申论的规范表达**。这一课快速过一遍。

:::note 学习建议
只考国考、四川的同学：重点看“歧义”和“谦敬辞”，用于申论和面试表达；报考其他考试的同学：全部掌握。
:::

## 一、六类病句

| 类型 | 典型例子 | 怎么改 |
|---|---|---|
| **语序不当** | 我们要认真**克服并找出**工作中的缺点 | 先找出，再克服 |
| **搭配不当** | 他的**写作水平**明显**改进**了 | 水平“提高”；方法“改进” |
| **成分残缺** | **通过**这次活动，**使**我们受到了教育 | 删“通过”或删“使”，句子才有主语 |
| **成分赘余** | 他**大约**用了**一个小时左右** | “大约”和“左右”删一个 |
| **结构混乱** | 这次比赛的冠军**是由**我班同学**夺得的冠军** | 句式杂糅：删去后一个“冠军” |
| **不合逻辑** | 能否保持良好心态，是**取得好成绩**的关键 | 两面对一面：改为“能否……是能否取得好成绩的关键” |

:::key 病句的三步检查
1. **抓主干**：找出主语、谓语、宾语，看搭配；
2. **查成分**：介词开头（通过、经过、由于）后面是否吞掉了主语；
3. **看逻辑**：“能否、是否”两面对一面；否定词多重（“难道不能否认”）；并列概念有包含关系（“水果和苹果”）。
:::

## 二、歧义：一句话两种理解

| 原因 | 例子 | 两种理解 |
|---|---|---|
| **结构不同** | 咬死了猎人的狗 | ① 狗被咬死了；② 某物咬死了猎人的狗 |
| **停顿不同** | 三个学校的老师 | ① 三个“学校的老师”；② “三个学校”的老师 |
| **多义词** | 他走了一个多小时 | ① 步行了一个多小时；② 离开了一个多小时 |
| **指代不明** | 小王对小李说他的方案通过了 | “他”是小王还是小李 |
| **施受不明** | 这个人谁都不认识 | ① 他不认识任何人；② 没人认识他 |

:::tip 写公文和申论时避免歧义
少用“他、她、其”指代多个对象，直接写名称；数量词紧挨被修饰的名词；“以上”“以下”写明是否包括本数（法律规定“以上”“以下”**包括本数**）。
:::

## 三、标点符号常考点

- **顿号**用于句中并列的词语之间；并列成分之间已有“和、及、与”时，不再用顿号；
- 并列词语后有“**等**”时，“等”前**不加**顿号：“北京、上海、广州等城市”；
- **约数**不用顿号：“三四天”“五六个”中间不加顿号；
- **书名号**用于书名、篇名、报刊名、法规文件名、影视剧名；不用于商品名、奖项名、活动名、课程名（课程名有时用引号）；
- 引语**完整独立**时，句末标点放在引号**里面**；引语只是句子的一部分时，句末标点放在引号**外面**。

## 四、修辞手法

| 修辞 | 特点 | 例子 |
|---|---|---|
| **比喻** | 本体和喻体是**不同类**事物，有相似点 | 书籍是人类进步的阶梯（暗喻） |
| **拟人** | 把物当人写 | 春风轻轻抚摸着大地 |
| **夸张** | 故意言过其实 | 飞流直下三千尺 |
| **借代** | 用相关事物代替本体 | 红领巾（代少先队员）；“巾帼”代女性 |
| **对偶** | 字数相等、结构相同、意义相关 | 海阔凭鱼跃，天高任鸟飞 |
| **排比** | 三个及以上结构相似的句子 | 申论分论点、标题常用 |
| **互文** | 上下文互相补充，合起来理解 | 秦时明月汉时关（秦汉时的明月和关隘） |

## 五、谦辞与敬辞

:::cards 谦敬辞
令尊 / 令堂 :: 敬称对方的父亲 / 母亲
家父 / 家母 :: 谦称自己的父亲 / 母亲
舍弟 / 舍妹 :: 谦称自己的弟弟 / 妹妹（“家”用于长辈，“舍”用于晚辈或同辈中年幼者）
拙作 / 拙见 :: 谦称自己的作品 / 见解
惠存 :: 请对方保存（赠送自己的作品时用）
斧正 / 指正 :: 请对方修改 / 指出错误
垂询 :: 敬称对方（长辈、上级）的询问
光临 / 惠顾 :: 敬称对方到来 / 光顾
敬请 / 恭候 :: 敬辞：请对方做某事 / 等候对方
鼎力 :: 敬辞，用于请托或感谢对方的大力帮助（不用于自己）
:::

:::warn 最常见的误用
- “**惠存**”只能用于请别人保存，不能说“我会惠存您的礼物”；
- “**鼎力**相助”是称赞或请求别人，不能说“我一定鼎力相助”；
- “**垂询**”是对方问，不能说“我向您垂询”；
- “**令尊**”是称呼别人的父亲，不能说“我的令尊”。
:::

## 六、随堂练习

:::quiz 病句与语言常识小测
下列句子没有语病的是：
A. 通过这次培训，使大家掌握了新的操作方法
B. 他的写作水平明显提高了
C. 我们要认真克服并找出工作中的不足
D. 能否坚持锻炼，是身体健康的重要保证
答案：B
解析：A 成分残缺（缺主语）；C 语序不当；D 两面对一面。
---
“三个学校的老师参加了培训”产生歧义的原因是：
A. 多义词
B. 停顿（结构层次）不同
C. 指代不明
D. 标点错误
答案：B
---
下列谦敬辞使用正确的是：
A. 这是我的拙作，请您惠存
B. 我一定鼎力相助
C. 感谢您的令尊来参加婚礼，我的令尊也很高兴
D. 我向专家垂询了这个问题
答案：A
解析：拙作谦称自己的作品，惠存请对方保存，都正确。B 鼎力不用于自己；C“我的令尊”错误；D 垂询是对方问。
---
下列标点使用正确的是：
A. 北京、上海、广州、等城市
B. 这次活动持续了三、四天
C. 他购买了苹果、香蕉和葡萄
D. 我们学习了《法治》课程
答案：C
解析：A“等”前不加顿号；B 约数不用顿号；D 课程名不用书名号。
---
“秦时明月汉时关”使用的修辞手法是：
A. 比喻
B. 借代
C. 互文
D. 夸张
答案：C
:::
