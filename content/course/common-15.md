上一课（经济常识）讲了供求、宏观指标和两大政策。这一课往外延伸三块：**货币与金融体系**（钱和银行、股市）、**国际经济**（汇率、国际组织）、**税收与常考经济学效应**。这些题的特点是“名词—含义”对应，很适合用记忆卡突破。

## 一、货币与金融

### 1. 货币的职能

| 职能 | 含义 | 例子 |
|---|---|---|
| **价值尺度** | 表现和衡量商品价值大小（观念上的货币即可） | 标价：一件衣服 200 元 |
| **流通手段** | 充当商品交换的媒介（必须是现实的货币） | 一手交钱一手交货 |
| 贮藏手段 | 退出流通领域被保存起来（必须是足值的金属货币） | 古人窖藏金银 |
| **支付手段** | 用于清偿债务、支付租金、工资、税款等 | 分期付款、还贷、发工资 |
| 世界货币 | 在世界市场上充当一般等价物 | |

:::reveal 想一想：下列分别体现货币的哪种职能？
1. 超市里一瓶饮料标价 4 元
2. 用手机支付买了这瓶饮料
3. 每月按揭还房贷
---
1. 价值尺度（标价）；2. 流通手段（钱货两清）；3. 支付手段（清偿债务）。

关键区别：**流通手段**是“一手交钱一手交货”；**支付手段**是“钱和货在时间上分离”，如赊购、还贷、缴税、发工资。
:::

- **数字人民币（e-CNY）**：由中国人民银行发行的法定数字货币，与纸币和硬币**等价**，具有价值特征和**法偿性**；
- 纸币的发行量必须以流通中所需要的**货币量**为限度，发行过多会引起通货膨胀。

### 2. 我国金融监管体系（2023 年机构改革后）

:::key “一行一总局一会一局”
- **中国人民银行**：中央银行，制定和执行**货币政策**、防范化解金融风险；
- **国家金融监督管理总局**：在原银保监会基础上组建，统一负责除证券业之外的金融业监管；
- **中国证券监督管理委员会**：证券期货市场监管；
- **国家外汇管理局**：由中国人民银行管理。
:::

- **政策性银行**：中国进出口银行、中国农业发展银行（国家开发银行定位为开发性金融机构）；
- **存款保险**：同一存款人在同一家投保机构所有被保险存款账户的存款本金和利息合并计算的资金数额在 **50 万元**以内的，实行全额偿付。

### 3. 资本市场

| 交易所 / 板块 | 成立或开市时间 | 定位 |
|---|---|---|
| 上海证券交易所 | 1990 年 | 主板；**科创板**（2019 年开市，首个试点注册制） |
| 深圳证券交易所 | 1990 年（1991 年正式开业） | 主板；**创业板**（2009 年开市） |
| **北京证券交易所** | 2021 年 9 月设立，11 月开市 | 服务**创新型中小企业** |

- 2023 年 2 月，**全面实行股票发行注册制**；
- 股票：股份公司的所有权凭证，**收益高、风险高**，不能退股只能转让；
- 债券：债务凭证，到期还本付息。风险由低到高：**国债 < 金融债券 < 企业（公司）债券**；
- 基金：集合投资、专家理财、组合投资、分散风险。

:::match 投资方式和特点
储蓄存款 :: 风险低、收益低、流动性强
国债 :: 有国家信用担保，风险最小的债券
股票 :: 收益高、风险高，只能转让不能退股
商业保险 :: 规避风险的手段，不以盈利为主要目的
:::

## 二、汇率与国际收支

:::key 人民币升值 / 贬值的影响（必会推理）
人民币**升值**（1 美元换的人民币变少）：

- 利于**进口**（进口商品变便宜）、出国**留学旅游**、**对外投资**、偿还外债；
- 不利于**出口**（我国商品在国外变贵）、吸引外资、入境旅游。

人民币**贬值**则相反：利于出口和吸引外资，不利于进口和出境消费。
:::

:::example 汇率题怎么做
2025 年初 1 美元兑换 7.3 元人民币，年底 1 美元兑换 7.1 元人民币。这一变化：
A. 不利于中国学生赴美留学
B. 有利于中国商品出口美国
C. 有利于中国企业赴美投资
D. 使美国商品在中国市场变贵
--- 判断升贬值
1 美元能换的人民币从 7.3 变成 7.1，**美元贬值、人民币升值**。
--- 推影响
人民币升值 → 出国留学、对外投资更划算 → **C 对**；出口不利（B 错），美国商品在中国变便宜（D 错），留学更划算（A 错）。
--- 答案
**C**。
:::

- **国际收支**：出口大于进口为**贸易顺差**（出超），进口大于出口为**贸易逆差**（入超）；
- 我国实行以市场供求为基础、参考一篮子货币进行调节、**有管理的浮动汇率制度**。

## 三、国际经济组织与合作

| 组织 / 协定 | 要点 |
|---|---|
| **世界贸易组织（WTO）** | 1995 年成立，总部日内瓦；中国 **2001 年 12 月 11 日**正式加入 |
| 国际货币基金组织（IMF） | 1945 年成立，负责国际货币金融；人民币 2016 年加入特别提款权（SDR）货币篮子 |
| 世界银行 | 向发展中国家提供长期贷款 |
| 二十国集团（G20） | 国际经济合作主要论坛，2016 年杭州峰会 |
| 亚太经合组织（APEC） | 1989 年成立，中国 1991 年加入；中国曾在 2001 年上海、2014 年北京主办，**2026 年在深圳**主办 |
| **区域全面经济伙伴关系协定（RCEP）** | 2020 年 11 月签署，**2022 年 1 月 1 日**生效；15 国：东盟 10 国 + 中、日、韩、澳、新西兰；全球人口和经济体量最大的自贸区 |
| **亚洲基础设施投资银行（亚投行）** | 2015 年成立、2016 年开业，总部**北京**，中国倡议成立的首个多边金融机构 |
| 金砖国家新开发银行 | 总部**上海** |
| **金砖国家** | 中国、俄罗斯、印度、巴西、南非；2024 年起埃及、埃塞俄比亚、伊朗、阿联酋成为成员，2025 年印度尼西亚加入 |
| **上海合作组织** | 2001 年在上海成立；成员国包括中、俄、哈、吉、塔、乌、印度、巴基斯坦、伊朗（2023）、白俄罗斯（2024） |

:::warn 别把两个“新银行”搞混
**亚投行**总部在北京，面向亚洲基础设施；**新开发银行**是金砖国家设立的，总部在上海。
:::

## 四、税收

- 税收的三个基本特征：**强制性、无偿性、固定性**（无偿性是核心）；
- 增值税是我国**第一大税种**；
- 个人所得税：综合所得基本减除费用标准为每月 **5000 元**（每年 6 万元）；实行**专项附加扣除**，包括子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、**3 岁以下婴幼儿照护**共 7 项；
- 偷税、欠税、骗税、抗税是四种违反税法的行为，**抗税**是以暴力、威胁方法拒不缴纳税款。

## 五、更多常考的经济学概念

:::cards 经济学效应与规律（续）
凡勃伦效应 :: 商品价格越高，消费者越愿意购买（炫耀性消费）
吉芬商品 :: 价格上涨反而需求增加的特殊商品（如灾荒年间的土豆）
口红效应 :: 经济不景气时，廉价的“小奢侈品”反而热销
棘轮效应 :: 消费习惯“由俭入奢易，由奢入俭难”
蝴蝶效应 :: 初始条件的微小变化引起整个系统长期的巨大连锁反应
长尾效应 :: 大量小众需求累积起来可以和主流需求相匹敌
搭便车 :: 不付成本而坐享他人之利
公地悲剧 :: 公共资源因产权不清被过度使用而枯竭
囚徒困境 :: 个人最优选择导致集体非最优结果
帕累托最优 :: 不可能在不使任何人境况变坏的情况下使某些人境况变好
二八定律 :: 20% 的关键因素决定 80% 的结果
外部性 :: 经济活动对他人产生的影响未计入价格；有正外部性（如植树）和负外部性（如污染）
市场失灵 :: 市场机制无法有效配置资源；原因包括垄断、外部性、公共物品、信息不对称
公共物品 :: 具有非竞争性和非排他性（如国防、路灯），市场不愿提供，需要政府供给
垄断 :: 少数企业控制市场，限制竞争；我国《反垄断法》2008 年施行、2022 年修正
信息不对称 :: 交易一方比另一方掌握更多信息，可能导致逆向选择（如二手车市场）和道德风险
菲利普斯曲线 :: 通货膨胀率与失业率之间存在此消彼长的关系
拉弗曲线 :: 税率过高反而导致税收减少
规模经济 :: 生产规模扩大使单位成本下降
中等收入陷阱 :: 进入中等收入后经济长期停滞，难以迈入高收入国家
塔西佗陷阱 :: 公权力失去公信力时，无论说真话还是假话、做好事还是坏事，都会被认为是说假话、做坏事
修昔底德陷阱 :: 新兴大国与守成大国之间必然冲突的说法（我国主张避免）
:::

:::tip 宏观调控的四大目标
**促进经济增长、增加就业、稳定物价、保持国际收支平衡**。

宏观政策的最新表述：2024 年 12 月中央经济工作会议提出实施**更加积极的财政政策**和**适度宽松的货币政策**（这是十多年来首次将货币政策基调调整为“适度宽松”）。
:::
