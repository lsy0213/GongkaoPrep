国考、四川的逻辑填空里，**两空题、三空题**占了一大半。多空题看起来难，其实给了更多排除的机会：**只要有一个空能确定，就能排除两个选项**。这一课讲多空题的做法，再补充一批真题里反复出现的**实词组**——特别是政策文本里的高频动词。

## 一、多空题四步法

:::flow 多空题四步
先看选项 :: 横向比较每一空的四个词，找出差异最大、最好判断的那一空
先做最有把握的空 :: 有明显对应（解释、并列、转折）或固定搭配的空优先，一次排除两个选项
再做剩下的空 :: 只在剩下的两个选项之间比较
回代全句 :: 把答案代回原文通读，检查搭配和语气
:::

:::key 空与空之间的关系
- **并列的两空**：意思相近（“既……又……”）或相反；
- **递进的两空**：后一空程度更深（“不仅……更……”）；
- **同一主语的两空**：感情色彩一致；
- 一个空与**文中另一处**对应：如前文说“稳步推进”，空里填“循序渐进”。
:::

:::example 两空题
推进乡村振兴，既要______乡村产业基础，又要______乡村治理短板，才能让农业强、农村美、农民富的目标落到实处。

A. 夯实　补齐　B. 巩固　弥补　C. 筑牢　填补　D. 加固　补足
--- 先看第二空
“短板”的固定搭配是**补齐**短板。“弥补”常搭配缺陷、损失，“填补”常搭配空白，“补足”常搭配差额、缺口。锁定 **A**。
--- 验证第一空
夯实基础，搭配恰当。
--- 答案
**A**。
:::

## 二、政策高频动词：看搭配对象

| 词 | 常见搭配 |
|---|---|
| **夯实** | 基础、根基 |
| **筑牢** | 防线、屏障、底线 |
| **补齐** | 短板 |
| **填补** | 空白 |
| **弥补** | 缺陷、不足、损失 |
| **破解** | 难题、瓶颈 |
| **化解** | 矛盾、风险、纠纷 |
| **激发** | 活力、潜能、热情 |
| **激活** | 市场、要素、资源 |
| **规避** | 风险（主动设法避开） |
| **遏制** | 势头、蔓延（使停止发展） |
| **抑制** | 欲望、物价、需求（压下去） |
| **推行** | 制度、政策（普遍实行） |
| **推广** | 经验、技术、做法（扩大范围） |
| **推进** | 改革、工作、进程（向前推动） |
| **彰显** | 价值、魅力、担当（显示出来，褒义） |
| **凸显** | 问题、矛盾、作用（突出地显露，中性） |
| **涵盖** | 范围、领域（包括在内） |
| **囊括** | 全部、奖项（全部收罗，程度更重） |

## 三、常考实词组

:::tabs
--- 改字头
- **改进**：改变旧状况，使有所进步（工作方法、作风）；
- **改善**：改变原有情况使好一些（生活、环境、关系）；
- **改良**：去掉缺点使更适合要求（品种、土壤）；
- **改革**：把不合理的部分改成新的（制度、体制）。
--- 以致 / 以至
- **以致**：表示**不好的结果**（“他平时不认真，以致考试失利”）；
- **以至**：表示**程度、范围的延伸**（“几年以至几十年”），也可表示结果（中性）。
--- 进而 / 从而 / 因而
- **进而**：在已有基础上**更进一步**；
- **从而**：引出**结果或目的**，前面是方法、条件；
- **因而**：引出**结果**，前面是原因。
--- 截然 / 迥然
- **截然**：界限分明，像割断一样（截然不同、截然相反、截然分开）；
- **迥然**：差别很远（迥然不同、迥然有别），**不能**说“迥然相反”。
--- 掣肘 / 束缚 / 羁绊
- **掣肘**：拉住胳膊，比喻**从旁干扰牵制**；
- **束缚**：使受到约束限制（思想、手脚）；
- **羁绊**：缠住了不能脱身，**牵制**（多用于感情、名利）。
:::

## 四、随堂练习

:::quiz 多空题小测
面对新一轮科技革命，我们要加快______关键核心技术难题，______各类创新主体的活力。
A. 化解　激活
B. 破解　激发
C. 消除　激励
D. 解决　激活
答案：B
解析：第一空搭配“难题”，破解、解决都可以，化解多搭配矛盾风险；第二空搭配“活力”，用**激发**。激活多搭配市场、资源。
---
这项改革经验已经在全省______，各地结合实际______落实。
A. 推广　推进
B. 推行　推广
C. 推进　推行
D. 推广　推行
答案：A
解析：经验用“推广”；落实工作用“推进”。
---
他对工作不认真，______出现了严重失误。
A. 以至
B. 以致
C. 从而
D. 进而
答案：B
解析：引出不好的结果，用“以致”。从而前面通常是方法或条件，引出积极的结果或目的。
---
两种观点______，形成了鲜明对比。
A. 迥然相反
B. 截然相反
C. 迥然相同
D. 截然一致
答案：B
解析：“迥然”只能说迥然不同、迥然有别，不能说迥然相反。
---
既要______安全底线，又要______发展活力，在统筹发展和安全中把握主动。
A. 筑牢　激发
B. 夯实　激活
C. 补齐　激励
D. 加固　焕发
答案：A
解析：“底线”搭配筑牢、守牢；“活力”搭配激发。
:::
