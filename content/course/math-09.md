“设未知数、列方程”是最通用的方法，但考试里经常遇到**未知数比方程多**的情况：两个未知数只有一个方程，三个未知数只有两个方程。这就是**不定方程**。它有无数组解，但题目里的未知数通常是**人数、箱数、件数**这样的正整数，再加上选项的帮助，往往只剩唯一答案。

## 一、不定方程的三种解法

先看系数和常数，选最快的特性：

| 方程特点 | 用什么 | 例子 |
|---|---|---|
| 某个系数与常数项有**公因数** | **整除特性** | 3x + 8y = 60：3x、60 都是 3 的倍数 → 8y 是 3 的倍数 → y 是 3 的倍数 |
| 系数**一奇一偶** | **奇偶特性** | 7x + 4y = 52：4y、52 都是偶数 → 7x 是偶数 → x 是偶数 |
| 某个系数尾数是 **5 或 0** | **尾数特性** | 11x + 5y = 89：5y 的尾数是 0 或 5 → 11x 的尾数是 9 或 4 |
| 以上都不明显 | **代入排除** | 用选项代入，或从小到大枚举 |

:::key 解不定方程的口诀
**先看整除，再看奇偶，系数带 5 看尾数，最后代入排除。** 求出一组解后，要回到题目检查“都是正整数”“x 比 y 大”这类附加条件。
:::

:::example 尾数特性
大盒每盒装 11 个零件，小盒每盒装 5 个零件，89 个零件恰好装满若干个大盒和小盒。大盒、小盒一共有多少个？

A. 11　B. 12　C. 13　D. 14
--- 列方程
设大盒 x 个、小盒 y 个：11x + 5y = 89（x、y 为正整数）。
--- 看尾数
5y 的尾数只能是 0 或 5，所以 11x 的尾数是 9 或 4。
11x ≤ 89，x ≤ 8。11x 尾数为 9 需要 x 尾数为 9（不行）；尾数为 4 需要 x = 4。
--- 求解
x = 4 时，5y = 89 − 44 = 45，y = 9。共 4 + 9 = **13** 个，答案 **C**。
:::

:::example 整除特性 + 附加条件
采购 A、B 两种设备，A 每台 3 万元，B 每台 8 万元，共花 60 万元，两种都买了，且 A 的台数多于 B。B 买了几台？

A. 2　B. 3　C. 4　D. 6
--- 列方程、看整除
3x + 8y = 60。3x 和 60 都能被 3 整除，所以 8y 能被 3 整除，**y 是 3 的倍数**。
--- 枚举
y = 3：3x = 36，x = 12；y = 6：3x = 12，x = 4。
--- 用附加条件
要求 x > y，只有 x = 12、y = 3 满足。答案 **B**。
:::

## 二、不定方程组

### 1. 未知数要求是整数：先消元

三个未知数、两个方程：**先消掉一个未知数**，变成一个二元不定方程，再用上面的特性求解。

:::example 百钱百鸡（《张丘建算经》）
公鸡每只 5 钱，母鸡每只 3 钱，小鸡 3 只 1 钱。用 100 钱买 100 只鸡，三种都要买，且公鸡比母鸡多。三种鸡各买几只？
--- 列方程组
公鸡 x、母鸡 y、小鸡 z：
x + y + z = 100；5x + 3y + z/3 = 100。
--- 消去 z
第二式乘 3：15x + 9y + z = 300，减去第一式：14x + 8y = 200，即 **7x + 4y = 100**。
--- 用特性
4y、100 都是 4 的倍数，所以 7x 是 4 的倍数，**x 是 4 的倍数**。
x = 4，y = 18；x = 8，y = 11；x = 12，y = 4。
--- 附加条件
公鸡比母鸡多：x = 12、y = 4，z = 100 − 16 = **84**。
验算：5 × 12 + 3 × 4 + 84 ÷ 3 = 60 + 12 + 28 = 100 ✓。
:::

### 2. 未知数不要求是整数：赋零法 / 配系数

当未知数是**单价**这类可以是小数的量，而题目只问“**各买一件共多少钱**”（即 x + y + z），可以直接：

- **赋零法**：令系数最“麻烦”的那个未知数为 0，解出另外两个，再求和；
- **配系数法**：找两个数 p、q，使 p × 方程一 + q × 方程二 正好等于 x + y + z。

:::example 赋零法
买 3 支笔、7 个本子、1 个文件袋共 32 元；买 4 支笔、10 个本子、1 个文件袋共 43 元。笔、本子、文件袋各买 1 个共多少元？

A. 8　B. 10　C. 11　D. 12
--- 列方程
3x + 7y + z = 32；4x + 10y + z = 43。
--- 赋零
令 y = 0：3x + z = 32，4x + z = 43，相减得 x = 11，z = −1。
--- 求和
x + y + z = 11 + 0 − 1 = **10**，答案 **B**。
（单价出现负数不要紧：赋零只是计算技巧，x + y + z 的值与 y 取多少无关。）
--- 验证：配系数
3 × 方程一 − 2 × 方程二：(9x + 21y + 3z) − (8x + 20y + 2z) = x + y + z = 96 − 86 = **10** ✓。
:::

:::warn 赋零法的前提
只有当题目问的是**“几个未知数的固定组合”**（如各买一件的总价），且这个组合确实能由两个方程配出来时，才可以赋零。题目问“笔的单价是多少”时**不能**赋零——那时答案不唯一，必须找别的条件。
:::

## 三、随堂练习

:::quiz 不定方程小测
小李用 76 元买了单价 5 元和 7 元的两种票，两种都买了，他最多买了多少张票？
A. 12
B. 13
C. 14
D. 15
答案：C
解析：5x + 7y = 76。7y 的尾数要使 76 − 7y 的尾数为 0 或 5，即 7y 尾数为 6 或 1，y = 8 或 3。y = 3 时 x = 11，共 14 张；y = 8 时 x = 4，共 12 张。最多 14 张。
---
购买 2 个 A、3 个 B、1 个 C 共 30 元；购买 3 个 A、5 个 B、1 个 C 共 43 元。A、B、C 各买 1 个共多少元？
A. 15
B. 16
C. 17
D. 18
答案：C
解析：赋零：令 B = 0，2A + C = 30，3A + C = 43，A = 13，C = 4，和为 17。或配系数：2 × 式一 − 式二 = A + B + C = 60 − 43 = 17。
---
方程 11x + 5y = 89 求正整数解，最快的突破口是：
A. 奇偶特性
B. 尾数特性
C. 3 的整除特性
D. 只能逐个代入
答案：B
解析：5y 的尾数只有 0 和 5 两种，立刻锁定 11x 的尾数。
---
关于不定方程，下列说法正确的是：
A. 不定方程一定有唯一解
B. 未知数是单价时，问各买一件的总价，可以赋零
C. 用奇偶特性时，两个系数必须都是奇数
D. 不定方程组只能用代入排除
答案：B
解析：A 错，不定方程一般有多组解，要靠整数条件和附加条件确定；C 错，奇偶特性要求系数一奇一偶才好用。
:::

:::fill 填一填
7x + 4y = 100（x、y 为正整数）中，x 一定是[[4]]的倍数；14x + 8y = 200 两边同除以[[2]]就得到这个方程。
:::

:::cards 本课记忆卡
不定方程 :: 未知数个数多于方程个数，靠“正整数”和附加条件定解
不定方程解法顺序 :: 先整除，再奇偶，系数带 5 或 0 看尾数，最后代入
整除特性解不定方程 :: 某系数与常数项有公因数 → 另一项也必须含这个因数
奇偶特性解不定方程 :: 系数一奇一偶时用
不定方程组（整数） :: 先消元，化成二元不定方程
赋零法 :: 未知数可为小数、只问固定组合（如各买一件）时，令一个未知数为 0
配系数法 :: p × 式一 + q × 式二 = 所求组合
百钱百鸡化简结果 :: 7x + 4y = 100，x 是 4 的倍数
