贯彻执行题（俗称“公文题”）让你以某个身份，写一篇实用文：倡议书、讲话稿、情况报告、宣传稿……它的得分 = **格式分 + 内容分 + 语言分**。这一课先把常见文种的格式记牢。

## 一、看清三个要素

:::key 身份、对象、目的
- **身份**：你是谁（街道工作人员？市政府调研组？）——决定口吻；
- **对象**：写给谁看（全体市民？领导？企业？）——决定语言风格；
- **目的**：要达到什么效果（号召行动？汇报情况？宣传推广？）——决定内容重点。
:::

## 二、常见文种的格式

:::tabs
--- 倡议书
**标题**：《倡议书》或《关于……的倡议书》
**称谓**：“广大市民朋友们：”
**正文**：背景和意义（为什么倡议）→ 倡议事项（分条，“一是……”）→ 号召结尾（“让我们行动起来……”）
**落款**：发起单位 + 日期（右下角）
--- 讲话稿 / 发言稿
**标题**：《在……上的讲话》（有时可省略）
**称谓**：“各位领导、同志们：”“各位村民朋友：”
**正文**：开头问候、说明讲话缘由 → 主体（分层次讲）→ 结尾（表态、号召、致谢）
**结尾**：“谢谢大家！”
**特点**：口语化，有现场感，多用“我们”。
--- 情况报告 / 调研报告
**标题**：《关于……的情况报告》《关于……的调研报告》
**主送**：报告给谁（“市委、市政府：”，有时可省略）
**正文**：基本情况 → 主要做法 / 存在问题 → 原因分析 → 对策建议
**落款**：报告单位 + 日期
**特点**：客观、准确、条理清楚，少用形容词。
--- 宣传稿 / 新闻稿
**标题**：要醒目，可以用主副标题
**正文**：导语（一句话说清何时、何地、何人、何事）→ 主体（事件经过、做法成效、人物话语）→ 结尾（意义或展望）
**特点**：生动，有事实，有吸引力。
--- 汇报提纲
**标题**：《关于……的汇报提纲》
**正文**：简短开头 → 分条列出要点（“一、……二、……”），每条一句话概括 + 简要说明
**特点**：简洁，只列要点，不展开。
--- 编者按 / 短评
**编者按**：附在文章前，说明转载原因、文章要点、读者应注意什么，篇幅短。
**短评**：观点鲜明的短小评论，“观点 + 分析 + 号召”。
:::

:::match 文种和用途
号召公众共同行动 :: 倡议书
在会议上口头讲话 :: 讲话稿
向上级汇报情况和问题 :: 情况报告
对外宣传一项工作或成就 :: 宣传稿
向领导简要汇报的要点 :: 汇报提纲
附在转载文章前的说明 :: 编者按
:::

## 三、格式要点填空

:::fill 倡议书的格式
倡议书的标题可以写作《关于……的[[倡议书]]》；称谓要[[顶格]]写，如“广大市民朋友们：”；正文先写背景和[[意义]]，再分条写倡议事项，最后用[[号召]]性的话结尾；落款写发起单位和[[日期|时间]]。
:::

:::tip 字数怎么分配
公文题多在 400—500 字。格式（标题、称谓、落款）约占 30 字；开头背景 50—80 字；主体（分条内容）占 70% 以上；结尾 30—50 字。**内容才是得分大头，开头结尾不要写太长。**
:::

以“县农业农村局调研组”的身份向县政府反映高标准农田建设中的问题，最合适的文种是：
A. 倡议书
B. 调研报告
C. 宣传稿
D. 公开信
答案：B
---
下列关于讲话稿的说法，**错误**的是：
A. 要有称谓，如“各位村民朋友”
B. 语言要口语化、有现场感
C. 结尾可以写“谢谢大家”
D. 必须使用大量专业术语，体现水平
答案：D
解析：讲话稿要贴合听众，对群众讲话尤其要通俗易懂。
