科技题有两类：一类是**生活中的物理、化学、生物现象**，可以用中学知识推理；另一类是**我国重大科技成就**，需要记忆。

## 一、物理：光、声、热、力

:::tabs
--- 光
| 原理 | 现象 |
|---|---|
| 光沿直线传播 | 影子、小孔成像、日食月食、“一叶障目” |
| 光的反射 | 平面镜成像、水中倒影、“镜花水月” |
| 光的折射 | 筷子在水中“折断”、“潭清疑水浅”、海市蜃楼 |
| 光的色散 | 彩虹（白光分解为七色光） |
--- 声
- 声音由物体**振动**产生，**不能在真空中传播**；
- 音调由**频率**决定（“高音”），响度由**振幅**决定（“大声”），音色由发声体本身决定（“闻其声知其人”）；
- 回声：声音遇到障碍物反射回来，蝙蝠靠超声波回声定位。
--- 热（物态变化）
| 变化 | 吸放热 | 例子 |
|---|---|---|
| 熔化（固→液） | 吸热 | 冰化成水 |
| 凝固（液→固） | 放热 | 水结冰 |
| 汽化（液→气） | 吸热 | 洒水降温、出汗散热 |
| 液化（气→液） | 放热 | 露、“白气”、眼镜起雾 |
| 升华（固→气） | 吸热 | 樟脑丸变小、干冰人工降雨 |
| 凝华（气→固） | 放热 | 霜、雾凇、窗户上的冰花 |
--- 力
- 惯性：一切物体保持原有运动状态的性质，质量越大惯性越大（系安全带防惯性伤害）；
- 压强：压力一定时，受力面积越小压强越大（刀刃磨薄、图钉做尖）；
- 液体压强随深度增加而增大（大坝下宽上窄）；
- 流速越大的地方压强越小（站台安全线、飞机升力）。
:::

:::warn 最容易错的
“白气”不是水蒸气（水蒸气看不见），而是水蒸气**液化**成的小水珠；霜是**凝华**而不是凝固。
:::

## 二、化学与生活

- **燃烧的三个条件**：可燃物、氧气（空气）、温度达到着火点；灭火就是破坏其中之一：
  - 油锅着火 → 盖锅盖（隔绝氧气），**不能泼水**；
  - 电器着火 → 先**切断电源**，再用干粉灭火器；
  - 森林火灾 → 开辟隔离带（移除可燃物）；
- 干冰是固态二氧化碳，升华吸热，用于人工降雨和舞台烟雾；
- 煤气中毒是**一氧化碳**中毒，它与血红蛋白结合，使人缺氧；
- 食品干燥剂多为生石灰（氧化钙），遇水放热，不可食用。

## 三、生物与健康

:::cards 维生素与疾病
缺维生素 A :: 夜盲症
缺维生素 B1 :: 脚气病（神经炎）
缺维生素 C :: 坏血病
缺维生素 D :: 佝偻病、骨质疏松
缺铁 :: 缺铁性贫血
缺碘 :: 地方性甲状腺肿（大脖子病）
:::

- 人体最大的消化腺是**肝脏**；最大的器官是**皮肤**；
- 抗生素只对**细菌**感染有效，对病毒感染（如普通感冒）无效；
- 疫苗的原理是让人体产生**特异性免疫**（抗体）；
- 心肺复苏：胸外按压与人工呼吸的比例为 **30∶2**，按压深度 5—6 厘米，频率每分钟 100—120 次。
