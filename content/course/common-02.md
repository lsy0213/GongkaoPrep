宪法是国家的根本法，常识判断里几乎每年都有宪法题，主要考**国家制度、国家机构、公民的基本权利和义务**。

## 一、宪法的基本情况

- 现行宪法是 **1982 年**宪法（五届全国人大五次会议通过），先后在 1988、1993、1999、2004、2018 年进行了 **5 次修正**；
- 2018 年修宪：把“中国共产党领导是中国特色社会主义最本质的特征”写入宪法**正文**第一条；增加“监察委员会”一节；把科学发展观、习近平新时代中国特色社会主义思想写入序言；
- **12 月 4 日**是国家宪法日；国家工作人员就职时应当依照法律规定公开进行宪法宣誓。

:::tabs 宪法和法律的区别
--- 修改程序
- **宪法修改**：由全国人大常委会或者 **1/5 以上**的全国人大代表提议，并由全国人大以全体代表的 **2/3 以上**多数通过；
- **法律**：由全国人大以全体代表的**过半数**通过（常委会制定的法律由常委会全体组成人员过半数通过）。
--- 效力
宪法具有**最高法律效力**，一切法律、行政法规、地方性法规都不得同宪法相抵触。
--- 解释与监督
**全国人大常委会**解释宪法；全国人大和全国人大常委会监督宪法的实施。
:::

## 二、国家的根本制度

| 项目 | 内容 |
|---|---|
| 国家性质（国体） | 工人阶级领导的、以工农联盟为基础的人民民主专政的社会主义国家 |
| 根本制度 | 社会主义制度 |
| 根本政治制度（政体） | 人民代表大会制度 |
| 基本政治制度 | 中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度 |
| 基本经济制度 | 公有制为主体、多种所有制经济共同发展，按劳分配为主体、多种分配方式并存，社会主义市场经济体制 |

:::warn 易混
“根本制度”是**社会主义制度**；“根本政治制度”是**人民代表大会制度**。
:::

## 三、国家机构

| 机构 | 性质 | 要点 |
|---|---|---|
| 全国人民代表大会 | **最高国家权力机关** | 每届 5 年，每年举行一次会议；修改宪法、制定基本法律；选举国家主席、副主席，决定国务院总理人选 |
| 全国人大常委会 | 全国人大的常设机关 | 解释宪法和法律、监督宪法实施；全国人大闭会期间行使部分职权 |
| 国家主席 | 国家元首 | 年满 **45 周岁**、有选举权和被选举权的公民可被选为国家主席 |
| 国务院 | 中央人民政府，**最高国家权力机关的执行机关**，**最高国家行政机关** | 实行**总理负责制**；总理、副总理、国务委员连续任职不得超过两届 |
| 中央军事委员会 | 领导全国武装力量 | 实行**主席负责制** |
| 国家监察委员会 | **最高监察机关** | 2018 年设立；对全国人大和全国人大常委会负责 |
| 最高人民法院 | **最高审判机关** | 监督地方各级法院的审判工作 |
| 最高人民检察院 | **最高检察机关**，国家的法律监督机关 | 领导地方各级检察院 |

:::match 国家机构和它的性质
全国人民代表大会 :: 最高国家权力机关
国务院 :: 最高国家行政机关
国家监察委员会 :: 最高监察机关
最高人民法院 :: 最高审判机关
最高人民检察院 :: 国家的法律监督机关
全国人大常委会 :: 解释宪法和法律
:::

## 四、公民的基本权利和义务

**基本权利**：

- 平等权：公民在法律面前一律平等；
- 政治权利和自由：年满 **18 周岁**的公民有选举权和被选举权（依法被剥夺政治权利的除外）；言论、出版、集会、结社、游行、示威的自由；
- 宗教信仰自由；
- 人身自由：人身自由、人格尊严、住宅不受侵犯，通信自由和通信秘密受法律保护；
- 社会经济权利：劳动的权利（**既是权利也是义务**）、休息的权利、获得物质帮助的权利；
- 文化教育权利：受教育的权利（**既是权利也是义务**）、进行科学研究和文艺创作的自由；
- 监督权：批评、建议、申诉、控告、检举的权利。

**基本义务**：维护国家统一和民族团结；遵守宪法和法律；维护祖国的安全、荣誉和利益；依法服兵役；依法纳税。

:::key 既是权利又是义务
**劳动**和**受教育**。（另外，夫妻双方有实行计划生育的义务；父母有抚养教育未成年子女的义务，成年子女有赡养扶助父母的义务。）
:::

:::quiz 小测
有权解释宪法的机关是：
A. 全国人民代表大会
B. 全国人大常委会
C. 最高人民法院
D. 国务院
答案：B
---
下列关于我国国家机构的说法，正确的是：
A. 国务院实行集体负责制
B. 中央军委实行主席负责制
C. 国家监察委员会对国务院负责
D. 最高人民检察院是最高审判机关
答案：B
解析：国务院实行总理负责制；国家监察委员会对全国人大及其常委会负责；最高人民法院才是最高审判机关。
---
下列哪项既是公民的权利，又是公民的义务？
A. 选举权
B. 受教育
C. 宗教信仰自由
D. 纳税
答案：B
解析：劳动和受教育既是权利又是义务；纳税只是义务。
