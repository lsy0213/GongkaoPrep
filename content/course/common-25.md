人文总览课列了最核心的文学常识（诗经楚辞、李杜、唐宋八大家、四大名著）。这一课按**时代顺序**把文学史串成一条线，补充流派、作家称号、“第一部”和外国文学，最后整理“诗句与作者”这一高频考法。

## 一、先秦到魏晋

| 时期 | 要点 |
|---|---|
| **先秦** | 《诗经》（第一部诗歌总集，现实主义源头，305 篇）；《楚辞》（屈原，浪漫主义源头）；诸子散文：《论语》（语录体）、《孟子》、《庄子》（想象奇特，寓言多）、《韩非子》；历史散文：《左传》（第一部详细的编年体史书）、《战国策》（国别体） |
| **两汉** | **汉赋**（司马相如、扬雄）；《史记》（纪传体通史）；《汉书》（纪传体断代史）；**乐府诗**，《孔雀东南飞》与北朝《木兰诗》合称“乐府双璧” |
| **魏晋** | **建安风骨**：“三曹”（曹操、曹丕、曹植）和建安七子；曹丕《典论·论文》是第一篇文学批评专论；**竹林七贤**（嵇康、阮籍等）；陶渊明开创**田园诗**（《归园田居》《桃花源记》）；谢灵运开创**山水诗** |
| **南北朝** | 刘勰《**文心雕龙**》（文学理论巨著）；钟嵘《诗品》；《世说新语》（志人小说） |

## 二、唐代：诗的高峰

:::tabs
--- 初唐与盛唐
- **初唐四杰**：王勃（《滕王阁序》）、杨炯、卢照邻、骆宾王；
- **山水田园诗派**：王维、孟浩然（“王孟”），王维“诗中有画，画中有诗”；
- **边塞诗派**：高适、岑参（“高岑”）、王昌龄（“七绝圣手”）、王之涣；
- **李白**（诗仙）：浪漫主义；**杜甫**（诗圣）：现实主义，“三吏三别”。
--- 中晚唐
- **白居易**：倡导**新乐府运动**，“文章合为时而著，歌诗合为事而作”；《长恨歌》《琵琶行》；
- **韩愈、柳宗元**：倡导**古文运动**；
- **刘禹锡**（诗豪）、**李贺**（诗鬼）、**贾岛**（“推敲”典故）；
- **小李杜**：李商隐、杜牧。
:::

## 三、宋元明清

| 时期 | 要点 |
|---|---|
| **宋词** | **婉约派**：柳永、晏殊、秦观、李清照（“易安体”）；**豪放派**：苏轼开创，辛弃疾发扬（“苏辛”） |
| **宋诗文** | 欧阳修领导诗文革新；**陆游**爱国诗人（存诗九千多首）；黄庭坚开创江西诗派；司马光《**资治通鉴**》（编年体通史） |
| **元曲** | 元曲四大家：关汉卿、马致远、郑光祖、白朴；王实甫《西厢记》；关汉卿《窦娥冤》；马致远《天净沙·秋思》 |
| **明清小说** | 四大名著；《聊斋志异》（蒲松龄，文言短篇）；《儒林外史》（吴敬梓，讽刺小说）；“三言二拍”（冯梦龙、凌濛初，白话短篇） |
| **明清戏曲** | 汤显祖《牡丹亭》；孔尚任《桃花扇》；洪昇《长生殿》 |

## 四、近现代文学

| 作家 | 代表作 | 关键词 |
|---|---|---|
| **鲁迅** | 《狂人日记》（第一篇现代白话小说）、《呐喊》《彷徨》、《阿 Q 正传》、散文集《朝花夕拾》、散文诗集《野草》 | 原名周树人 |
| **郭沫若** | 诗集《女神》 | 新诗奠基 |
| **茅盾** | 《子夜》 | 茅盾文学奖 |
| **巴金** | “激流三部曲”《家》《春》《秋》 | |
| **老舍** | 《骆驼祥子》《四世同堂》、话剧《茶馆》 | 人民艺术家 |
| **曹禺** | 话剧《雷雨》《日出》 | |
| **沈从文** | 《边城》 | 湘西 |
| **钱锺书** | 《围城》 | |
| **莫言** | 《红高粱家族》《蛙》 | 2012 年诺贝尔文学奖，第一位获奖的中国籍作家 |

:::tip 四川籍作家
巴金生于**成都**，郭沫若生于**乐山沙湾**，都是四川人；此外还有李劼人（成都，《死水微澜》）、艾芜（新都）、沙汀（安县）。古代的**李白**在四川江油（青莲乡）长大，**苏轼**是四川眉山人，杜甫在成都住过近四年（杜甫草堂）。
:::

## 六、诗句与作者

:::match 名句配作者
人生自古谁无死，留取丹心照汗青 :: 文天祥
先天下之忧而忧，后天下之乐而乐 :: 范仲淹
安得广厦千万间，大庇天下寒士俱欢颜 :: 杜甫
但愿人长久，千里共婵娟 :: 苏轼
生当作人杰，死亦为鬼雄 :: 李清照
位卑未敢忘忧国 :: 陆游

:::quiz 文学常识小测
下列作家与称号对应错误的是：
A. 李白——诗仙
B. 杜甫——诗圣
C. 李贺——诗佛
D. 刘禹锡——诗豪
答案：C
解析：李贺是“诗鬼”，王维是“诗佛”。
---
我国第一部纪传体通史和第一部编年体通史分别是：
A. 《史记》《资治通鉴》
B. 《汉书》《左传》
C. 《史记》《左传》
D. 《资治通鉴》《史记》
答案：A
解析：《左传》是编年体史书，但不是通史；《资治通鉴》是编年体通史。
---
开创田园诗的诗人是：
A. 谢灵运
B. 陶渊明
C. 王维
D. 孟浩然
答案：B
解析：谢灵运开创山水诗；王维、孟浩然是唐代山水田园诗派代表。
---
下列作品与作者对应正确的是：
A. 《子夜》——巴金
B. 《边城》——沈从文
C. 《雷雨》——老舍
D. 《围城》——茅盾
答案：B
---
莎士比亚的四大悲剧不包括：
A. 《哈姆雷特》
B. 《李尔王》
C. 《威尼斯商人》
D. 《麦克白》
答案：C
解析：《威尼斯商人》是喜剧。
:::
