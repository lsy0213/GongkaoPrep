申论阅卷人常说一句话：“**一看就是外行写的**”——用词口语化、提法不规范、对策说得太空。这一课解决“说得像”的问题：**规范词**（政策提法和动词搭配）、**金句**（开头、结尾、分论点可用的句子）、**人物素材**（大作文最常用的榜样人物）。

## 一、规范词：把大白话换成规范表达

| 大白话 | 规范表达 |
|---|---|
| 政府多管管 | 强化监管、压实主体责任、健全长效机制 |
| 让老百姓办事方便 | 优化政务服务，推进“高效办成一件事”，让数据多跑路、群众少跑腿 |
| 大家一起来 | 构建党委领导、政府负责、社会协同、公众参与的工作格局 |
| 给钱支持 | 加大财政投入，完善补贴、税收、金融等政策支持 |
| 找人才 | 引育并举，完善人才引进、培养、评价、激励机制 |
| 让人知道 | 加强宣传引导，营造全社会共同参与的良好氛围 |
| 用技术 | 以数字化赋能，运用大数据、人工智能提升精准度 |
| 看看效果 | 建立考核评估机制，把群众满意度作为重要评价标准 |

:::key 对策的“主体 + 动词 + 对象 + 目的”
规范的对策句有四个部分：**谁来做 + 做什么 + 对谁做 + 达到什么效果**。
例：“**街道**要**整合**闲置社区用房，**低价租给**早餐店、修补店等便民业态，**让居民在家门口享受便利服务**。”
:::

### 常用政策提法

- **工作理念**：以人民为中心；高质量发展；统筹发展和安全；因地制宜；
- **治理方式**：党建引领；共建共治共享；“枫桥经验”；网格化管理；接诉即办；
- **政务服务**：“放管服”改革；“高效办成一件事”；“最多跑一次”；一网通办；
- **经济发展**：新质生产力；构建全国统一大市场；优化营商环境；民营经济发展壮大；
- **发展规划**：“十五五”时期（2026—2030 年）。

## 二、金句：开头、结尾、过渡

:::tabs
--- 开头
- “治国有常，而利民为本。”
- “天下之势不盛则衰，天下之治不进则退。”
- “凡益之道，与时偕行。”（《周易》，适合改革、创新类）
- 时政型开头：“××是……的重要举措，关系……”
--- 分论点
- 讲坚持：“功成不必在我，功成必定有我。”
- 讲实干：“空谈误国，实干兴邦。”
- 讲基层：“郡县治，天下安。”
- 讲民生：“利民之事，丝发必兴；厉民之事，毫末必去。”
- 讲生态：“绿水青山就是金山银山。”
- 讲改革：“改革只有进行时，没有完成时。”
--- 结尾
- “道阻且长，行则将至；行而不辍，未来可期。”
- “山再高，往上攀，总能登顶；路再长，走下去，定能到达。”
- 展望型结尾：“我们有理由相信，……必将……”
:::

:::warn 金句的三条使用规则
1. **一篇作文 3—4 句就够**：开头一句、每个分论点段最多一句、结尾一句；
2. **必须写准**：记不清原文就不要用，错一个字比不用更扣印象分；
3. **引完要接分析**：金句是论据，不是结论，后面要接一两句解释它和观点的关系。
:::

## 三、人物素材

| 人物 | 事迹关键词 | 适用话题 |
|---|---|---|
| **焦裕禄** | 兰考治沙治碱，“心中装着全体人民，唯独没有他自己” | 干部作风、为民服务 |
| **谷文昌** | 东山岛植树防风固沙，“不带领群众把风沙制服，就让风沙把我埋掉” | 生态、久久为功 |
| **杨善洲** | 退休后扎根大亮山义务植树 20 余年 | 生态、奉献 |
| **黄文秀** | 北京师范大学研究生，回乡任驻村第一书记，牺牲在扶贫路上 | 乡村振兴、青年担当 |
| **张桂梅** | 创办云南华坪女子高中，帮助 2000 多名女孩走出大山 | 教育、奉献 |
| **廖俊波** | “樵夫书记”，为政清廉、实干担当 | 干部作风、担当 |
| **袁隆平** | 杂交水稻，“禾下乘凉梦” | 科技创新、粮食安全 |
| **南仁东** | 二十余年建成“中国天眼”FAST | 科技创新、坚守 |
| **黄大年** | 放弃国外优厚条件回国，深地探测 | 科技报国 |
| **樊锦诗** | “敦煌的女儿”，守护敦煌莫高窟 | 文化传承 |
| **王继才** | 夫妻守卫开山岛 32 年 | 坚守、爱国 |
| **张富清** | 战斗英雄，深藏功名六十多年，扎根山区 | 初心、奉献 |

:::tip 事例的写法
人物事例在作文里**只写两三句**：谁 + 做了什么（关键细节或数字）+ 体现了什么。例如：“南仁东二十余年如一日，踏遍贵州数百个洼地，最终建成世界最大单口径射电望远镜。这份坚守，正是科技工作者‘十年磨一剑’的生动写照。”
:::

C. 希望大家都重视起来
D. 一定要解决好这个问题
答案：B

A. 每段都引用两三句名言

C. 引用后用一两句话分析它与观点的关系
D. 名言放在结尾代替结论
答案：C
