“科技常识总览”过了一遍光、声、热、力的基本现象。这一课把**物理**和**化学**往深处讲一层：**力学和简单机械、电与磁、光学器件、常见气体和金属、酸碱与生活化学**，再加一组常考的“**诗句里的物理化学**”。科技题最大的特点是**能用原理推出来**，所以每个知识点都先讲原理，再举生活例子。

## 一、力学

### 1. 牛顿三定律与惯性

| 定律 | 内容 | 生活例子 |
|---|---|---|
| 第一定律（惯性定律） | 物体不受外力时，保持静止或匀速直线运动状态 | 急刹车时人向前倾；拍打衣服除尘；跳远助跑 |
| 第二定律 | 加速度与合外力成正比，与质量成反比（F = ma） | 同样的力推空车比推满车跑得快 |
| 第三定律 | 作用力与反作用力大小相等、方向相反、作用在两个物体上 | 划船时桨向后推水，船向前进；火箭升空 |

:::warn 惯性只和质量有关
惯性是物体的**固有属性**，大小只由**质量**决定，与速度无关。“由于惯性的作用”“受到惯性”的说法都是错的，应说“由于**具有**惯性”。
:::

### 2. 摩擦力与压强

- **增大摩擦**：增大压力、增大接触面粗糙程度（鞋底花纹、雪天撒沙、轮胎防滑链）；
- **减小摩擦**：减小压力、使接触面光滑、变滑动为**滚动**（轴承）、使接触面分离（加润滑油、气垫船、磁悬浮）；
- **压强** = 压力 ÷ 受力面积：书包带做宽、坦克用履带、铁轨铺枕木是**减小**压强；刀刃磨薄、图钉做尖、啄木鸟的尖嘴是**增大**压强。

### 3. 杠杆

:::key 三类杠杆
| 类型 | 特点 | 例子 |
|---|---|---|
| **省力杠杆** | 动力臂 > 阻力臂，省力但费距离 | 羊角锤、瓶起子、钳子、撬棍、独轮车、铡刀 |
| **费力杠杆** | 动力臂 < 阻力臂，费力但省距离 | **筷子、镊子、钓鱼竿**、理发剪刀、扫帚、人的前臂 |
| **等臂杠杆** | 动力臂 = 阻力臂 | **天平**、跷跷板 |
:::

- 定滑轮**不省力**，但能改变力的方向（旗杆顶端）；动滑轮**省一半力**，但不能改变方向。

### 4. 浮力与大气压

- **阿基米德原理**：浸在液体中的物体受到的浮力等于它排开液体所受的重力；
- 轮船做成空心的，增大排水量；**潜水艇靠改变自身重力**实现上浮下沉；热气球、飞艇靠充入密度小于空气的气体；
- 人在死海里不会沉下去：死海含盐量高，海水**密度大**，浮力大；
- **马德堡半球实验**证明了大气压的存在；**托里拆利实验**测出大气压的值；
- 海拔越高，气压越低，水的**沸点越低**——高原上要用**高压锅**才能煮熟饭；
- 吸管喝饮料、吸盘挂钩、钢笔吸墨水都利用了**大气压**；
- **流速越大，压强越小**：火车站台设安全线；飞机机翼上凸下平产生升力；两船并行容易相撞；“八月秋高风怒号，卷我屋上三重茅”（屋顶上方空气流速大、压强小）。

## 二、电与磁

| 知识点 | 内容 |
|---|---|
| 导体与绝缘体 | 金属、人体、大地、石墨、酸碱盐溶液是导体；橡胶、玻璃、陶瓷、塑料、干木头是绝缘体 |
| 安全电压 | **不高于 36 伏** |
| 安全用电原则 | **不接触低压带电体，不靠近高压带电体**；发现有人触电先**切断电源**或用干木棍挑开电线，不能直接用手拉 |
| 雷雨天 | 不要在大树下避雨；**避雷针**（富兰克林发明）把电荷引入大地 |
| 电磁感应 | **法拉第**发现，磁生电；应用：**发电机**、动圈式话筒 |
| 通电导体在磁场中受力 | 电生运动；应用：**电动机** |
| 电流的磁效应 | **奥斯特**发现，电生磁；应用：电磁铁、电磁继电器 |
| 电磁炉 | 利用电磁感应产生涡流加热，必须用**铁质**等导磁锅具 |
| 微波炉 | 微波使食物中的水分子振动发热；**不能用金属容器**（会打火），不能加热带壳鸡蛋（会爆裂） |
| 磁悬浮列车 | 利用磁极间相互作用使列车悬浮，**减小摩擦** |

:::match 发现和应用
法拉第电磁感应 :: 发电机
通电导体在磁场中受力 :: 电动机
奥斯特电流磁效应 :: 电磁铁
光的全反射 :: 光导纤维
超声波回声定位 :: 声呐、B 超
:::

## 三、声与光的应用

:::tabs
--- 声
- **超声波**（频率高于 20000 Hz）：方向性好、穿透力强——**B 超**、**声呐**、超声波清洗、蝙蝠回声定位；
- **次声波**（低于 20 Hz）：**地震、海啸、台风**会产生，可用于预报；
- 控制噪声的三条途径：在**声源处**（禁鸣喇叭、消声器）、在**传播过程中**（隔音墙、植树）、在**人耳处**（戴耳塞）；
- **多普勒效应**：声源靠近时音调变高、远离时变低（救护车鸣笛声由高变低）。
--- 透镜与视力
- **凸透镜**：会聚光线。照相机（倒立缩小实像）、投影仪（倒立放大实像）、**放大镜**（正立放大虚像）；
- **近视**：晶状体太厚，像成在视网膜**前方**，戴**凹透镜**矫正；
- **远视、老花**：像成在视网膜**后方**，戴**凸透镜**矫正；
- **光导纤维**利用光的**全反射**传输信号。
--- 看不见的光
- **紫外线**：杀菌消毒、**验钞**、促进人体合成**维生素 D**；过量照射伤害皮肤；
- **红外线**：**遥控器**、夜视仪、**红外测温**、浴霸取暖；一切物体都在辐射红外线；
- **天空呈蓝色**：大气对波长短的蓝光**散射**更强；**朝霞、夕阳呈红色**：阳光穿过的大气层更厚，蓝光被散射掉，剩下波长长的红光。
:::

## 四、热学

- **热传递三种方式**：**传导**（铁勺变烫）、**对流**（暖气片装在下方、空调装在上方）、**辐射**（晒太阳）；
- **保温瓶**：瓶胆双层玻璃中间抽**真空**（阻断传导和对流），内壁**镀银**（反射热辐射）；
- **水的比热容大**：沿海地区昼夜温差比内陆小；用水做暖气和发动机的冷却剂；
- **热胀冷缩**：铁轨之间留缝隙、电线夏松冬紧；
- 冬天户外铁栏杆比木栏杆“冷”：铁导热快，从手上带走的热量多，两者温度其实相同。

## 五、化学

### 1. 常见气体

| 气体 | 性质 / 用途 |
|---|---|
| **氧气** | 助燃、供给呼吸（本身**不能燃烧**） |
| **氮气** | 空气中含量最多（约 78%）；化学性质稳定，作**食品包装保护气**；**液氮**用于冷冻 |
| **二氧化碳** | 灭火、**温室气体**；固态叫**干冰**，用于人工降雨 |
| **一氧化碳** | 有毒，与血红蛋白结合导致**煤气中毒**；无色无味 |
| **稀有气体** | 化学性质稳定；通电发出有色光，用于**霓虹灯**；**氦气**密度小且不可燃，用于填充气球（比氢气安全） |
| 氢气 | 最轻的气体，燃烧产物只有水，**清洁能源** |
| **甲烷** | **天然气、沼气、瓦斯**的主要成分；瓦斯爆炸就是甲烷与空气混合遇明火爆炸 |
| 臭氧 | 平流层臭氧吸收紫外线，保护地球生物 |

### 2. 金属之最

:::cards 金属之最
地壳中含量最多的金属元素 :: 铝（地壳中含量最多的元素是氧）
人体中含量最多的金属元素 :: 钙
导电、导热性最好的金属 :: 银
熔点最低的金属 :: 汞（水银，常温下唯一的液态金属）
熔点最高的金属 :: 钨（用作灯丝）
硬度最大的金属 :: 铬
目前世界年产量最高的金属 :: 铁
:::

- 铁生锈的条件：同时接触**水和氧气**；防锈方法：刷漆、涂油、镀其他金属、制成不锈钢；
- 银器变黑是生成了**硫化银**；古人“银针验毒”实际上验的是砒霜中混有的**硫化物**。

### 3. 酸碱与生活化学

| 场景 | 原理 |
|---|---|
| 胃酸过多 | 胃酸主要是**盐酸**，可服用含氢氧化铝或**小苏打**（碳酸氢钠）的药物中和 |
| 蒸馒头 | 发酵产生酸，加入**小苏打**或纯碱中和并产生二氧化碳，使馒头松软 |
| 蚊虫叮咬 | 蚊虫分泌**蚁酸**（酸性），涂**肥皂水**或稀氨水（碱性）止痒 |
| 除水垢 | 水垢主要是碳酸钙，用**食醋**溶解 |
| **洁厕灵 + 84 消毒液** | 洁厕灵含**盐酸**，84 消毒液含**次氯酸钠**，混用会产生有毒的**氯气**，**绝对不能混用** |
| 净水 | **明矾**使水中杂质凝聚沉降；**活性炭**吸附色素和异味 |
| 点豆腐 | **卤水**（氯化镁）或**石膏**（硫酸钙）使豆浆中的蛋白质凝聚 |
| 加碘盐 | 加入的是**碘酸钾**，烹调时宜在菜快出锅时加入 |
| 腌菜、隔夜菜 | 可能产生**亚硝酸盐**，过量食用导致中毒 |
| 新装修房屋 | 主要污染物是**甲醛**、苯，应通风后再入住 |
| 烟花颜色 | **焰色反应**：钠呈黄色、钾呈紫色、铜呈绿色、锶呈红色 |
| 黑火药 | “一硫二硝三木炭”：硫黄、硝石（硝酸钾）、木炭 |

:::warn 两个“灭火”易错点
- **油锅着火**：盖上锅盖（隔绝氧气）或放入青菜，**不能用水浇**（油浮在水面上继续燃烧并飞溅）；
- **电器着火**：先**切断电源**，再用干粉或二氧化碳灭火器，不能用水；
- 图书、档案、精密仪器着火，用**二氧化碳灭火器**（不留痕迹）。
:::

## 六、诗句里的物理化学

:::cards 诗句中的科学
坐地日行八万里，巡天遥看一千河 :: 地球自转（赤道周长约 4 万千米，即 8 万里）
孤帆一片日边来 / 两岸青山相对出 :: 运动的相对性（以船为参照物）
潭清疑水浅 :: 光的折射
楼台倒影入池塘 :: 光的反射（平面镜成像）
不敢高声语，恐惊天上人 :: 响度（“高声”指声音大）
路人借问遥招手，怕得鱼惊不应人 :: 液体（水）能传声
八月秋高风怒号，卷我屋上三重茅 :: 流速大的地方压强小
千锤万凿出深山，烈火焚烧若等闲 :: 石灰石（碳酸钙）高温煅烧生成生石灰
春蚕到死丝方尽 :: 蚕丝的主要成分是蛋白质
野火烧不尽，春风吹又生 :: 燃烧与植物再生；草木灰含钾肥
墙角数枝梅，遥知不是雪，为有暗香来 :: 分子在不停地做无规则运动
:::

## 七、随堂练习

下列工具中，属于费力杠杆的是：
A. 羊角锤
B. 瓶起子
C. 镊子
D. 钳子
答案：C

高原上煮饭要用高压锅，是因为：
A. 高原气压高，水的沸点高

答案：B

发电机的工作原理是：
A. 电流的磁效应
B. 电磁感应
C. 通电导体在磁场中受力

答案：B
---
近视眼应佩戴：
A. 凸透镜
B. 凹透镜
C. 平面镜
D. 三棱镜

答案：A
