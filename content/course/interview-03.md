组织计划题让你“组织一次调研 / 宣传 / 活动 / 培训”。很多人答成流水账：“首先成立小组，然后制定方案，最后总结”——这样只能拿中下档分数。高分答案的关键是**针对性**和**亮点**。

## 一、常见类型

| 类型 | 例子 |
|---|---|
| 调研 | “领导让你调研本市老旧小区加装电梯的情况，你怎么组织？” |
| 宣传 | “组织一次针对老年人的防诈骗宣传活动。” |
| 活动 | “单位组织青年干部开展志愿服务活动，你负责，怎么做？” |
| 培训 | “为新入职的同事组织一次业务培训。” |
| 会议 | “组织一次企业座谈会，听取企业对营商环境的意见。” |

## 二、答题框架

:::key 目的 → 准备 → 实施 → 总结
1. **目的意义**（一两句，不要长）：为什么做这件事；
2. **准备**：摸清对象的情况和需求、制定方案、协调人员物资场地；
3. **实施**（重点，占一半以上时间）：分环节写，**每个环节说清“做什么、怎么做、为什么这样做”**，设计一两个亮点；
4. **总结**：收集反馈、形成报告、建立长效机制。
:::

:::tip 怎么做出针对性
**先分析对象**：老年人 → 不会用智能手机、喜欢面对面交流、怕麻烦 → 宣传形式用“案例讲解 + 现场演示 + 发放大字版手册”，地点选在社区活动室和菜市场。

同样是宣传，对年轻人就要换成短视频、线上互动。**对象不同，方式就不同**——这就是针对性。
:::

:::warn 流水账的典型表现
“首先，我会成立工作小组；其次，制定详细方案；然后，按方案实施；最后，及时总结。”——每一句都对，但每一句都适用于任何活动，等于什么都没说。
:::

## 三、开口练

:::speak 组织计划（宣传）
社区里不少老年人遭遇过电信诈骗，单位让你组织一次针对老年人的防诈骗宣传活动，你会怎么做？
--- 参考思路
**目的**：提升老年人的防诈骗意识和能力，守住他们的“养老钱”。

**准备**：
- 和社区、派出所对接，了解本社区老年人最常遇到的诈骗类型（保健品、冒充公检法、“以房养老”等）；
- 邀请民警准备真实案例，制作大字版防诈手册和顺口溜。

**实施**：
- **讲案例**：在社区活动室请民警用身边的真实案例讲解骗局套路，讲完让老人提问；
- **演情景**：请志愿者现场表演“冒充子女借钱”的情景剧，让老人当场辨别，答对的发小礼品；
- **教技能**：手把手帮老人在手机上安装“国家反诈中心”App，设置陌生来电提醒；
- **进家门**：对行动不便、独居的老人，由网格员上门讲解，同时请子女加入“家庭反诈群”。

**总结**：活动后回访了解效果，收集新出现的诈骗手法，形成常态化宣传机制，比如每月在社区公告栏更新“防骗提醒”。
:::

:::speak 组织计划（调研）
领导让你调研本区老旧小区加装电梯的推进情况，你会怎么开展？
--- 参考思路
**目的**：摸清加装电梯推进中的难点，为下一步工作提供依据。

**准备**：梳理已加装、正在加装、未加装小区的名单；确定调研内容（推进进度、资金、居民意见、施工问题）；设计问卷和访谈提纲。

**实施**：
- **分类调研**：选取进展快、进展慢、未启动三类小区各几个，对比找原因；
- **多方访谈**：走访居民（尤其是低层住户和高层老人，了解意见分歧）、物业、施工企业和街道；
- **数据分析**：统计资金来源、审批时长、居民同意率等数据。

**总结**：形成调研报告，提出可推广的经验（如“一楼补偿协商机制”“一站式审批”）和政策建议，报领导参考。
:::
