生物和医学题是常识里“最贴近生活”的一类：为什么香蕉放苹果旁边熟得快？流鼻血该仰头吗？抗生素能治感冒吗？这一课按“**植物与微生物—遗传—人体—营养—传染病与免疫—急救常识**”来讲，最后附上常用公共服务热线。很多题考的就是**生活中的误区**。

## 一、植物与微生物

### 1. 植物

- **光合作用**：在**叶绿体**中，利用光能把二氧化碳和水合成有机物，释放氧气；
- **呼吸作用**：在**线粒体**中分解有机物、释放能量，**白天黑夜都在进行**（所以夜间卧室不宜放大量绿植）；
- **蒸腾作用**：水分从叶片气孔散失，促进水和无机盐的运输；移栽树木时剪掉部分枝叶、选阴天移栽，是为了**减弱蒸腾作用**；
- 植物细胞特有：**细胞壁、叶绿体、液泡**（动物细胞没有）；
- **植物激素**：**生长素**使植物向光生长；**乙烯**促进果实**成熟**——把青香蕉和熟苹果放在一起，苹果释放的乙烯能催熟香蕉；
- 嫁接、扦插、组织培养属于**无性繁殖**，能保持母本的优良性状。

### 2. 微生物

| 类型 | 特点 | 应用 / 疾病 |
|---|---|---|
| **细菌** | 单细胞、没有成形的细胞核 | **乳酸菌**：酸奶、泡菜；**醋酸菌**：酿醋；根瘤菌：固氮；致病：结核、肺炎、霍乱 |
| **真菌** | 有成形的细胞核 | **酵母菌**：面包、馒头、酿酒；**青霉菌**：提取青霉素；蘑菇、木耳 |
| **病毒** | **没有细胞结构**，只能**寄生在活细胞**内 | 流感、新冠、艾滋病、狂犬病、乙肝 |

:::warn 抗生素不是“万能消炎药”
- 抗生素（如青霉素，1928 年**弗莱明**发现）只对**细菌**有效，对**病毒**无效——普通感冒多由病毒引起，滥用抗生素会导致**耐药菌**产生；
- “消炎药”的说法不准确，抗生素是抗菌药，必须凭处方使用。
:::

## 二、遗传

- 1953 年**沃森和克里克**提出 DNA **双螺旋结构**模型；
- **基因**是有遗传效应的 DNA 片段；人体细胞有 **23 对（46 条）染色体**；
- 性别决定：男性为 **XY**，女性为 **XX**，**生男生女由父亲的精子决定**；
- 禁止**近亲结婚**：近亲携带相同隐性致病基因的可能性大，后代患隐性遗传病的概率高（如白化病、色盲属于隐性遗传病）；
- **克隆**属于**无性繁殖**，1996 年英国诞生的**多莉羊**是第一只体细胞克隆哺乳动物；
- 杂交水稻利用的是**杂种优势**（袁隆平）；转基因技术是把一种生物的基因转入另一种生物。

## 三、人体

### 1. 人体之最

:::cards 人体之最
人体最大的器官 :: 皮肤
人体最大的消化腺 :: 肝脏（分泌胆汁，胆汁不含消化酶）
人体最大的内分泌腺 :: 甲状腺
消化和吸收的主要场所 :: 小肠
人体最坚硬的组织 :: 牙釉质
人体最大的细胞 :: 卵细胞
人体含量最多的物质 :: 水（约占体重 60%—70%）
:::

### 2. 血液与血型

| 成分 | 功能 |
|---|---|
| **红细胞** | 含**血红蛋白**，运输氧气；数量少或血红蛋白少导致**贫血** |
| **白细胞** | 吞噬病菌，**防御**；有炎症时数量增多 |
| **血小板** | **止血、凝血** |
| 血浆 | 运载血细胞，运输营养物质和代谢废物 |

- ABO 血型：A 型、B 型、AB 型、O 型；输血以输**同型血**为原则；
- 我国提倡 **18—55 周岁**健康公民自愿**无偿献血**，一次献血量一般为 200—400 毫升，适量献血不影响健康。

### 3. 激素

| 激素 | 分泌腺 | 分泌异常 |
|---|---|---|
| **胰岛素** | 胰岛 | 分泌不足 → **糖尿病**（胰岛素是唯一能降低血糖的激素） |
| **生长激素** | 垂体 | 幼年不足 → **侏儒症**（智力正常）；幼年过多 → **巨人症**；成年过多 → 肢端肥大症 |
| **甲状腺激素** | 甲状腺 | 幼年不足 → **呆小症**（智力低下）；过多 → **甲亢**；缺碘 → 地方性甲状腺肿 |
| 肾上腺素 | 肾上腺 | 使心跳加快、血压升高，应急反应 |

:::warn 侏儒症 vs 呆小症
都是“个子矮”，区别在**智力**：侏儒症（缺生长激素）**智力正常**；呆小症（幼年缺甲状腺激素）**智力低下**。
:::

### 4. 反射

- **非条件反射**：生来就有，如膝跳反射、婴儿吮吸、眨眼；
- **条件反射**：后天形成，如**望梅止渴**、谈虎色变、**画饼充饥**、老马识途；巴甫洛夫用狗进行条件反射实验。

## 四、营养与膳食

- **六大营养素**：**糖类、脂肪、蛋白质、维生素、水、无机盐**；膳食纤维被称为“第七营养素”；
- **糖类**是人体最主要的**供能**物质；**蛋白质**是建造和修复身体的重要原料；**脂肪**是储备能源；**维生素**和无机盐不提供能量，但不可缺少；
- 无机盐：缺**钙**→ 佝偻病、骨质疏松；缺**铁**→ 缺铁性贫血；缺**碘**→ 大脖子病；缺**锌**→ 生长发育迟缓、味觉减退；
- 《中国居民膳食指南》倡导：食物多样、合理搭配；吃动平衡；多吃蔬果、奶类、全谷、大豆；少盐少油、控糖限酒。

## 五、传染病与免疫

:::key 传染病流行的三个环节与预防
| 环节 | 预防措施 | 例子 |
|---|---|---|
| **传染源** | **控制传染源** | 隔离治疗患者、扑杀患病家禽 |
| **传播途径** | **切断传播途径** | 戴口罩、勤洗手、消毒、灭蚊 |
| **易感人群** | **保护易感人群** | **接种疫苗**、锻炼身体 |
:::

- **人体三道防线**：第一道是**皮肤和黏膜**；第二道是体液中的杀菌物质和**吞噬细胞**（前两道是**非特异性免疫**，生来就有）；第三道是免疫器官和免疫细胞，产生**抗体**（**特异性免疫**）；
- 接种疫苗属于特异性免疫；卡介苗预防**结核病**；
- **艾滋病**（HIV）通过**血液、性接触、母婴**传播，**不会**通过握手、拥抱、共餐、蚊虫叮咬传播；每年 **12 月 1 日**是世界艾滋病日；
- **狂犬病**一旦发病，病死率几乎为 100%，被犬猫咬伤后要及时处理伤口并接种疫苗。

## 六、急救常识

:::tabs 常见情况怎么处理
--- 流鼻血
**身体稍向前倾**，用手指捏住两侧鼻翼压迫止血 10 分钟左右，可冷敷额头。**不要仰头**，否则血液会流入咽喉，可能引起呛咳或误吸。
--- 烫伤
立即用**流动的冷水冲洗 15—30 分钟**降温；不要涂牙膏、酱油；起水泡不要刺破；严重的及时就医。
--- 被犬猫咬伤
立即用**肥皂水和流动清水交替冲洗伤口至少 15 分钟**，再用碘伏消毒，尽快到医院接种**狂犬病疫苗**。
--- 气道异物
用**海姆立克急救法**：站在患者背后，双手环抱其腰部，一手握拳顶在肚脐上方两横指处，另一手包住拳头，**快速向内向上**冲击，直到异物排出。
--- 心脏骤停
立即拨打 120，进行**心肺复苏**（胸外按压与人工呼吸比例 30∶2）；有条件的使用 **AED**（自动体外除颤器）。
--- 煤气中毒、中暑
- 煤气中毒：**迅速开窗通风**，把患者转移到空气新鲜处；不要在室内开关电器、点火；
- 中暑：转移到阴凉通风处，补充淡盐水，用湿毛巾擦身降温。
--- 骨折与出血
- 骨折：**不要随意移动**，先用夹板等**固定**再送医；
- 大出血：用干净布料直接**压迫止血**；四肢动脉出血可在伤口**近心端**加压。
:::
