模式分解考两个性质：**无损连接**（分解后再连接，数据不多不少）和**保持函数依赖**（原来的依赖在分解后的模式里都还在）。

## 一、无损连接的判断

:::key 分成两个关系时的快速判定
R 分解成 R1、R2，满足下面任意一条就是无损连接：
- (R1 ∩ R2) → (R1 − R2)，或
- (R1 ∩ R2) → (R2 − R1)

也就是：**两个关系的公共属性，是其中一个关系的码**。
:::

分成三个及以上关系时用**表格法**：每个分解一行、每个属性一列，属于该分解的属性填 a，不属于的填 b；反复按函数依赖把能推出的 b 改成 a，出现一整行全是 a 就是无损。

:::example 两个关系
R(A, B, C)，F = {A → B}，分解为 R1(A, B)、R2(A, C)，是否无损？
--- 公共属性
R1 ∩ R2 = {A}，R1 − R2 = {B}
--- 判断
A → B 成立，公共属性 A 是 R1 的码
--- 答案
**无损连接**。
:::

:::example 有损的情况
R(A, B, C)，F = {A → B}，分解为 R1(A, B)、R2(B, C)？
--- 公共属性
R1 ∩ R2 = {B}；B 推不出 A，也推不出 C
--- 答案
**有损**：连接后会产生多余的元组。
:::

## 二、保持函数依赖的判断

把原来的每个依赖拿出来，看它是否能在**某一个分解后的模式里**（或由各分解的依赖推出）。

:::example 保持函数依赖
R(A, B, C)，F = {A → B, B → C}，分解为 R1(A, B)、R2(A, C)：
--- 逐个看
A → B 在 R1 里；B → C：B 和 C 不在同一个模式里，R1 只能得到 A → B，R2 只能得到 A → C，推不出 B → C
--- 答案
是无损连接（公共属性 A 是 R1 的码），但**不保持函数依赖**。改成 R1(A, B)、R2(B, C) 就既无损又保持依赖。
:::

## 三、规范化分解能达到什么

| 目标 | 无损连接 | 保持函数依赖 |
|---|---|---|
| 分解到 3NF | 可以同时保证 | 可以同时保证 |
| 分解到 BCNF | 能保证 | **不一定**能保证 |

:::quiz 随堂测验
R(A, B, C, D)，F = {A → B, C → D}，分解为 R1(A, B)、R2(C, D)，则：
A. 无损且保持函数依赖
B. 有损但保持函数依赖
C. 无损但不保持函数依赖
D. 有损且不保持函数依赖
答案：B
解析：R1、R2 没有公共属性，连接就是笛卡尔积，有损；两个依赖各在一个模式中，保持依赖。
---
分解到 BCNF 时：
A. 一定既无损又保持依赖
B. 能保证无损连接，但不一定保持依赖
C. 能保证保持依赖，但不一定无损
D. 两者都不能保证
答案：B
:::

:::cards 记忆卡
无损连接 :: 分解后再自然连接，能还原原关系，元组不多不少
两个关系无损的判定 :: 公共属性能决定 R1 − R2 或 R2 − R1
保持函数依赖 :: 原依赖都能在分解后的模式中找到或推出
三个以上关系判断无损 :: 表格法，出现全 a 行则无损
分解到 3NF :: 可以同时保证无损连接和保持依赖
分解到 BCNF :: 保证无损，不一定保持依赖
:::
