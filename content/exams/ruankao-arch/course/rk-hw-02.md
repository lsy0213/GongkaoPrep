CPU 的结构、寻址方式、CISC 与 RISC、流水线计算是计算机组成里最常考的四个点，其中**流水线**几乎每隔一两年就出一道计算题。

## 一、CPU 的组成

| 部件 | 组成 | 作用 |
|---|---|---|
| 运算器 | 算术逻辑单元 ALU、累加器 AC、数据缓冲寄存器 DR、状态条件寄存器 PSW | 执行算术和逻辑运算 |
| 控制器 | **程序计数器 PC**、**指令寄存器 IR**、指令译码器、时序部件 | 取指令、译码、发出控制信号 |

:::key 两个最容易考的寄存器
- **PC**：存放**下一条**指令的地址；
- **IR**：存放**当前正在执行**的指令。
:::

## 二、寻址方式（按取操作数的速度从快到慢）

| 方式 | 操作数在哪 | 特点 |
|---|---|---|
| 立即寻址 | 就在指令里 | 最快，不用访存 |
| 寄存器寻址 | 寄存器里 | 很快 |
| 直接寻址 | 指令给出主存地址 | 访存 1 次 |
| 寄存器间接寻址 | 寄存器里放的是地址 | 访存 1 次 |
| 间接寻址 | 主存里放的是地址 | 访存 2 次，最慢 |
| 相对 / 变址寻址 | PC 或变址寄存器 + 偏移 | 便于程序浮动、数组访问 |

## 三、CISC 与 RISC

| | CISC 复杂指令集 | RISC 精简指令集 |
|---|---|---|
| 指令数量 | 多，长度可变 | 少，长度固定 |
| 寻址方式 | 多 | 少 |
| 实现 | **微程序控制** | **硬布线（组合逻辑）控制** |
| 寄存器 | 少 | 多 |
| 流水线 | 较难 | 适合流水线，大多指令一个周期完成 |

## 四、流水线计算

设一条指令分 k 段，各段时间为 t₁…t_k，执行 n 条指令：

- **流水线周期** = 最慢一段的时间 Δt_max；
- **总时间** = (t₁ + t₂ + … + t_k) + (n − 1) × Δt_max；
- 各段时间相等（都是 Δt）时：总时间 = (k + n − 1) × Δt；
- **吞吐率** TP = n ÷ 总时间；最大吞吐率 = 1 ÷ Δt_max；
- **加速比** = 不用流水线的时间 ÷ 用流水线的时间。

:::example 流水线总时间
一条指令分取指、分析、执行三段，各段时间 2ns、2ns、1ns。连续执行 100 条指令需要多少时间？吞吐率是多少？
--- 第一条指令
走完三段：2 + 2 + 1 = 5ns
--- 之后每条
每隔最慢一段 2ns 完成一条：(100 − 1) × 2 = 198ns
--- 答案
总时间 5 + 198 = **203ns**；吞吐率 = 100 ÷ 203 ≈ 0.49 条/ns。不用流水线要 100 × 5 = 500ns，加速比约 2.46。
:::

:::warn 不要算成“各段之和 × n”
那是不用流水线的时间。流水线只有第一条指令完整走一遍，后面每条只多一个“最慢段”的时间。
:::

## 五、Flynn 分类

按指令流和数据流分：SISD（单处理器）、**SIMD（向量机、阵列处理机）**、MISD（实际很少）、**MIMD（多处理器、多核）**。

:::quiz 随堂测验
程序计数器 PC 中存放的是：
A. 当前正在执行的指令
B. 下一条要执行的指令的地址
C. 操作数
D. 运算结果
答案：B
解析：PC 存下一条指令地址，IR 存当前指令。
---
关于 RISC，说法错误的是：
A. 指令长度固定
B. 多采用硬布线控制
C. 寻址方式多、指令复杂
D. 适合采用流水线
答案：C
解析：寻址方式多、指令复杂是 CISC 的特点。
---
某流水线分 4 段，每段 1Δt，执行 50 条指令共需：
A. 50Δt
B. 53Δt
C. 54Δt
D. 200Δt
答案：B
解析：(k + n − 1)Δt = (4 + 50 − 1)Δt = 53Δt。
:::

:::cards 记忆卡
PC 和 IR 各存什么 :: PC 存下一条指令的地址；IR 存当前正在执行的指令
最快的寻址方式 :: 立即寻址（操作数就在指令中）
CISC 和 RISC 的控制方式 :: CISC 多用微程序控制，RISC 多用硬布线控制
流水线总时间公式 :: 各段时间之和 + (n − 1) × 最慢一段时间
流水线吞吐率 :: 指令条数 ÷ 总时间；最大吞吐率 = 1 ÷ 最慢一段时间
Flynn 分类中多核属于 :: MIMD（多指令流多数据流）
:::
