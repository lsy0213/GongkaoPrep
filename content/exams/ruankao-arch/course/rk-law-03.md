标准化偶尔考 1 题：标准的分类、代号、有效期，以及软件工程相关的国家标准。

## 一、标准的层级

| 层级 | 制定者 | 代号举例 |
|---|---|---|
| 国际标准 | ISO、IEC、ITU | ISO 9001 |
| 区域标准 | 欧洲标准化委员会等 | EN |
| **国家标准** | 国务院标准化行政主管部门 | **GB**（强制）、**GB/T**（推荐）、GB/Z（指导性技术文件） |
| **行业标准** | 国务院有关行政主管部门 | **SJ**（电子）、**JB**（机械）、**YD**（通信）、**JR**（金融） |
| **地方标准** | 省级标准化行政主管部门 | **DB** + 地区代码 |
| **团体标准** | 学会、协会等 | T/ |
| **企业标准** | 企业 | **Q/** |

- 国家标准分**强制性**（GB，必须执行）和**推荐性**（GB/T，鼓励采用）；行业标准、地方标准都是推荐性的；
- 优先级：强制性国家标准是底线；推荐性国家标准、行业、地方、团体、企业标准的技术要求**不得低于**强制性国家标准；
- 国家鼓励企业标准、团体标准**严于**国家标准。

## 二、标准的复审

- 标准实施后，制定部门要**适时复审**，复审周期一般**不超过 5 年**；
- 复审结果：继续有效、修订、废止。

## 三、采用国际标准

- **等同采用**（IDT）：技术内容和文本结构相同；
- **修改采用**（MOD）：有技术差异，但清楚标明并解释；
- 非等效（NEQ）：不属于采用国际标准，只表明有对应关系。

## 四、软件工程相关标准

| 标准 | 内容 |
|---|---|
| GB/T 8566 | 软件生存周期过程 |
| GB/T 8567 | 计算机软件**文档编制规范** |
| GB/T 9385 | 软件需求规格说明 |
| GB/T 16260 / 25000 系列 | 软件质量（对应 ISO 9126 / 25010） |
| GB/T 22239 | 网络安全等级保护基本要求 |
| ISO/IEC 12207 | 软件生存周期过程（国际） |

:::key 代号速记
GB 强制、GB/T 推荐、SJ 电子行业、DB 地方、Q 企业。“GB/T 8567”就是推荐性国家标准，编号 8567。
:::
