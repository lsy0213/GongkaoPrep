信息系统这一章知识点散、靠记，每年 2～3 题：信息系统的类型、企业信息化（ERP、CRM、SCM）、电子政务与电子商务、系统规划方法、企业应用集成。

## 一、信息系统的类型

| 类型 | 面向 | 要点 |
|---|---|---|
| 业务处理系统 TPS | 操作层 | 处理日常业务数据，最基础 |
| 管理信息系统 MIS | 中层管理 | 生成报表、辅助管理 |
| **决策支持系统 DSS** | 高层、半结构化决策 | 数据库 + **模型库** + 方法库 + 知识库 + 人机交互 |
| 专家系统 ES | 特定领域 | 知识库 + **推理机**，模拟专家推理 |
| 办公自动化 OAS | 办公 | 文字处理、公文流转 |
| 主管信息系统 EIS | 高层领导 | 汇总、钻取关键指标 |

## 二、企业信息化

- **ERP**（企业资源计划）：由 MRP → MRP II 发展而来，管理企业的**物流、资金流、信息流**（2012 年真题），把财务、采购、生产、销售、人力等整合在一个系统；
- **CRM**（客户关系管理）：以客户为中心，销售、营销、客户服务自动化；
- **SCM**（供应链管理）：管理从供应商到客户的整个链条；
- **BPR**（业务流程重组）：对业务流程做**根本性、彻底性**的重新设计，追求显著改善；BPM（业务流程管理）则是持续优化。

## 三、电子商务与电子政务

| 电子商务 | 电子政务 |
|---|---|
| B2B 企业对企业 | G2G 政府之间 |
| B2C 企业对个人 | **G2B** 政府对企业（如网上报税、企业登记） |
| C2C 个人对个人 | **G2C** 政府对公民（如社保查询） |
| O2O 线上到线下 | G2E 政府对公务员 |

## 四、信息系统生命周期与规划方法

生命周期：**系统规划 → 系统分析 → 系统设计 → 系统实施 → 系统运行与维护**。

| 规划方法 | 要点 |
|---|---|
| 企业系统规划 BSP | 自上而下识别企业目标和过程，自下而上设计系统，用 U/C 矩阵划分子系统 |
| 关键成功因素 CSF | 抓住影响企业成功的少数关键因素 |
| 战略集合转化 SST | 把组织战略集合转化为信息系统战略 |

## 五、企业应用集成 EAI

从浅到深：**界面集成**（门户、统一入口）→ **数据集成**（共享数据库、ETL）→ **控制集成 / 应用集成**（API、消息、RPC）→ **业务流程集成**（跨系统的流程编排）→ 企业之间的集成。
