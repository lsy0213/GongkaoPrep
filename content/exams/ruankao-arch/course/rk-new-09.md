安全架构设计是教程第 2 版的章节，偏“体系”：安全架构的框架、各层面的安全设计、零信任。论文出过“论系统安全架构设计及其应用”。（加密、签名等技术细节在“信息安全”课程中。）

## 一、安全架构的层次

| 层面 | 关注 | 手段 |
|---|---|---|
| 物理安全 | 机房、设备 | 门禁、防雷、UPS、异地备份 |
| **网络安全** | 边界与传输 | 防火墙、**IDS / IPS**、VPN、网络隔离、DMZ |
| **系统安全** | 操作系统、主机 | 补丁、加固、最小权限、主机审计 |
| **应用安全** | 应用程序 | **身份认证**、**授权**、输入校验（防 SQL 注入、XSS）、会话管理 |
| **数据安全** | 数据的机密、完整、可用 | **加密存储与传输**、脱敏、备份、访问控制、数据分级分类 |
| 管理安全 | 制度与人员 | 安全策略、培训、审计、应急预案 |

## 二、安全模型与框架

- **WPDRRC 模型**：预警（Warning）、保护（Protection）、检测（Detection）、响应（Response）、恢复（Recovery）、反击（Counterattack）；人员、策略、技术三大要素；
- **P2DR 模型**：策略（Policy）、防护、检测、响应；
- **OSI 安全体系结构**：5 类安全服务（**认证、访问控制、数据机密性、数据完整性、抗抵赖**）、8 类安全机制。

## 三、零信任架构

:::key 零信任的核心思想
“**永不信任，始终验证**”：不再区分内网和外网，**每一次访问**都要基于身份、设备、环境做认证和授权，遵循**最小权限**，并持续评估。核心组件：**策略决策点 PDP**、**策略执行点 PEP**，以及身份管理、微隔离。
:::

## 四、常见的安全设计实践

- **统一身份认证**：SSO 单点登录、OAuth 2.0（授权）、OpenID Connect（认证）、多因素认证 MFA；
- **权限模型**：**RBAC**（基于角色）、ABAC（基于属性）；
- **接口安全**：HTTPS、签名防篡改、时间戳 + nonce 防重放、限流防刷；
- **数据库安全**：参数化查询防注入、敏感字段加密、审计；
- 安全开发：**SDL** 安全开发生命周期、威胁建模（**STRIDE**：仿冒、篡改、抵赖、信息泄露、拒绝服务、权限提升）。

:::example 案例题：系统安全设计
某政务系统要对外开放数据查询接口，安全上如何设计？
--- 身份与权限
OAuth 2.0 + 应用签名认证调用方；RBAC 控制访问哪些数据
--- 传输与数据
全程 HTTPS；敏感数据脱敏返回；请求带时间戳和随机数防重放
--- 运营
API 网关限流防刷；全量调用日志审计；按等级保护三级要求测评
:::
