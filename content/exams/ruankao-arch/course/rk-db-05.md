规范化几乎每年必考：给一个关系模式和函数依赖集，问候选键是什么、属于第几范式。掌握“求候选键”的图示法，题就会做了。

## 一、函数依赖

- **X → Y**：X 的值确定后，Y 的值唯一确定；
- **完全函数依赖**：X → Y，且 X 的任何真子集都不能确定 Y；
- **部分函数依赖**：X → Y，但 X 的某个真子集就能确定 Y；
- **传递函数依赖**：X → Y、Y → Z，且 Y 不能确定 X，则 Z 传递依赖于 X。

Armstrong 公理：**自反律**（Y ⊆ X 则 X → Y）、**增广律**（X → Y 则 XZ → YZ）、**传递律**（X → Y、Y → Z 则 X → Z）；推论有合并规则、分解规则、伪传递规则。

## 二、求候选键：图示法

:::key 四步求候选键
1. 把函数依赖画成有向图；
2. 找**入度为 0** 的属性（只在箭头左边出现、从不在右边出现），它们**一定在候选键里**；
3. 从这些属性出发，看能否推出全部属性（求闭包）；能，就是唯一候选键；
4. 不能，就依次加入“既在左边又在右边”的属性再试。只在右边出现的属性一定不在候选键里。
:::

:::example 求候选键
R(A, B, C, D)，F = {A → B, B → C, C → D}，候选键是什么？
--- 找入度为 0 的属性
A 只在左边出现，入度为 0；B、C、D 都出现在右边
--- 求 A 的闭包
A → B → C → D，A⁺ = {A, B, C, D}，等于全部属性
--- 答案
候选键是 **A**，主属性只有 A。
:::

:::example 两个入度为 0
R(A, B, C, D, E)，F = {A → C, B → D, C → E}，候选键？
--- 入度为 0
A、B 都只在左边出现
--- 闭包
(AB)⁺ = {A, B, C, D, E}
--- 答案
候选键是 **AB**。
:::

## 三、范式

| 范式 | 条件 | 消除了什么 |
|---|---|---|
| 1NF | 属性都是**不可再分**的原子值 | — |
| 2NF | 1NF + 非主属性**完全依赖**于候选键 | 非主属性对码的**部分依赖** |
| 3NF | 2NF + 非主属性**不传递依赖**于候选键 | 非主属性对码的**传递依赖** |
| BCNF | 每个函数依赖的左边都包含候选键 | 主属性对码的部分和传递依赖 |
| 4NF | BCNF + 消除非平凡的多值依赖 | 多值依赖 |

:::tip 快速判断
- 候选键只有一个属性 → 不可能有部分依赖，至少 2NF；
- 所有属性都是主属性 → 至少 3NF；
- 每个依赖的左边都是超键 → BCNF。
:::

:::example 判断范式
接上例 R(A, B, C, D)，F = {A → B, B → C, C → D}，属于第几范式？
--- 2NF
候选键 A 是单属性，没有部分依赖，满足 2NF
--- 3NF
A → B → C，C 传递依赖于 A，不满足 3NF
--- 答案
最高 **2NF**。
:::

## 四、不规范的后果

低范式会造成**数据冗余、插入异常、删除异常、修改异常**。例如“学生-课程-教师”放在一张表里，删掉最后一个选课学生，教师信息也跟着没了（删除异常）。

:::quiz 随堂测验
R(A, B, C)，F = {AB → C, C → A}，R 的候选键是：
A. 只有 AB
B. AB 和 BC
C. 只有 BC
D. ABC
答案：B
解析：B 入度为 0。(AB)⁺ = ABC；(BC)⁺：C → A，得 ABC。两个都是候选键。
---
上题中 R 属于第几范式（最高）：
A. 1NF
B. 2NF
C. 3NF
D. BCNF
答案：C
解析：A、B、C 都是主属性，至少 3NF；C → A 中 C 不是超键，不满足 BCNF。
---
2NF 消除的是：
A. 非主属性对码的部分函数依赖
B. 非主属性对码的传递函数依赖
C. 主属性对码的部分依赖
D. 多值依赖
答案：A
:::

:::cards 记忆卡
部分函数依赖 :: 码的某个真子集就能确定该属性
传递函数依赖 :: X → Y、Y → Z 且 Y 不能确定 X，则 Z 传递依赖于 X
求候选键第一步 :: 找入度为 0 的属性，它们一定在候选键中
只在依赖右边出现的属性 :: 一定不在候选键中
2NF :: 消除非主属性对码的部分依赖
3NF :: 消除非主属性对码的传递依赖
BCNF :: 每个函数依赖的左边都是超键
全是主属性的关系 :: 至少 3NF
:::
