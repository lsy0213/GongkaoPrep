计算机网络每年 2～3 题，偏概念：分层模型、各层设备和协议、TCP 与 UDP、常用端口、DNS。

## 一、分层模型

| OSI 七层 | TCP/IP 四层 | 典型协议 | 设备 |
|---|---|---|---|
| 应用层、表示层、会话层 | 应用层 | HTTP、FTP、SMTP、DNS、SNMP | 网关 |
| 传输层 | 传输层 | **TCP、UDP** | — |
| 网络层 | 网际层 | **IP、ICMP、ARP**、路由协议 | **路由器** |
| 数据链路层 | 网络接口层 | 以太网、PPP | **交换机**、网桥 |
| 物理层 | 网络接口层 | — | 中继器、集线器 |

## 二、TCP 与 UDP

| | TCP | UDP |
|---|---|---|
| 连接 | 面向连接（**三次握手**建立，四次挥手释放） | 无连接 |
| 可靠性 | 可靠：确认、重传、按序 | 不可靠，尽最大努力交付 |
| 流量 / 拥塞控制 | **滑动窗口**流量控制；慢开始、拥塞避免等 | 没有 |
| 适用 | 文件传输、网页、邮件 | 视频、语音、DNS 查询、实时应用 |

:::key 常用端口
HTTP 80 · HTTPS 443 · FTP 20（数据）/ 21（控制）· SSH 22 · Telnet 23 · SMTP 25 · DNS 53 · DHCP 67/68 · POP3 110 · SNMP 161/162
:::

## 三、几个协议

- **ARP**：已知 IP 地址求 MAC 地址；RARP 反过来；
- **ICMP**：差错报告和查询，ping、tracert 用它；
- **DHCP**：自动分配 IP 地址；
- **DNS**：域名 → IP。查询方式有**递归**（让服务器替我查到底）和**迭代**（服务器告诉我下一个去问谁）；本地域名服务器既可以递归也可以迭代。

## 四、网络规划

**层次化设计**：

- **核心层**：高速转发，不做复杂策略；
- **汇聚层**：路由聚合、访问控制、策略；
- **接入层**：用户接入、VLAN 划分。
