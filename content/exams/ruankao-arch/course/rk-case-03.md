架构风格选择题的套路：**对比两个方案 → 结合需求 → 给出选择和理由**。另一类是“画架构图 / 填架构图的空”。

## 一、对比题的答题模板

:::flow 四段式
点出需求 :: “根据题目描述，系统的关键需求是……（如：规则经常变化、需要实时响应、多工具协作）”
方案一分析 :: “方案一采用……风格，其优点是……，但……”
方案二分析 :: “方案二采用……风格，其优点是……，缺点是……”
结论 :: “综合考虑……，选择方案二更合适。”
:::

:::tip 表格作答更清晰
能画表就画表：行是质量属性（性能、可修改性、可扩展性、可靠性），列是两个方案，每格写“优 / 劣 + 原因”。
:::

## 二、常见风格对比结论（背下来）

| 场景 | 推荐 |
|---|---|
| 编译器 / IDE 的语法树共享 | 数据共享（仓库）风格 |
| 简单可预测环境的控制 | 闭环控制 |
| 复杂环境下的机器人 / 自动驾驶 | 分层 + 事件驱动 |
| 规则频繁变化 | 基于规则的系统、解释器 |
| 工具集成、松耦合 | 隐式调用（事件驱动） |
| 语音识别、模式识别 | 黑板 |
| 大型互联网应用 | 微服务 + 分层 |

## 三、架构图题

- 题目给一张有空缺的**分层架构图**（表现层、业务层、数据层……）或**部署图**，让你填空；
- 方法：根据说明中提到的技术和组件，按“**从上到下：用户 → 接入 → 应用 → 服务 → 数据**”的顺序对号入座；
- 常见元素：负载均衡（Nginx）、API 网关、注册中心、消息队列、Redis、MySQL 主从、Elasticsearch、HDFS。

:::write 风格对比 | 300 | 9
某工业设备控制系统需要根据传感器数据实时调整设备运行参数，环境较为稳定，控制逻辑相对简单。候选方案 A 为闭环控制风格，方案 B 为基于规则的系统。请对比两种方案并给出选择。
--- 要点
闭环控制：结构简单，实时性好，通过反馈持续调整
闭环控制适合环境稳定、控制逻辑简单的场景
基于规则：规则可配置、灵活，适合规则复杂多变
基于规则：需要规则解释，效率较低，实时性较差
结论：选方案 A 闭环控制，因为环境稳定、要求实时
--- 参考答案
方案 A 闭环控制：传感器采集→控制器计算→执行器调整→反馈，结构简单、**实时性好**，适合环境稳定、可预测的场景；方案 B 基于规则：规则可灵活配置，适合规则复杂多变的场景，但需要规则解释与匹配，**执行效率较低**。本系统环境稳定、控制逻辑简单、强调实时，因此选择**方案 A**。
:::
