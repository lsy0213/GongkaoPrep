试题一最常考**质量属性 + 架构评估**，几乎是“送分模板题”：把需求归到质量属性、填效用树、判断风险点 / 敏感点 / 权衡点。

## 一、题型一：给需求归类

题目列出 8～12 条需求，问“哪些属于质量属性需求、分别是哪个属性”，或者“填写效用树中的空 (1)～(6)”。

:::key 判断口诀
- 出现**响应时间、吞吐量、并发、多少秒内** → **性能**；
- 出现**故障、宕机、恢复、切换、7×24、99.99%** → **可用性**；
- 出现**新增、修改、扩展、多少人天、不影响其他模块** → **可修改性**；
- 出现**非法访问、加密、认证、审计、攻击** → **安全性**；
- 出现**测试、覆盖率、模拟、日志定位** → **可测试性**；
- 出现**易学、操作步骤、提示、界面** → **易用性**；
- “**支持 XX 功能**”这种**不是质量属性**，是功能需求。
:::

## 二、题型二：风险点、敏感点、权衡点、非风险点

| 判断 | 关键词 |
|---|---|
| **权衡点** | 一个决策**同时影响两个或以上**质量属性（“提高了 A，但降低了 B”） |
| **敏感点** | 一个决策**影响某一个**质量属性（“直接影响响应时间”） |
| **风险点** | 决策**可能导致**某属性不满足要求（“可能”“隐患”“无法满足”） |
| **非风险点** | 决策**能够满足**要求（“可以保证”“满足”） |

## 三、题型三：ATAM 步骤和概念

常问：ATAM 有哪几个阶段、效用树在哪个阶段生成、谁参与头脑风暴。答案见“系统架构设计”第 9 课：**演示 → 调查与分析 → 测试 → 报告**。

:::write 分类需求 | 200 | 8
某医院信息系统的部分需求：(a) 挂号高峰期每秒处理 300 个请求；(b) 医生可以查询患者的历史病历；(c) 主数据库故障后 1 分钟内切换到备库；(d) 患者隐私数据加密存储，访问留痕；(e) 新增一种医保结算方式，3 人天内完成。请指出哪些是质量属性需求，分别属于哪个质量属性。
--- 要点
(a) 性能
(b) 是功能需求，不是质量属性
(c) 可用性
(d) 安全性
(e) 可修改性
--- 参考答案
质量属性需求：(a) **性能**（吞吐量）；(c) **可用性**（故障恢复）；(d) **安全性**（加密、审计）；(e) **可修改性**（修改成本）。(b) 描述的是系统要提供的功能，属于**功能需求**。
:::

:::quiz 随堂测验
“用户请求经过网关鉴权会增加约 50ms 延迟，但能阻止非法访问”，这个决策是：
A. 风险点
B. 敏感点
C. 权衡点
D. 非风险点
答案：C
---
“系统支持按科室查询排班信息”属于：
A. 性能需求
B. 可用性需求
C. 功能需求
D. 易用性需求
答案：C
:::

:::cards 记忆卡
“多少秒内响应”是什么属性 :: 性能
“故障后多少秒内恢复”是什么属性 :: 可用性
“新增功能多少人天完成”是什么属性 :: 可修改性
“支持某某功能” :: 功能需求，不是质量属性
权衡点的特征 :: 一个决策同时影响多个质量属性
风险点的特征 :: 决策可能导致质量属性不满足
非风险点的特征 :: 决策能够满足质量属性要求
