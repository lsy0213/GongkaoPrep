结构化方法考数据流图、数据字典、模块设计原则（耦合与内聚），案例分析常让你补全数据流图或指出错误。

## 一、结构化分析 SA

- **数据流图 DFD**：外部实体、**加工**、**数据流**、**数据存储**四种元素，自顶向下分层（顶层图 → 0 层图 → 1 层图……）；
- **数据字典 DD**：对数据流图中每个元素的定义，用 = + [ | ] { } ( ) 表示组成、选择、重复、可选；
- 加工逻辑描述：**结构化语言、判定表、判定树**；
- 动态行为：状态转换图；数据建模：E-R 图。

:::warn 数据流图的常见错误
- **黑洞**：加工只有输入没有输出；
- **奇迹**：加工只有输出没有输入；
- **灰洞**：输入不足以产生输出；
- 父图和子图**不平衡**（子图的输入输出数据流与父图对应加工不一致）；
- 数据存储、外部实体之间直接相连（中间必须有加工）。
:::

## 二、结构化设计 SD

- **概要设计**：模块划分、模块之间的调用关系，用**结构图（SC）**表示；
- **详细设计**：每个模块的算法和数据结构，用程序流程图、N-S 图、PAD 图、伪代码表示；
- 数据流图 → 结构图：**变换分析**（输入—变换—输出）和**事务分析**（按事务类型分派）。

## 三、内聚与耦合

原则：**高内聚、低耦合**。

| 内聚（从低到高） | 说明 |
|---|---|
| 偶然内聚 | 各部分毫无关系 |
| 逻辑内聚 | 逻辑上相似的功能放一起，靠参数选 |
| 时间内聚 | 同一时间执行，如初始化 |
| 过程内聚 | 按特定顺序执行 |
| 通信内聚 | 操作同一数据 |
| 顺序内聚 | 前一个的输出是后一个的输入 |
| **功能内聚**（最高） | 共同完成一个单一功能 |

| 耦合（从低到高） | 说明 |
|---|---|
| 非直接耦合（最低） | 没有直接关系 |
| **数据耦合** | 通过参数传递简单数据 |
| 标记耦合 | 传递数据结构 |
| 控制耦合 | 传递控制信号（开关、标志） |
| 外部耦合 | 共享外部变量（简单变量） |
| 公共耦合 | 共享公共数据区 |
| **内容耦合**（最高） | 直接访问另一模块内部数据或跳进其内部 |

:::tip 记忆
内聚：“偶逻时过通顺功”；耦合：“非数标控外公内”。
:::

:::quiz 随堂测验
数据流图中某个加工只有输入数据流没有输出数据流，这个错误叫：
A. 黑洞
B. 奇迹
C. 灰洞
D. 不平衡
答案：A
---
模块 A 通过传递一个标志来决定模块 B 执行哪段代码，这种耦合是：
A. 数据耦合
B. 标记耦合
C. 控制耦合
D. 公共耦合
答案：C
---
内聚程度最高的是：
A. 顺序内聚
B. 通信内聚
C. 功能内聚
D. 时间内聚
答案：C
:::
