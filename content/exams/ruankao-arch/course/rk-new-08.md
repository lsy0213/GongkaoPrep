嵌入式系统架构和通信系统架构是教程第 2 版新增的章节。嵌入式题目在案例分析中几乎每年都有一道（可选），要会答“安全关键系统”的设计要点。

## 一、嵌入式软件架构

| 架构 | 特点 |
|---|---|
| **层次化架构** | 硬件层 → **硬件抽象层 HAL / BSP** → 操作系统层 → 中间件层 → 应用层 |
| 递归模式架构 | 构件可以嵌套组合 |
| **IMA 综合模块化航电** | 用通用的硬件模块和分区操作系统替代联合式航电，资源共享、降低体积重量 |

:::key 分区操作系统（ARINC 653）
在一个处理器上划分多个**分区**，各分区在**时间和空间上隔离**，一个分区故障不影响其他分区，适合安全关键系统（航空电子）。
:::

## 二、嵌入式数据库与中间件

- 嵌入式数据库：**SQLite**、Berkeley DB 等；特点是体积小、嵌入应用、零配置；
- 嵌入式中间件：**DDS**（数据分发服务，发布 / 订阅，支持 **QoS** 策略，用于军事、航空等实时系统）、CORBA/e。

## 三、安全关键系统

- 安全性分析方法：**FMEA**（故障模式及影响分析，自下而上）、**FTA**（故障树分析，自顶向下）、危险分析；
- 软件安全等级：如航空的 **DO-178C**（A 级最高，失效会导致灾难性后果）、汽车的 ISO 26262（ASIL A～D）；
- 设计手段：冗余（双机、三模）、看门狗、**分区隔离**、形式化验证、MC/DC 覆盖测试。

## 四、通信系统架构

| 网络 | 要点 |
|---|---|
| 局域网 | 单核心、双核心、环形、层次型（核心层、汇聚层、接入层） |
| 广域网 | 单核心、双核心、环形、半冗余、对等子域、层次子域 |
| 移动通信 | 5G 的三大场景：**eMBB**（增强移动宽带）、**URLLC**（超高可靠低时延）、**mMTC**（海量物联） |
| 存储网络 | **DAS**（直连）、**NAS**（文件级，网络附加存储）、**SAN**（块级，存储区域网络） |
| SDN | 软件定义网络：**控制平面与数据平面分离**，集中控制 |
