物联网、人工智能、区块链属于“未来信息综合技术”，综合知识每年 2～3 题，偏概念。

## 一、物联网

- 三层架构：**感知层**（传感器、RFID、二维码）→ **网络层**（NB-IoT、LoRa、5G、ZigBee）→ **应用层**；
- 关键技术：**RFID**、传感器、**M2M**、云计算、边缘计算；
- 低功耗广域网：**NB-IoT**（授权频段、运营商部署）、**LoRa**（非授权频段、自建）；近距离：ZigBee、蓝牙、Wi-Fi。

## 二、人工智能

| 概念 | 要点 |
|---|---|
| 机器学习 | **监督学习**（有标签：分类、回归）、**无监督学习**（无标签：聚类、降维）、**强化学习**（通过奖励与环境交互） |
| 深度学习 | 多层神经网络：**CNN**（图像）、**RNN / LSTM**（序列）、**Transformer**（注意力机制，大模型的基础） |
| 应用 | 计算机视觉、自然语言处理、语音识别、推荐 |
| 机器学习的流程 | 数据采集 → 预处理 → 特征工程 → 模型训练 → 评估 → 部署 |

## 三、区块链

:::key 区块链的特点
**去中心化**、**不可篡改**（哈希链 + 共识）、**可追溯**、**匿名性**、**透明**；核心技术：**分布式账本**、**共识机制**、**密码学**（哈希、数字签名）、**智能合约**。
:::

| 共识机制 | 说明 |
|---|---|
| **PoW** 工作量证明 | 算力竞争（比特币），能耗高 |
| **PoS** 权益证明 | 按持币量和时间 |
| **DPoS** 委托权益证明 | 选出代表记账 |
| **PBFT** 实用拜占庭容错 | 适合联盟链，容忍不超过 1/3 的恶意节点 |

类型：**公有链**（任何人可参与）、**联盟链**（成员机构参与，如 Hyperledger Fabric）、**私有链**。

## 四、其他新技术

- **云计算 / 边缘计算 / 雾计算**：边缘计算就近处理数据，降低时延和带宽（下一课详讲）；
- **大数据**、**数字孪生**、**元宇宙**；
- **信创**：自主可控的国产 CPU、操作系统、数据库、中间件。
