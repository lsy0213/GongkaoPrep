信息安全每年 2～3 题，加密技术是基础：对称与非对称的区别、常见算法的归类、两者如何结合使用。

## 一、信息安全的基本属性

**CIA**：**机密性**（Confidentiality，不泄露）、**完整性**（Integrity，不被篡改）、**可用性**（Availability，需要时能用）；另外还有**可控性**、**不可抵赖性**（抗抵赖）。

## 二、对称加密

- 加密和解密用**同一个密钥**；
- 优点：**速度快**，适合加密**大量数据**；
- 缺点：**密钥分发困难**；n 个人两两通信需要 n(n − 1) ÷ 2 个密钥。

| 算法 | 要点 |
|---|---|
| **DES** | 分组 64 位，有效密钥 **56 位**，已不安全 |
| **3DES** | 三次 DES，有效密钥 112 位（两个密钥）或 168 位 |
| **AES** | 分组 128 位，密钥 128 / 192 / 256 位，当前主流 |
| IDEA | 密钥 128 位 |
| **SM4** | 国密分组算法，分组和密钥都是 128 位 |
| RC4 | 流密码 |

## 三、非对称加密（公钥加密）

- 每人一对密钥：**公钥**公开、**私钥**自己保管；
- **公钥加密、私钥解密** → 保证机密性；**私钥签名、公钥验证** → 数字签名；
- 优点：**密钥分发方便**，可以做数字签名；缺点：**速度慢**。

| 算法 | 依据的数学难题 |
|---|---|
| **RSA** | 大整数**因子分解** |
| **ECC** 椭圆曲线 | 椭圆曲线离散对数，同等安全下密钥更短 |
| DSA | 离散对数，只能用于签名 |
| Diffie-Hellman | 离散对数，用于**密钥交换** |
| **SM2** | 国密椭圆曲线公钥算法 |

:::key 混合加密（数字信封）
用**对称密钥**加密数据（快）→ 用**接收方的公钥**加密这个对称密钥（安全分发）→ 一起发送。接收方用私钥解出对称密钥，再解密数据。HTTPS / TLS 就是这样工作的。
:::

## 四、国密算法

| 算法 | 类型 |
|---|---|
| SM1 | 对称（算法不公开，用于芯片） |
| **SM2** | 非对称（椭圆曲线） |
| **SM3** | 摘要（哈希，256 位） |
| **SM4** | 对称（分组） |
| SM9 | 基于标识的密码 |

:::quiz 随堂测验
下列属于非对称加密算法的是：
A. DES
B. AES
C. RSA
D. SM4
答案：C
---
甲要给乙发送机密文件，应用什么加密：
A. 甲的私钥
B. 甲的公钥
C. 乙的公钥
D. 乙的私钥
答案：C
---
10 个人两两之间用对称加密通信，需要多少个密钥：
A. 10
B. 20
C. 45
D. 90
答案：C
解析：n(n − 1) ÷ 2 = 10 × 9 ÷ 2 = 45。
:::

对称加密的优缺点 :: 快，适合大量数据；密钥分发难
非对称加密的优缺点 :: 密钥分发方便、可签名；速度慢
DES 的有效密钥长度 :: 56 位
AES 的分组长度 :: 128 位
RSA 的数学基础 :: 大整数因子分解
数字信封 :: 对称密钥加密数据，接收方公钥加密对称密钥
国密 SM2、SM3、SM4 :: SM2 非对称，SM3 摘要，SM4 对称
n 个人两两对称通信的密钥数 :: n(n − 1) ÷ 2
:::
