CPU 和外设怎么交换数据，决定了 CPU 有多少时间“闲着等”。四种 I/O 控制方式的区别和 DMA 的特点是常考点。

## 一、总线

- 按传送内容分：**数据总线、地址总线、控制总线**；
- **地址总线的宽度决定可寻址的范围**（n 位地址线可寻址 2ⁿ 个单元），数据总线宽度决定一次传输的位数；
- **总线带宽** = 总线频率 × 总线宽度（位）÷ 8（字节/秒）；
- 常见：PCI、PCIe（串行、点对点）、USB、SPI、I²C、CAN（汽车、工控）。

## 二、四种 I/O 控制方式

| 方式 | CPU 参与程度 | 说明 |
|---|---|---|
| 程序查询 | 全程等待、反复查询 | 最简单，CPU 利用率最低 |
| 程序中断 | 外设准备好时中断 CPU | CPU 和外设可以**并行** |
| **DMA** | 只在开始和结束时介入 | 数据在**外设和主存之间直接传送，不经过 CPU** |
| 通道 / I/O 处理机 | 几乎不参与 | 专门的处理机管理 I/O |

:::key DMA 的三个要点
- 数据传送不经过 CPU，由 DMA 控制器控制总线；
- CPU 只在传送开始（设置参数）和结束（中断通知）时参与；
- DMA 请求在**一个总线周期结束后**响应（中断请求是在一条**指令执行结束后**响应）。
:::

## 三、中断

- **中断向量**：中断服务程序的入口地址，用来快速找到服务程序；
- 响应过程：关中断 → **保护现场（断点）** → 识别中断源 → 执行服务程序 → 恢复现场 → 开中断 → 返回；
- **中断响应时间**：从发出中断请求到开始执行服务程序第一条指令的时间；
- 多重中断（中断嵌套）：处理低优先级中断时，可以被更高优先级的中断打断。

:::quiz 随堂测验
数据在外设和主存之间直接传送、不经过 CPU 的方式是：
A. 程序查询
B. 程序中断
C. DMA
D. 无条件传送
答案：C
---
CPU 响应中断的时机一般是：
A. 一个时钟周期结束时
B. 一条指令执行结束时
C. 一个总线周期结束时
D. 任意时刻
答案：B
解析：中断在一条指令结束后响应；DMA 请求在一个总线周期结束后响应。
---
地址总线 32 位，按字节编址，可寻址空间是：
A. 32MB
B. 4GB
C. 2GB
D. 64KB
答案：B
解析：2³² 字节 = 4GB。
:::

地址总线宽度决定什么 :: 可寻址空间（n 位可寻址 2ⁿ 个单元）
CPU 利用率最低的 I/O 方式 :: 程序查询
DMA 的特点 :: 外设与主存直接传数据，不经 CPU；CPU 只在开始和结束时介入
