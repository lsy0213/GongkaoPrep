这一课是计算机系统的地基：数怎么在机器里表示、出错了怎么发现。综合知识里每 2～3 年出一题，海明码校验位最常考。

## 一、进制转换

| 方向 | 方法 |
|---|---|
| R 进制 → 十进制 | 按权展开：(1011)₂ = 1×2³ + 0×2² + 1×2¹ + 1 = 11 |
| 十进制整数 → R 进制 | 除 R 取余，**倒着**写 |
| 十进制小数 → 二进制 | 乘 2 取整，**顺着**写 |
| 二进制 ↔ 八 / 十六进制 | 3 位 / 4 位一组 |

## 二、原码、反码、补码、移码

以 8 位为例（最高位是符号位）：

| 编码 | +5 | −5 | 8 位能表示的整数范围 |
|---|---|---|---|
| 原码 | 0000 0101 | 1000 0101 | −127 ～ +127（0 有两种） |
| 反码 | 0000 0101 | 1111 1010 | −127 ～ +127（0 有两种） |
| 补码 | 0000 0101 | 1111 1011 | **−128 ～ +127**（0 唯一） |
| 移码 | 1000 0101 | 0111 1011 | −128 ～ +127，常用于浮点数阶码 |

:::key 记住三条
- 正数的原码、反码、补码相同；
- 负数：反码 = 原码符号位不变、其余取反；补码 = 反码 + 1；
- 移码 = 补码的符号位取反。n 位补码范围是 −2ⁿ⁻¹ ～ 2ⁿ⁻¹−1。
:::

## 三、浮点数

N = M × 2ᴱ，M 是尾数、E 是阶码。

- **阶码的位数决定表示范围**，**尾数的位数决定精度**；
- 规格化：尾数最高位是有效数字（补码表示时符号位和最高数值位不同）；
- 浮点加减：**对阶（小阶向大阶看齐）→ 尾数加减 → 规格化 → 舍入 → 溢出判断**。

## 四、校验码

| 校验码 | 能力 | 要点 |
|---|---|---|
| 奇偶校验 | 只能检出**奇数个**位错，不能纠错 | 加 1 位校验位 |
| 海明码 | 能检错，**能纠正 1 位错** | 校验位 r 满足 2ʳ ≥ k + r + 1（k 为数据位） |
| CRC 循环冗余校验 | 检错能力强，**不能纠错** | 模 2 除法；生成多项式最高次幂为 r，则校验码 r 位 |

:::example 海明码要几位校验位
数据 32 位，用海明码纠正 1 位错，至少需要几位校验位？
--- 列不等式
2ʳ ≥ 32 + r + 1
--- 试数
r = 5：32 ≥ 38？不成立；r = 6：64 ≥ 39 成立。
--- 答案
至少 **6** 位。
:::

:::quiz 随堂测验
8 位补码能表示的整数范围是：
A. −127 ～ 127
B. −128 ～ 127
C. −127 ～ 128
D. 0 ～ 255
答案：B
解析：n 位补码范围是 −2^(n−1) ～ 2^(n−1)−1，8 位即 −128 ～ 127。
---
下面哪种校验码能够纠正 1 位错误？
A. 奇偶校验码
B. CRC 校验码
C. 海明码
D. 以上都不能
答案：C
解析：奇偶校验和 CRC 只能检错，海明码能纠正 1 位错。
---
浮点数的表示范围主要由什么决定？
A. 尾数的位数
B. 阶码的位数
C. 符号位
D. 基数
答案：B
解析：阶码决定范围，尾数决定精度。
:::

:::cards 记忆卡
负数的补码怎么求 :: 原码符号位不变、其余各位取反，再加 1
n 位补码的表示范围 :: −2^(n−1) ～ 2^(n−1)−1
移码和补码的关系 :: 补码的符号位取反
浮点数阶码、尾数各决定什么 :: 阶码决定表示范围，尾数决定精度
浮点数加减的步骤 :: 对阶（小阶向大阶看齐）→ 尾数运算 → 规格化 → 舍入 → 溢出判断
海明码校验位公式 :: 2^r ≥ k + r + 1（k 数据位，r 校验位）
CRC 能否纠错 :: 不能，只能检错；采用模 2 除法
奇偶校验能检出什么错误 :: 奇数个位出错
:::
