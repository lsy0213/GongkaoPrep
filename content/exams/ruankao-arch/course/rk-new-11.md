边缘计算、数字孪生是教程第 2 版重点介绍的新技术；大模型应用架构是 2024 年以后的新热点，论文和案例都可能涉及。

## 一、边缘计算

- 在**靠近数据源的网络边缘**处理数据，而不是全部送到云端；
- 好处：**低时延**、**节省带宽**、**数据隐私**（数据不出本地）、离线可用；
- **云边协同**：云端负责训练模型、全局管理、大数据分析；边缘负责实时处理、推理、数据预处理；
- 协同内容：资源协同、数据协同、智能协同、应用管理协同、业务管理协同、服务协同；
- 应用：工业互联网、智慧交通、视频分析、自动驾驶。

| 对比 | 云计算 | 边缘计算 |
|---|---|---|
| 位置 | 集中式数据中心 | 分布在网络边缘 |
| 时延 | 高 | 低 |
| 擅长 | 全局分析、大规模计算 | 实时响应、本地处理 |

## 二、数字孪生

:::key 数字孪生
在虚拟空间建立物理实体的**高保真数字模型**，通过**实时数据**与物理实体**双向映射、同步**，实现监控、仿真、预测、优化。关键技术：**建模**、**仿真**、**物联网（数据采集）**、大数据与 AI。
:::

应用：智能制造（产线仿真）、智慧城市、设备预测性维护、航空发动机健康管理。

## 三、大模型应用架构

| 模式 | 说明 |
|---|---|
| **提示工程** | 设计提示词让模型完成任务，成本最低 |
| **RAG 检索增强生成** | 先从**向量数据库**中检索相关知识，再连同问题交给大模型生成答案；解决知识过时和“幻觉”，不需要训练 |
| **微调** | 用领域数据继续训练（如 LoRA），让模型掌握领域风格和知识 |
| **智能体 Agent** | 大模型 + **规划 + 记忆 + 工具调用**，自主完成多步任务 |

:::tip RAG 的流程
文档切片 → **向量化（Embedding）** → 存入**向量数据库** → 用户提问向量化 → **相似度检索** → 拼接上下文 → 大模型生成回答。
:::

大模型应用的架构关注点：**幻觉**、数据安全与隐私（私有化部署）、**成本和时延**（缓存、小模型路由）、可观测性与评测、内容安全审核。

边缘计算的好处 :: 低时延、省带宽、数据隐私、离线可用

数字孪生的关键技术 :: 建模、仿真、物联网、大数据与 AI

大模型智能体 Agent :: 大模型加规划、记忆、工具调用
微调与 RAG 的区别 :: 微调改模型参数；RAG 不训练，靠检索外部知识
