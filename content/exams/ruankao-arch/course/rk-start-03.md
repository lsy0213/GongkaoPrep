软考一年两次，全国统一时间、分批次机考。下面按时间顺序把报名到拿证的流程走一遍，具体日期每年以官方通知为准。

## 一、一年两次

:::flow 时间线（大致）
上半年报名 :: 约 3～4 月，在各省软考办 / 中国计算机技术职业资格网报名、缴费
上半年考试 :: 约 5 月下旬（如 2026 年为 5 月 23–26 日，分批次）
下半年报名 :: 约 8 月
下半年考试 :: 约 10 月底到 11 月（如 2026 年为 10 月 24–27 日）
打印准考证 :: 考前约一周，在报名网站下载，看清**批次和场次**
查成绩 :: 考后约 1～2 个月，在中国计算机技术职业资格网查询
领证书 :: 合格后可下载电子证书，纸质证书按各地通知领取
:::

:::tip 设置考试日期
在本软件的“设置 → 考试与计划”里把考试日期改成你报的那一次，首页倒计时和复习计划都会跟着调整。
:::

## 二、报名

1. 进入报名网站（各省入口不同，从中国计算机技术职业资格网点进去），注册、实名认证；
2. 选择**级别（高级）→ 资格（系统架构设计师）**，选考区；
3. 上传照片、填写信息，等待审核（部分地区需要现场或线上资格审核）；
4. 审核通过后缴费，**缴费成功才算报名完成**。

:::warn 常见坑
- 报名时间只有一周左右，错过就要等半年；
- 有的省份名额有限，开放后很快报满；
- 照片规格不合格会被退回，留出修改时间。
:::

## 三、机考是怎么考的

自 2023 年下半年起，软考全部改为**计算机化考试**：

| 项目 | 机考 |
|---|---|
| 选择题 | 在电脑上点选，可以标记、来回修改 |
| 案例分析 | 键盘输入答案；需要画图时用考试系统的绘图工具 |
| 论文 | **键盘打字**，系统显示字数 |
| 输入法 | 用考场提供的输入法（一般有拼音、五笔），不能自带 |
| 草稿和计算 | 按考场规定，不能带计算器、电子设备 |

:::key 一定要提前练打字
论文 120 分钟要打出 2500 字左右，加上思考时间，**打字速度至少要 40 字/分钟**。平时就在软件的“论文写作”里限时打字练。
:::

## 四、考前准备

- 在官网下载**官方模拟作答系统**，熟悉界面、绘图工具和输入法；
- 用本软件的“机考模拟”按真实流程练一两次：综合知识和案例连考 240 分钟；
- 考试当天带**身份证 + 准考证**，提前到场。

:::check 报名、考试清单
- 查本省报名时间和入口
- 报名、审核、缴费
- 在设置里填好考试日期
- 下载官方模拟作答系统练一次
- 打印准考证，确认批次、场次和考点
- 考试当天带身份证和准考证
:::
