软件维护考四种维护类型的辨别，软件质量考 ISO/IEC 9126（以及新版 25010）的质量特性。

## 一、软件维护的四种类型

| 类型 | 原因 | 例子 |
|---|---|---|
| **改正性维护** | 修正使用中发现的错误 | 修复报表计算错误 |
| **适应性维护** | 适应**外部环境**变化 | 操作系统升级、换数据库、政策变化 |
| **完善性维护**（占比最大） | 用户提出**新功能、性能改进** | 增加导出功能、提高查询速度 |
| **预防性维护** | 为将来的维护打基础，提高可维护性和可靠性 | 重构、补充文档 |

:::tip 判断
关键看“为什么改”：有错 → 改正性；环境变了 → 适应性；用户要更多更好 → 完善性；防患于未然 → 预防性。
:::

## 二、可维护性

- 可维护性的特性：**可理解性、可测试性、可修改性**（以及可靠性、可移植性、可使用性、效率）；
- 影响维护的因素：文档质量、模块化程度、编程风格、开发人员是否在岗；
- 遗留系统的处理策略：**淘汰**（低水平、低价值）、**继承**（低水平、高价值，继续用）、**改造**（高水平、高价值）、**集成**（高水平、低价值）。

## 三、软件质量模型

ISO/IEC 9126 的 **6 个质量特性**（及子特性）：

| 特性 | 子特性 |
|---|---|
| **功能性** | 适合性、准确性、互操作性、**安全保密性**、依从性 |
| **可靠性** | 成熟性、**容错性**、易恢复性 |
| **易用性** | 易理解性、易学性、易操作性 |
| **效率** | 时间特性、资源利用性 |
| **可维护性** | 易分析性、易改变性、**稳定性**、易测试性 |
| **可移植性** | 适应性、易安装性、共存性、**易替换性** |

:::key 新标准 ISO/IEC 25010
把 6 个特性扩展为 8 个：功能适合性、性能效率、**兼容性**、易用性、可靠性、**信息安全性**、可维护性、可移植性（把安全性和兼容性独立出来）。
:::

## 四、软件质量保证

- **软件质量保证 SQA**：独立于开发团队，审计过程是否按规范执行；
- **评审**：正式技术评审 FTR、走查、审查（Inspection，最正式）；
- 质量成本：预防成本、评估成本、内部失败成本、外部失败成本。
