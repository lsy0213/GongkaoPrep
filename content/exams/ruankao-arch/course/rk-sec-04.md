网络攻击与防御考“这是什么攻击”和“用什么防”：主动与被动攻击、常见 Web 攻击、DDoS、防火墙与入侵检测。

## 一、主动攻击与被动攻击

| 类型 | 特点 | 例子 |
|---|---|---|
| **被动攻击** | 只**窃听、监视**，不修改数据，**难以检测**，重在预防（加密） | 窃听、**流量分析** |
| **主动攻击** | **篡改、伪造、中断**数据，容易检测，难以预防 | 重放、**篡改**、**伪装**、**拒绝服务** |

## 二、常见攻击

| 攻击 | 说明 | 防御 |
|---|---|---|
| **SQL 注入** | 在输入中拼接 SQL 语句 | **参数化查询（预编译）**、输入校验、最小权限 |
| **XSS 跨站脚本** | 在页面中注入恶意脚本，在其他用户浏览器执行 | 输出**转义**、CSP、HttpOnly Cookie |
| **CSRF 跨站请求伪造** | 诱导已登录用户在不知情时发出请求 | **CSRF Token**、校验 Referer、SameSite Cookie |
| **DoS / DDoS** | 耗尽资源使服务不可用；SYN Flood 等 | 流量清洗、限流、CDN、SYN Cookie |
| **重放攻击** | 截获合法报文后重新发送 | **时间戳**、随机数 nonce、序列号 |
| **中间人攻击** | 在通信双方之间截获、篡改 | 数字证书、HTTPS 双向认证 |
| **ARP 欺骗** | 伪造 ARP 应答，冒充网关 | 静态 ARP 绑定 |
| DNS 欺骗 / 劫持 | 篡改域名解析结果 | DNSSEC |
| 社会工程 | 利用人的弱点（钓鱼邮件） | 安全培训 |
| **APT 高级持续性威胁** | 针对特定目标、长期潜伏 | 纵深防御、威胁情报 |

## 三、防御技术

| 技术 | 说明 |
|---|---|
| **防火墙** | 在网络边界按规则过滤；类型有**包过滤**（网络层，快但粗）、**应用代理**（应用层，安全但慢）、**状态检测** |
| **IDS 入侵检测** | **旁路**监听，发现攻击并报警，**不阻断**；分**误用检测**（特征匹配，查已知攻击）和**异常检测**（偏离正常行为，可发现未知攻击） |
| **IPS 入侵防御** | **串联**在链路中，发现攻击**直接阻断** |
| **WAF** | Web 应用防火墙，防 SQL 注入、XSS 等 |
| 蜜罐 | 诱骗攻击者，收集攻击信息 |
| **DMZ** 隔离区 | 放置对外服务器（Web、邮件），与内网隔离 |

:::key IDS vs IPS vs 防火墙
防火墙**按规则过滤**（看地址端口）；IDS **检测报警**（旁路）；IPS **检测并阻断**（串联）。
:::

:::quiz 随堂测验
下列属于被动攻击的是：
A. 篡改
B. 重放
C. 流量分析
D. 拒绝服务
答案：C
---
防范 SQL 注入最有效的方法是：
A. 安装杀毒软件
B. 使用参数化查询
C. 增加带宽
D. 关闭日志
答案：B
---
旁路部署、只检测报警不阻断的是：
A. IDS
B. IPS
C. WAF
D. 包过滤防火墙
答案：A
:::
