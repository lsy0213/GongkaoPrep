专业英语固定是综合知识的**最后 5 题**（第 71～75 题），是一篇关于架构或软件工程的短文完形填空。掌握高频词汇，大部分空就能填对。

## 一、架构类高频词

| 英文 | 中文 |
|---|---|
| architecture style / pattern | 架构风格 / 模式 |
| component / connector | 构件 / 连接件 |
| quality attribute | 质量属性 |
| performance / availability / reliability | 性能 / 可用性 / 可靠性 |
| modifiability / maintainability | 可修改性 / 可维护性 |
| scalability / elasticity | 可伸缩性 / 弹性 |
| security / confidentiality / integrity | 安全性 / 机密性 / 完整性 |
| usability / testability / interoperability | 易用性 / 可测试性 / 互操作性 |
| trade-off / sensitivity point | 权衡 / 敏感点 |
| stakeholder | 利益相关者、干系人 |
| scenario / utility tree | 场景 / 效用树 |
| layered / pipe-and-filter / blackboard | 分层 / 管道—过滤器 / 黑板 |
| event-driven / publish-subscribe | 事件驱动 / 发布—订阅 |
| microservice / service mesh / container | 微服务 / 服务网格 / 容器 |
| loose coupling / high cohesion | 松耦合 / 高内聚 |
| fault tolerance / redundancy / failover | 容错 / 冗余 / 故障转移 |
| load balancing / caching / throughput / latency | 负载均衡 / 缓存 / 吞吐量 / 时延 |
