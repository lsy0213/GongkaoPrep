安全协议考“哪个协议工作在哪一层、提供什么安全”：SSL/TLS、IPSec、HTTPS、SSH、PGP 等。

## 一、各层的安全协议

| 层次 | 协议 |
|---|---|
| 应用层 | **HTTPS**、**SSH**、**PGP**（邮件）、**S/MIME**（邮件）、SET（电子支付）、Kerberos |
| 传输层 | **SSL / TLS** |
| 网络层 | **IPSec** |
| 数据链路层 | **PPTP**、**L2TP**、WPA2/WPA3（无线） |

## 二、TLS / HTTPS

- HTTPS = HTTP + **TLS**，默认端口 **443**；
- 握手过程：协商算法 → 服务器发送**数字证书** → 客户端验证证书 → 用非对称加密**协商会话密钥** → 之后用**对称加密**传输数据；
- 提供：**机密性**（加密）、**完整性**（MAC）、**服务器身份认证**（证书），可选客户端认证。

## 三、IPSec

| 组成 | 作用 |
|---|---|
| **AH** 认证头 | 提供**完整性和数据源认证**，**不加密** |
| **ESP** 封装安全载荷 | 提供**加密**，也可以提供完整性认证 |
| **IKE** | 密钥交换和安全关联管理 |

两种模式：**传输模式**（只保护数据部分，主机之间）、**隧道模式**（整个 IP 包封装，网关之间，用于 VPN）。

## 四、VPN

在公共网络上建立**加密隧道**：二层（PPTP、L2TP）、三层（**IPSec**）、应用层（**SSL VPN**，用浏览器即可，部署方便）。

## 五、其他

- **SSH**：替代 Telnet、FTP 的明文登录，端口 22；
- **PGP**：电子邮件加密和签名，用 IDEA 加密、RSA 管理密钥、MD5 / SHA 摘要；
- **Kerberos**：基于对称加密的认证协议（见第 3 课）；
- **网络安全体系**：纵深防御（多层防护），等级保护（下一课）。

:::key 记忆要点
HTTPS 的“S”来自 TLS（传输层）；IPSec 在网络层；“AH 不加密、ESP 加密”是高频考点。
:::
