存储体系的核心思想是用小而快的存储器配合大而慢的存储器，靠**局部性原理**让整体既快又便宜。Cache 的映射方式、平均访问时间和主存芯片计算是高频考点。

## 一、存储层次

寄存器 → **Cache** → 主存 → 辅存（磁盘、SSD），越往上越快、越贵、越小。

:::key 局部性原理
- **时间局部性**：刚访问过的数据很可能马上再访问（如循环变量）；
- **空间局部性**：访问了某个地址，附近的地址很可能也要访问（如顺序执行、数组）。
Cache、虚拟内存、页面置换都建立在局部性之上。
:::

## 二、Cache

### 1. 地址映像

| 方式 | 规则 | 优点 | 缺点 |
|---|---|---|---|
| 直接映像 | 主存块只能放到 Cache 的固定一块 | 简单、快 | **冲突率最高** |
| 全相联映像 | 主存块可放到 Cache 任一块 | 冲突率最低 | 比较慢、电路贵 |
| 组相联映像 | 组间直接、组内全相联 | 折中，最常用 | — |

### 2. 替换算法

随机、先进先出 FIFO、最近最少使用 **LRU**（命中率高、最常用）、最不经常使用 LFU。

### 3. 写策略

- **写直达（write-through）**：同时写 Cache 和主存，主存总是最新，但写得慢；
- **写回（write-back）**：只写 Cache，块被换出时才写回主存，快，但要“脏位”标记。

### 4. 平均访问时间

命中率为 h，Cache 周期 Tc，主存周期 Tm：

**平均访问时间 T = h × Tc + (1 − h) × Tm**

:::example Cache 平均访问时间
Cache 命中率 95%，Cache 存取周期 1ns，主存 100ns，平均访问时间是多少？
--- 代公式
T = 0.95 × 1 + 0.05 × 100 = 0.95 + 5
--- 答案
**5.95ns**。（若题目说“未命中时先访问 Cache 再访问主存”，未命中部分用 Tc + Tm。）
:::

## 三、主存芯片计算

- **容量** = 末地址 − 首地址 + 1（单位看编址方式：按字节编址就是字节数）；
- **芯片数量** = 总容量（位）÷ 单片容量（位）。

:::example 需要几片芯片
地址 0000H～3FFFH，按字节编址，用 4K×4bit 的芯片组成，需要几片？
--- 容量
3FFFH − 0000H + 1 = 4000H = 16384 = 16K，按字节编址即 16K × 8bit
--- 芯片数
(16K × 8) ÷ (4K × 4) = **8 片**
:::

## 四、存储器分类

| 按访问方式 | 例子 |
|---|---|
| 随机存取 | 主存（RAM） |
| 顺序存取 | 磁带 |
| 直接存取 | 磁盘 |
| **相联存储器** | 按内容访问，用于 Cache 的地址比较、快表 TLB |

RAM 中 **SRAM** 快、贵，用作 Cache；**DRAM** 需要刷新，用作主存。

:::quiz 随堂测验
三种 Cache 地址映像中，冲突率最高的是：
A. 直接映像
B. 全相联映像
C. 组相联映像
D. 一样
答案：A
---
按内容访问的存储器是：
A. 随机存储器
B. 相联存储器
C. 顺序存储器
D. 只读存储器
答案：B
---
Cache 命中率 90%，Cache 2ns，主存 50ns，按 h×Tc + (1−h)×Tm 计算的平均访问时间是：
A. 6.8ns
B. 5ns
C. 26ns
D. 7ns
答案：A
解析：0.9 × 2 + 0.1 × 50 = 1.8 + 5 = 6.8ns。
:::

:::cards 记忆卡
局部性原理的两种 :: 时间局部性、空间局部性
冲突率最高、最低的 Cache 映像 :: 直接映像最高，全相联最低，组相联折中
写直达与写回 :: 写直达同时写 Cache 和主存；写回只写 Cache，换出时再写主存
Cache 平均访问时间 :: h × Tc + (1 − h) × Tm
主存容量怎么算 :: 末地址 − 首地址 + 1
Cache 一般用什么 RAM :: SRAM（快、不需刷新）；主存用 DRAM
相联存储器的特点 :: 按内容访问
:::
