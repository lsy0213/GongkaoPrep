架构描述语言 ADL 和模型驱动架构考概念，每年约 1 题，记住名字和关键词即可。

## 一、架构描述语言 ADL

ADL 用形式化或半形式化的方式描述架构，基本元素是：**构件、连接件、架构配置**。

| ADL | 特点 |
|---|---|
| **ACME** | 架构描述的**交换语言**，可以在不同 ADL 之间转换 |
| **Wright** | 用 CSP 描述**连接件的交互协议**，支持一致性检查 |
| **C2** | 基于消息的 C2 风格，适合 GUI 软件 |
| Rapide | 基于事件，支持**仿真** |
| UniCon | 强调构件和连接件的类型，可以生成代码 |
| Darwin / π-ADL | 支持**动态**架构 |
| **AADL** | 架构分析与设计语言，主要用于**嵌入式实时系统**（航空、汽车） |

:::tip UML 和 ADL
UML 是通用建模语言，可以通过扩展（构造型、标记值、约束）描述架构，但语义不如 ADL 严格；ADL 可以做形式化分析。
:::

## 二、模型驱动架构 MDA

MDA 是 OMG 提出的方法，核心是把**业务逻辑和平台技术分离**：

:::flow MDA 的转换链
CIM 计算无关模型 :: 描述业务需求和领域，不涉及计算细节
PIM 平台无关模型 :: 描述系统功能和结构，不依赖具体技术平台
PSM 平台相关模型 :: 针对具体平台（如 Java EE、.NET）的模型
代码 :: 由 PSM 自动或半自动生成
:::

MDA 的好处：**可移植性**（同一 PIM 生成多个平台）、**互操作性**、**生产率**提高、文档与代码一致。核心标准：UML、**MOF**（元对象设施）、**XMI**（XML 元数据交换）、CWM。

## 三、模型驱动开发 MDD 与 DSL

- **MDD / MDE**：以模型为中心的开发，MDA 是它的一种具体实现；
- **领域特定语言 DSL**：为某个领域设计的小语言，比如 SQL、正则表达式、Gradle 脚本；
- 低代码平台可以看作 MDD 在今天的应用。

:::quiz 随堂测验
主要用于嵌入式实时系统建模与分析的架构描述语言是：
A. ACME
B. AADL
C. C2
D. Wright
答案：B
---
MDA 中针对具体实现技术平台的模型是：
A. CIM
B. PIM
C. PSM
D. MOF
答案：C
---
作为不同 ADL 之间交换描述的语言是：
A. ACME
B. Rapide
C. UniCon
D. Darwin
答案：A
:::
