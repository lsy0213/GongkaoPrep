# 信号量、PV 操作与前趋图
- 信号量和 P、V
  - P(S)（申请）：S = S − 1；若 S < 0，进程阻塞，排进 S 的等待队列
  - V(S)（释放）：S = S + 1；若 S ≤ 0，从等待队列唤醒一个进程
  - S 的含义
  - S ≥ 0：表示可用资源数
  - S < 0：|S| 表示正在等待的进程数
- 取值范围
  - 取值范围：m ～ m − n
- 前趋图
  - 万能规则
  - 每一条箭头设一个信号量（初值 0）
  - 箭头的起点进程结束时执行 V；箭头的终点进程开始前执行 P
- 生产者—消费者
  - 生产一个产品：P(full)
  - P(empty)：P(mutex)
  - P(mutex)：从缓冲区取产品
  - 放入缓冲区：V(mutex)
  - V(mutex)：V(empty)
  - V(full)：消费
  - 顺序不能反
- 记忆要点
  - P 操作做什么：S 减 1，若 S < 0 则阻塞
  - V 操作做什么：S 加 1，若 S ≤ 0 则唤醒一个等待进程
  - S < 0 时 |S| 表示：等待该资源的进程数
  - 互斥信号量初值：1
  - n 个进程共享 m 个资源，信号量范围：m ～ m − n
  - 前趋图信号量规则：每条箭头一个信号量；起点 V，终点 P
