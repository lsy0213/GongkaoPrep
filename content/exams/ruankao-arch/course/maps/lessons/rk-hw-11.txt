# 计算机网络：体系结构与协议
- 分层模型
  - 应用层、表示层、会话层：应用层；HTTP、FTP、SMTP、DNS、SNMP
  - 传输层：传输层；TCP、UDP
  - 网络层：网际层；IP、ICMP、ARP、路由协议
  - 数据链路层：网络接口层；以太网、PPP
  - 物理层：网络接口层；—
- TCP 与 UDP
  - 连接：面向连接（三次握手建立，四次挥手释放）；无连接
  - 可靠性：可靠：确认、重传、按序；不可靠，尽最大努力交付
  - 流量 / 拥塞控制：滑动窗口流量控制；慢开始、拥塞避免等；没有
  - 适用：文件传输、网页、邮件；视频、语音、DNS 查询、实时应用
  - 常用端口
- 几个协议
  - ARP：已知 IP 地址求 MAC 地址；RARP 反过来
  - ICMP：差错报告和查询，ping、tracert 用它
  - DHCP：自动分配 IP 地址
  - DNS：域名 → IP。查询方式有递归（让服务器替我查到底）和迭代
- 网络规划
  - 核心层：高速转发，不做复杂策略
  - 汇聚层：路由聚合、访问控制、策略
  - 接入层：用户接入、VLAN 划分
- 记忆要点
  - OSI 七层：物理、数据链路、网络、传输、会话、表示、应用
  - 路由器、交换机各在哪层：路由器网络层，交换机数据链路层
  - TCP 建立连接：三次握手
  - TCP 流量控制方法：滑动窗口
  - ARP 的作用：已知 IP 求 MAC
  - HTTPS 端口：443
