# 网络攻击与防御
- 主动攻击与被动攻击
  - 被动攻击：只窃听、监视，不修改数据，难以检测，重在预防（加密）；窃听、流量分析
  - 主动攻击：篡改、伪造、中断数据，容易检测，难以预防；重放、篡改、伪装、拒绝服务
- 常见攻击
  - SQL 注入：在输入中拼接 SQL 语句；参数化查询（预编译）、输入校验、最小权限
  - XSS 跨站脚本：在页面中注入恶意脚本，在其他用户浏览器执行
  - CSRF 跨站请求伪造：诱导已登录用户在不知情时发出请求
  - DoS / DDoS：耗尽资源使服务不可用；SYN Flood 等
  - 重放攻击：截获合法报文后重新发送；时间戳、随机数 nonce、序列号
  - 中间人攻击：在通信双方之间截获、篡改；数字证书、HTTPS 双向认证
  - ARP 欺骗：伪造 ARP 应答，冒充网关；静态 ARP 绑定
  - DNS 欺骗 / 劫持：篡改域名解析结果；DNSSEC
- 防御技术
  - 防火墙：在网络边界按规则过滤；类型有包过滤（网络层，快但粗）、应用代理
  - IDS 入侵检测：旁路监听，发现攻击并报警，不阻断；分误用检测
  - IPS 入侵防御：串联在链路中，发现攻击直接阻断
  - WAF：Web 应用防火墙，防 SQL 注入、XSS 等
  - 蜜罐：诱骗攻击者，收集攻击信息
  - DMZ 隔离区：放置对外服务器（Web、邮件），与内网隔离
  - IDS vs IPS vs 防火墙
- 记忆要点
  - 被动攻击的特点：只窃听不修改，难检测，重在预防
  - 主动攻击举例：重放、篡改、伪装、拒绝服务
  - SQL 注入的防御：参数化查询、输入校验、最小权限
  - XSS 的防御：输出转义、CSP、HttpOnly
  - CSRF 的防御：CSRF Token、校验 Referer、SameSite Cookie
  - 重放攻击的防御：时间戳、随机数、序列号
