# 操作系统概述与进程管理
- 操作系统的五大功能
- 进程
  - 进程是程序的一次执行过程，是动态的；程序是静态的指令集合
  - 进程由程序、数据、进程控制块 PCB 组成，PCB 是进程存在的唯一标志
  - 进程是资源分配的基本单位；引入线程后，线程是 CPU 调度的基本单位
  - 进程三态
    - 就绪 → 运行：被调度程序选中，分到 CPU
    - 运行 → 就绪：时间片用完，或被更高优先级的进程抢占
    - 运行 → 阻塞：等待某个事件（如 I/O、信号量）
    - 阻塞 → 就绪：等待的事件发生了（注意：不能直接回到运行）
    - 易错
- 线程
- 调度算法
  - 先来先服务 FCFS：简单，对短作业不利
  - 短作业优先 SJF：平均等待时间最短，长作业可能“饿死”
  - 优先级调度：可抢占 / 不可抢占；低优先级可能饥饿
  - 时间片轮转 RR：分时系统常用，响应快
  - 多级反馈队列：综合了以上优点，多级队列、优先级逐级降低、时间片逐级加大
- 记忆要点
  - 进程由什么组成：程序、数据、进程控制块 PCB
  - 资源分配和 CPU 调度的基本单位：资源分配是进程，调度是线程
  - 进程三态：就绪、运行、阻塞
  - 阻塞态事件完成后进入：就绪态（不能直接运行）
  - 线程独有的资源：栈、寄存器（含 PC）、线程控制块
  - 平均等待时间最短的调度算法：短作业优先 SJF
