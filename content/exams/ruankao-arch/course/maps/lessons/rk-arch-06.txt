# 构件与中间件
- 构件与连接件
  - 构件：可独立部署的计算单元，通过接口与外界交互
  - 连接件：构件之间的交互机制，如过程调用、消息、事件、管道、共享数据、RPC
  - 构件组装的不匹配：构件本身不匹配、连接件不匹配、部署时不匹配
- 中间件
  - 数据库中间件：屏蔽不同数据库的差异；ODBC、JDBC、MyCat等
  - 远程过程调用 RPC：像调用本地函数一样调用远程服务；gRPC、Dubbo、Thrift
  - 面向消息的中间件 MOM：异步消息传递，解耦、削峰、异步
  - 分布式对象中间件：分布式对象调用；CORBA、DCOM、Java RMI
  - 事务处理中间件（TP 监视器）：分布式事务、负载均衡；Tuxedo、CICS
  - 应用服务器：为 Web 应用提供运行环境
  - 消息中间件的作用
- CORBA 的结构
  - ORB（对象请求代理）：核心，负责请求的传递
  - IDL（接口定义语言）：描述接口，与语言无关
  - 桩 Stub（客户端代理）和骨架 Skeleton（服务端代理）
  - 对象适配器 POA：连接 ORB 和对象实现
- 构件技术与 Web 服务的比较
- 记忆要点
  - 构件的两类接口：提供接口和需要接口
  - 构件不匹配的解决办法：包装器、适配器、桥接器、中介器
  - 中间件的位置：操作系统、网络与应用之间
  - 消息中间件的作用：异步、解耦、削峰、可靠投递
  - 点对点与发布订阅：点对点一条消息一个消费者；发布订阅一条消息多个订阅者
  - CORBA 的核心：ORB 对象请求代理
