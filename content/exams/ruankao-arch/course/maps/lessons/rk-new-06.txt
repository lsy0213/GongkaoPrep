# 云原生：容器、Kubernetes 与 Serverless
- 云计算基础
  - IaaS 基础设施即服务：虚拟机、存储、网络；云服务器 ECS
  - PaaS 平台即服务：运行环境、中间件、数据库；云数据库、应用托管
  - SaaS 软件即服务：直接可用的软件；在线办公、CRM
- 云原生
  - 云原生的核心技术（CNCF 定义）
- 容器与 Kubernetes
  - 虚拟化层次：硬件虚拟化，每个 VM 有完整操作系统；操作系统级虚拟化，共享宿主机内核
  - 启动：分钟级；秒级
  - 资源占用：大；小
  - 隔离性：强；较弱
  - Docker：镜像（只读模板）、容器（镜像的运行实例）、仓库
  - Kubernetes（K8s）：容器编排平台
  - Pod：最小调度单位，一组共享网络和存储的容器
  - Deployment：声明副本数，支持滚动更新和回滚
- Serverless
  - FaaS（函数即服务）+ BaaS（后端即服务）
  - 特点：不用管服务器、按调用计费、自动弹性伸缩（可以缩到 0）、事件驱动
  - 缺点：冷启动延迟、执行时间受限、调试困难、厂商锁定
- 发布策略
  - 蓝绿发布：两套环境，切换流量，回滚快
  - 灰度（金丝雀）发布：先让一小部分用户用新版本，逐步放量
  - 滚动更新：逐个替换实例（K8s 默认）
- 记忆要点
  - 云计算三种服务模式：IaaS、PaaS、SaaS
  - 云原生核心技术：容器、服务网格、微服务、不可变基础设施、声明式 API
  - 容器与虚拟机的根本区别：容器是操作系统级虚拟化，共享内核
  - K8s 的 Pod：最小调度单位，一组共享网络和存储的容器
  - K8s 的 HPA：根据指标自动水平扩缩容
  - Serverless 组成：FaaS + BaaS
