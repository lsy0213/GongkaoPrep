# 嵌入式系统架构与通信系统架构
- 嵌入式软件架构
  - 层次化架构：硬件层 → 硬件抽象层 HAL / BSP → 操作系统层 → 中间件层 → …
  - 递归模式架构：构件可以嵌套组合
  - IMA 综合模块化航电：用通用的硬件模块和分区操作系统替代联合式航电，资源共享、降低体积重量
  - 分区操作系统（ARINC 653）
- 嵌入式数据库与中间件
  - 嵌入式数据库：SQLite、Berkeley DB 等；特点是体积小、嵌入应用、零配置
  - 嵌入式中间件：DDS
- 安全关键系统
  - 安全性分析方法：FMEA（故障模式及影响分析，自下而上）、FTA
  - 软件安全等级：如航空的 DO-178C
  - 设计手段：冗余（双机、三模）、看门狗、分区隔离、形式化验证、MC/DC 覆盖测试
- 通信系统架构
  - 局域网：单核心、双核心、环形、层次型（核心层、汇聚层、接入层）
  - 广域网：单核心、双核心、环形、半冗余、对等子域、层次子域
  - 移动通信：5G 的三大场景：eMBB（增强移动宽带）、URLLC（超高可靠低时延）等
  - 存储网络：DAS（直连）、NAS（文件级，网络附加存储）、SAN（块级，存储区域网络）
  - SDN：软件定义网络：控制平面与数据平面分离，集中控制
- 记忆要点
  - 嵌入式层次化架构：硬件层、硬件抽象层 / BSP、操作系统、中间件、应用层
  - ARINC 653：分区操作系统，分区在时间和空间上隔离
  - IMA：综合模块化航电，资源共享
  - FMEA 与 FTA：FMEA 自下而上分析故障影响；FTA 自顶向下找失效原因
  - DO-178C：航空机载软件标准，A 级最高
  - 5G 三大场景：eMBB、URLLC、mMTC
