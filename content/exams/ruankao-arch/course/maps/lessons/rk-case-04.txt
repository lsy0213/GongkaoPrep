# 数据库与缓存题
- 高频问法与答案要点
  - Redis 和 MySQL 怎么分工：热点数据、会话、计数放 Redis
  - Redis 的持久化方式：RDB 快照、AOF 日志，比较优缺点
  - Redis 的数据类型选择：排行榜用 ZSet，对象用 Hash，队列用 List
  - 缓存穿透 / 击穿 / 雪崩：现象 + 对策（见数据库课程第 9 课）
  - 缓存与数据库一致性：先更新数据库再删除缓存；延迟双删；订阅 binlog 异步更新
  - 反规范化的手段：增加冗余列、派生列、重新组表、分割表
  - 反规范化的问题与对策：数据不一致 → 触发器、应用同步、批处理
  - 读写分离的问题：主从延迟导致读到旧数据 → 关键读走主库、延迟检测

- 记忆要点
  - 排行榜用 Redis 的：ZSet 有序集合
  - Cache Aside 写操作：先更新数据库，再删除缓存
  - 防缓存雪崩：过期时间加随机值、缓存高可用、限流降级、多级缓存
  - 反规范化后保持一致：触发器、应用程序同步、批处理
  - MongoDB 的优势：模式灵活、易水平扩展
