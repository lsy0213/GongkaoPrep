# 数制、编码与校验码
- 进制转换
  - R 进制 → 十进制：按权展开：(1011)₂ = 1×2³ + 0×2² + 1×2¹ …
  - 十进制整数 → R 进制：除 R 取余，倒着写
  - 十进制小数 → 二进制：乘 2 取整，顺着写
  - 二进制 ↔ 八 / 十六进制：3 位 / 4 位一组
- 原码、反码、补码、移码
  - 原码：0000 0101；1000 0101
  - 反码：0000 0101；1111 1010
  - 补码：0000 0101；1111 1011
  - 移码：1000 0101；0111 1011
  - 记住三条
- 浮点数
  - 阶码的位数决定表示范围，尾数的位数决定精度
  - 浮点加减：对阶（小阶向大阶看齐）→ 尾数加减 → 规格化 → 舍入 → 溢出判断
- 校验码
  - 奇偶校验：只能检出奇数个位错，不能纠错；加 1 位校验位
  - 海明码：能检错，能纠正 1 位错；校验位 r 满足 2ʳ ≥ k + r + 1
  - CRC 循环冗余校验：检错能力强，不能纠错；模 2 除法；生成多项式最高次幂为 r
- 记忆要点
  - 负数的补码怎么求：原码符号位不变、其余各位取反，再加 1
  - n 位补码的表示范围：−2^(n−1) ～ 2^(n−1)−1
  - 移码和补码的关系：补码的符号位取反
  - 浮点数阶码、尾数各决定什么：阶码决定表示范围，尾数决定精度
  - 浮点数加减的步骤：对阶（小阶向大阶看齐）→ 尾数运算 → 规格化 → 舍入 → 溢出判断
  - 海明码校验位公式：2^r ≥ k + r + 1（k 数据位，r 校验位）
