# NoSQL、Redis 与缓存设计
- NoSQL 的四类
  - 键值：Redis、Memcached；缓存、会话、计数器
  - 列族：HBase、Cassandra；海量数据、写多读少、按列分析
  - 文档：MongoDB；结构多变的 JSON 文档
  - 图：Neo4j；社交关系、推荐、知识图谱
- Redis
  - String：缓存对象、计数器、分布式锁
  - Hash：存对象的多个字段
  - List：消息队列、最新列表
  - Set：去重、共同好友（交集）
  - ZSet（有序集合）：排行榜
  - 持久化：RDB（定时快照，恢复快、可能丢最后一段数据）、AOF
  - 集群：主从复制（读写分离）、哨兵（自动故障切换）等
- 缓存的三大问题
  - 缓存穿透：查询根本不存在的数据，每次都打到数据库；缓存空值、布隆过滤器、参数校验
  - 缓存击穿：某个热点 key 过期瞬间，大量请求打到数据库
  - 缓存雪崩：大量 key 同时过期或缓存宕机；过期时间加随机值、集群高可用、限流降级、多级缓存
  - 缓存与数据库一致性
- 记忆要点
  - NoSQL 四类：键值、列族、文档、图
  - 社交关系用哪类 NoSQL：图数据库，如 Neo4j
  - RDB 持久化：定时快照，恢复快，可能丢数据
  - AOF 持久化：记录写命令，数据完整，文件大恢复慢
  - 缓存穿透：查不存在的数据；用空值缓存、布隆过滤器
  - Cache Aside 写操作：先更新数据库，再删除缓存
