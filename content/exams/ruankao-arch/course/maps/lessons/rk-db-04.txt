# 关系代数与 SQL
- 关系代数运算
  - 并、差、交：∪ − ∩；要求两个关系结构相同（同元、同域）
  - 笛卡尔积：×；列数相加，行数相乘
  - 选择：σ；选行（按条件）
  - 投影：π；选列
  - θ 连接：⋈；笛卡尔积后按条件选行
  - 自然连接：⋈；在同名属性上做等值连接，并去掉重复的同名列
  - 除：÷；“包含所有”类查询
  - 查询效率
- SQL 语句结构
  - WHERE 和 HAVING
- 其他常考语句
  - 视图：CREATE VIEW … AS SELECT …
  - 授权：GRANT 权限 ON 对象 TO 用户 [WITH GRANT OPTION]
  - 完整性：PRIMARY KEY、FOREIGN KEY … REFERENCES等
  - 索引：加快查询，但减慢插入和修改
- 记忆要点
  - 笛卡尔积的列数和行数：列数相加，行数相乘
  - 自然连接：在同名属性上等值连接，并去掉重复列
  - 提高查询效率的原则：尽早做选择和投影，再连接
  - WHERE 和 HAVING 的区别：WHERE 分组前筛行、不能用聚集函数
  - WITH GRANT OPTION：被授权者可以把权限再授给别人
  - WITH CHECK OPTION：通过视图修改的数据必须满足视图条件
