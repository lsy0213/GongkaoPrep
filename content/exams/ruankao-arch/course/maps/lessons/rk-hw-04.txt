# 总线、输入输出与中断
- 总线
  - 按传送内容分：数据总线、地址总线、控制总线
  - 地址总线的宽度决定可寻址的范围（n 位地址线可寻址 2ⁿ 个单元）
  - 总线带宽 = 总线频率 × 总线宽度（位）÷ 8（字节/秒）
- 四种 I/O 控制方式
  - 程序查询：全程等待、反复查询；最简单，CPU 利用率最低
  - 程序中断：外设准备好时中断 CPU；CPU 和外设可以并行
  - DMA：只在开始和结束时介入；数据在外设和主存之间直接传送，不经过 CPU
  - 通道 / I/O 处理机：几乎不参与；专门的处理机管理 I/O
  - DMA 的三个要点
  - DMA 请求在一个总线周期结束后响应（中断请求是在一条指令执行结束后响应）
- 中断
  - 中断向量：中断服务程序的入口地址，用来快速找到服务程序
  - 响应过程：关中断 → 保护现场（断点） → 识别中断源 → 执行服务程序 → 恢复现场 →…
  - 中断响应时间：从发出中断请求到开始执行服务程序第一条指令的时间
- 记忆要点
  - 三类总线：数据总线、地址总线、控制总线
  - 地址总线宽度决定什么：可寻址空间（n 位可寻址 2ⁿ 个单元）
  - CPU 利用率最低的 I/O 方式：程序查询
  - DMA 的特点：外设与主存直接传数据，不经 CPU；CPU 只在开始和结束时介入
  - DMA 请求和中断请求的响应时机：DMA 在总线周期结束后；中断在指令执行结束后
