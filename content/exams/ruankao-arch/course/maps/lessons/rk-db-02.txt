# 数据库三级模式与数据模型
- 三级模式、两级映像
  - 外模式：子模式、用户模式；用户看到的视图，可以有多个
  - 概念模式：模式、逻辑模式；全体数据的逻辑结构（表），只有一个
  - 内模式：存储模式；物理存储方式（索引、存储文件），只有一个
  - 两级映像 → 两种独立性
  - 外模式 / 模式映像 → 逻辑独立性：表结构改了，只改映像，应用程序不用改
  - 模式 / 内模式映像 → 物理独立性：存储方式改了（加索引、换文件组织），表结构和应用不用改
  - 真题陷阱
- 数据模型
  - 概念模型：E-R 图，和具体数据库无关
  - 逻辑模型：层次、网状、关系、面向对象模型
  - 物理模型：数据在存储介质上的组织
- 关系模型的术语
  - 关系：一张二维表
  - 元组：一行
  - 属性：一列
  - 域：属性的取值范围
  - 候选码（候选键）：能唯一标识元组、且没有多余属性的属性组
  - 主码（主键）：选定的一个候选码
  - 主属性：包含在任何一个候选码中的属性
  - 外码（外键）：本表中引用另一张表主码的属性
- 完整性约束
  - 实体完整性：主码不能为空、不能重复
  - 参照完整性：外码要么为空，要么等于被参照表中某个主码值
  - 用户定义完整性：如“工资必须在 2000～50000 之间”，用 CHECK 或触发器实现
- 记忆要点
  - 三级模式：外模式（用户视图）、概念模式（逻辑结构）、内模式（存储结构）
  - 逻辑独立性靠什么：外模式 / 模式映像
  - 物理独立性靠什么：模式 / 内模式映像
  - 建聚簇索引改变哪一级模式：内模式
  - 实体完整性：主码非空且唯一
  - 参照完整性：外码为空或等于被参照表的主码值
