# 系统建模题：UML、数据流图与 E-R 图
- 用例图
  - 参与者：人或外部系统，画在系统边界外
  - 用例：系统提供的功能，动词 + 名词（“提交订单”）
  - 关系：include（必须执行，提取公共部分）、extend（条件满足时可选执行）、泛化
- 类图
  - 找类：说明中的名词；找属性：名词的描述；找操作：动词
  - 关系：整体部分能独立存在 → 聚合；不能 → 组合；“是一种” → 泛化
  - 多重度：1、0..1、*、1..*；比如“一个订单包含一个或多个商品明细”：订单端 1
- 顺序图和活动图
  - 活动图：泳道按角色分，分叉 / 汇合表示并行，菱形表示判断
- 数据流图 DFD
  - 补全 DFD 的方法
  - 外部实体：系统之外提供或接收数据的人、组织、系统
  - 数据存储：说明里“保存在……表 / 文件中”的东西
  - 加工：动词短语（“审核订单”）
  - 补数据流：利用父图子图平衡——子图的输入输出必须和父图对应加工一致
- E-R 图
- 记忆要点
  - 用例的命名：动词加名词
  - 找类的方法：名词是类，名词的描述是属性，动词是操作
  - include 与 extend：include 必须执行；extend 条件满足时执行
  - DFD 中的数据存储：说明中保存数据的表或文件
  - 父图子图平衡：子图输入输出与父图对应加工一致
  - 关联关系本身有属性时：建模为关联类
