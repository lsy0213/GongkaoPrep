# 架构描述语言与模型驱动架构
- 架构描述语言 ADL
  - ACME：架构描述的交换语言，可以在不同 ADL 之间转换
  - Wright：用 CSP 描述连接件的交互协议，支持一致性检查
  - C2：基于消息的 C2 风格，适合 GUI 软件
  - Rapide：基于事件，支持仿真
  - UniCon：强调构件和连接件的类型，可以生成代码
  - Darwin / π-ADL：支持动态架构
  - AADL：架构分析与设计语言，主要用于嵌入式实时系统（航空、汽车）
  - UML 和 ADL
- 模型驱动架构 MDA
  - CIM 计算无关模型：描述业务需求和领域，不涉及计算细节
  - PIM 平台无关模型：描述系统功能和结构，不依赖具体技术平台
  - PSM 平台相关模型：针对具体平台（如 Java EE、.NET）的模型
  - 代码：由 PSM 自动或半自动生成
- 模型驱动开发 MDD 与 DSL
  - MDD / MDE：以模型为中心的开发，MDA 是它的一种具体实现
  - 领域特定语言 DSL：为某个领域设计的小语言，比如 SQL、正则表达式、Gradle 脚本
- 记忆要点
  - ADL 的三个基本元素：构件、连接件、架构配置
  - AADL：嵌入式实时系统的架构分析与设计语言
  - MDA 的模型链：CIM → PIM → PSM → 代码
  - MDA 的核心标准：UML、MOF、XMI、CWM
