# 架构风格选择与架构设计题
- 对比题的答题模板
  - 点出需求：“根据题目描述，系统的关键需求是……
  - 方案一分析：“方案一采用……风格，其优点是……，但……”
  - 方案二分析：“方案二采用……风格，其优点是……，缺点是……”
  - 结论：“综合考虑……，选择方案二更合适。”
  - 表格作答更清晰
- 常见风格对比结论（背下来）
  - 编译器 / IDE 的语法树共享：数据共享（仓库）风格
  - 简单可预测环境的控制：闭环控制
  - 复杂环境下的机器人 / 自动驾驶：分层 + 事件驱动
  - 规则频繁变化：基于规则的系统、解释器
  - 工具集成、松耦合：隐式调用（事件驱动）
  - 语音识别、模式识别：黑板
  - 大型互联网应用：微服务 + 分层
- 架构图题
  - 题目给一张有空缺的分层架构图（表现层、业务层、数据层……）或部署图，让你填空
  - 方法：根据说明中提到的技术和组件，按“从上到下：用户 → 接入 → 应用 → 服务 → 数…
- 记忆要点
  - 风格对比题的四段式：点出需求、分析方案一、分析方案二、给出结论
  - IDE 中的编译器：以语法树为中心的数据共享风格
  - 规则频繁变化：基于规则的系统或解释器
  - 复杂环境中的机器人：分层加事件驱动
  - 填架构图的顺序：用户、接入、应用、服务、数据，从上到下对号入座
