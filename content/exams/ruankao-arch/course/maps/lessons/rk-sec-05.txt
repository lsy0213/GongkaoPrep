# 安全协议与网络安全体系
- 各层的安全协议
  - 应用层：HTTPS、SSH、PGP（邮件）、S/MIME（邮件）、SET（电子支付）等
  - 传输层：SSL / TLS
  - 网络层：IPSec
  - 数据链路层：PPTP、L2TP、WPA2/WPA3（无线）
- TLS / HTTPS
  - HTTPS = HTTP + TLS，默认端口 443
  - 握手过程：协商算法 → 服务器发送数字证书 → 客户端验证证书 → 用非对称加密协商会话密…
  - 提供：机密性（加密）、完整性（MAC）、服务器身份认证（证书），可选客户端认证
- IPSec
  - AH 认证头：提供完整性和数据源认证，不加密
  - ESP 封装安全载荷：提供加密，也可以提供完整性认证
  - IKE：密钥交换和安全关联管理
- VPN
- 其他
  - SSH：替代 Telnet、FTP 的明文登录，端口 22
  - PGP：电子邮件加密和签名，用 IDEA 加密、RSA 管理密钥、MD5 / SHA 摘要
  - Kerberos：基于对称加密的认证协议（见第 3 课）
  - 网络安全体系：纵深防御（多层防护），等级保护（下一课）
  - 记忆要点
- 记忆要点
  - SSL / TLS 工作在：传输层
  - IPSec 工作在：网络层
  - IPSec 的 AH：完整性和数据源认证，不加密
  - IPSec 的 ESP：提供加密，也可认证
  - IPSec 两种模式：传输模式和隧道模式
  - HTTPS 默认端口：443
