# 论点展开：理论、实践与效果
- 理论阐述怎么写
  - 回答论述要求中的“主要内容 / 概念 / 分类 / 过程”
  - 300～400 字，用条目式：“ATAM 分为四个阶段：一是……；二是……”
  - 只写和论题直接相关的理论，不要大段抄教材
- 实践论点怎么写
  - 一个论点的“五步法”
  - 提出做法（小标题）：“采用 Redis 缓存提高查询性能”
  - 说明原因：项目中遇到了什么问题，有什么需求或约束
  - 具体实施：技术方案、关键设计、方案对比和选择理由（体现架构师的决策）
  - 问题与解决：实施中遇到的困难，怎么解决的
  - 效果：用数据说明
- 效果、不足与改进
  - 效果：上线时间、运行情况、量化指标，用户评价
  - 不足：客观写 1～2 点（“由于工期紧，监控体系还不完善”），不要写致命问题
  - 改进：针对不足提出下一步计划
- 记忆要点
  - 理论阐述的写法：条目式，300～400 字，只写与论题相关的，最后过渡到项目
  - 实践论点五步法：提出做法、说明原因、具体实施、问题与解决、效果
  - 体现架构师思考：写出方案对比和选择理由
  - 效果的写法：用数据说话
  - 不足的写法：客观写 1～2 点，不写致命问题，并提出改进
