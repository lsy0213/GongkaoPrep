# 存储体系与 Cache
- 存储层次
  - 局部性原理
  - 时间局部性：刚访问过的数据很可能马上再访问（如循环变量）
  - 空间局部性：访问了某个地址，附近的地址很可能也要访问（如顺序执行、数组）
- Cache
  - 1. 地址映像
    - 直接映像：主存块只能放到 Cache 的固定一块；简单、快
    - 全相联映像：主存块可放到 Cache 任一块；冲突率最低
    - 组相联映像：组间直接、组内全相联；折中，最常用
  - 2. 替换算法
  - 3. 写策略
    - 写直达（write-through）：同时写 Cache 和主存，主存总是最新，但写得慢
    - 写回（write-back）：只写 Cache，块被换出时才写回主存，快，但要“脏位”标记
  - 4. 平均访问时间
- 主存芯片计算
  - 容量 = 末地址 − 首地址 + 1（单位看编址方式：按字节编址就是字节数）
  - 芯片数量 = 总容量（位）÷ 单片容量（位）
- 存储器分类
  - 随机存取：主存（RAM）
  - 顺序存取：磁带
  - 直接存取：磁盘
  - 相联存储器：按内容访问，用于 Cache 的地址比较、快表 TLB
- 记忆要点
  - 局部性原理的两种：时间局部性、空间局部性
  - 冲突率最高、最低的 Cache 映像：直接映像最高，全相联最低，组相联折中
  - 写直达与写回：写直达同时写 Cache 和主存；写回只写 Cache，换出时再写主存
  - Cache 平均访问时间：h × Tc + (1 − h) × Tm
  - 主存容量怎么算：末地址 − 首地址 + 1
  - Cache 一般用什么 RAM：SRAM（快、不需刷新）；主存用 DRAM
