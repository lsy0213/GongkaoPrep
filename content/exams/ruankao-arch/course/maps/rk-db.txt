- 数据库基础
  - 三级模式两级映像 @rk-db-02

    - 模式 / 内模式映像 → 物理独立性

  - 关系代数与 SQL @rk-db-04
    - 自然连接去重复列；尽早选择投影

- 规范化
  - 函数依赖、候选键与范式 @rk-db-05
    - 入度为 0 的属性一定在候选键中
    - 2NF 消除部分依赖，3NF 消除传递依赖
  - 模式分解 @rk-db-06
    - 无损连接：公共属性是某一方的码
    - 保持函数依赖
- 事务与并发 @rk-db-07
  - ACID；丢失修改、脏读、不可重复读
  - 两段锁协议保证可串行化
  - 系统故障：未提交 UNDO，已提交 REDO

  - 分布式数据库、CAP 与 BASE @rk-db-08
    - 分片透明最高；2PC、TCC、Saga
  - NoSQL、Redis 与缓存 @rk-db-09

  - 反规范化：冗余列、派生列、重新组表、分割表
