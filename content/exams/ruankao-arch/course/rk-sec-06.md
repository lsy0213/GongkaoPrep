## 一、网络安全等级保护 2.0

**五个等级**（GB/T 22239—2019），依据是受到破坏后对**公民、法人和其他组织**的合法权益、**社会秩序和公共利益**、**国家安全**的损害程度：

| 等级 | 名称 | 受侵害后果 |
|---|---|---|
| 第一级 | 用户自主保护级 | 对公民、法人合法权益造成损害 |
| 第二级 | 系统审计保护级 | 对公民、法人合法权益造成**严重**损害，或对社会秩序和公共利益造成损害 |
| 第三级 | **安全标记保护级** | 对社会秩序和公共利益造成**严重**损害，或对国家安全造成损害 |
| 第四级 | 结构化保护级 | 对社会秩序和公共利益造成**特别严重**损害，或对国家安全造成严重损害 |
| 第五级 | 访问验证保护级 | 对国家安全造成特别严重损害 |

:::tip 名称来源
等级名称来自 GB 17859 计算机信息系统安全保护等级：用户自主、系统审计、安全标记、结构化、访问验证。
:::

- 等保 2.0 的工作环节：**定级 → 备案 → 建设整改 → 等级测评 → 监督检查**；
- 第三级以上系统**每年至少测评一次**；
- 技术要求：安全物理环境、安全通信网络、安全区域边界、安全计算环境、安全管理中心；管理要求：安全管理制度、机构、人员、建设管理、运维管理；
- 扩展要求：云计算、移动互联、物联网、工业控制系统、大数据。

## 二、风险评估

:::key 风险评估的要素
**资产**（价值）、**威胁**（可能造成损害的因素）、**脆弱性**（资产自身的弱点）、**安全措施**、**风险**。
风险 = f(资产价值, 威胁可能性, 脆弱性严重程度)。威胁利用脆弱性对资产造成损害，形成风险。
:::

风险评估流程：评估准备 → **资产识别** → **威胁识别** → **脆弱性识别** → 已有安全措施确认 → **风险分析** → 风险处置建议。

风险处置方式：**规避**（不做）、**转移**（保险、外包）、**降低**（加安全措施）、**接受**。

## 三、相关法律

《网络安全法》（2017）、《数据安全法》（2021）、《个人信息保护法》（2021）、《密码法》（2020）、关键信息基础设施安全保护条例。
