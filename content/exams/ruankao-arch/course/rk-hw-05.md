操作系统是综合知识的必考章节，每年 4～6 分。这一课先讲进程的基本概念和调度，下一课讲 PV 操作。

## 一、操作系统的五大功能

进程（处理机）管理、存储管理、文件管理、设备管理、作业管理（用户接口）。

## 二、进程

- 进程是**程序的一次执行过程**，是动态的；程序是静态的指令集合；
- 进程由**程序、数据、进程控制块 PCB** 组成，**PCB 是进程存在的唯一标志**；
- 进程是**资源分配**的基本单位；引入线程后，**线程是 CPU 调度**的基本单位。

### 进程三态

:::flow 状态转换
就绪 → 运行 :: 被调度程序选中，分到 CPU
运行 → 就绪 :: 时间片用完，或被更高优先级的进程抢占
运行 → 阻塞 :: 等待某个事件（如 I/O、信号量）
阻塞 → 就绪 :: 等待的事件发生了（注意：**不能直接回到运行**）
:::

:::warn 易错
阻塞态的进程事件完成后只能先进入**就绪**，等待调度，不能直接变成运行态；就绪也不能直接变成阻塞。
:::

## 三、线程

同一进程的线程**共享**进程的代码段、数据段、打开的文件、全局变量等资源；但**每个线程有自己的栈、寄存器（含程序计数器）和线程控制块**。

## 四、调度算法

| 算法 | 特点 |
|---|---|
| 先来先服务 FCFS | 简单，对短作业不利 |
| 短作业优先 SJF | 平均等待时间最短，长作业可能“饿死” |
| 优先级调度 | 可抢占 / 不可抢占；低优先级可能饥饿 |
| 时间片轮转 RR | 分时系统常用，响应快 |
| 多级反馈队列 | 综合了以上优点，多级队列、优先级逐级降低、时间片逐级加大 |

:::example 平均周转时间
三个作业同时到达，运行时间分别为 6、2、4 小时，单道运行。按短作业优先，平均周转时间是多少？
--- 顺序
SJF：2 → 4 → 6
--- 各作业周转时间
完成时刻：2、6、12（同时到达，周转时间 = 完成时刻）
--- 答案
(2 + 6 + 12) ÷ 3 = **20/3 ≈ 6.67 小时**。按 FCFS（6、2、4 的顺序）则是 (6 + 8 + 12) ÷ 3 ≈ 8.67 小时。
:::

:::quiz 随堂测验
进程存在的唯一标志是：
A. 程序
B. 数据
C. 进程控制块 PCB
D. 线程
答案：C
---
同一进程的多个线程之间不能共享的是：
A. 代码段
B. 打开的文件
C. 全局变量
D. 栈
答案：D
解析：每个线程有自己的栈和寄存器。
---
下列状态转换不可能发生的是：
A. 运行 → 就绪
B. 就绪 → 运行
C. 阻塞 → 运行
D. 运行 → 阻塞
答案：C
:::
