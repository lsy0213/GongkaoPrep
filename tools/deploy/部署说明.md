# 放到服务器上，手机随时打开（服务器模式）

`python main.py --server` 是服务器模式：不开窗口，只听本机 127.0.0.1:8769，前面由 Nginx 提供 HTTPS；
手机、别的电脑用浏览器打开 `https://<服务器 IP>/`，输入密码登录。只有一个使用者（你自己）。

和局域网「手机访问」的区别：电脑不用开着，出门在外也能用；但服务器上是**单独的一份**学习记录，和电脑上的不同步。

代码见 `gongkao/remote.py`（登录）、`gongkao/server.py`（`is_remote` 的访问控制）。下面以和 EngNest 同一台腾讯云轻量服务器（Ubuntu 24.04）为例，
共用 EngNest 已经装好的 Nginx 和 Let's Encrypt 证书（`/etc/nginx/ssl/engnest.*`，给 IP 签的证书哪个端口都能用，续期由 `engnest-cert.timer` 负责）。

## 1. 在自己电脑上打包

```bash
python tools/deploy/pack.py build/deploy
```

打出四个包（说明见 `pack.py` 开头）：

| 包 | 内容 | 大小（约） |
|---|---|---|
| `app.tar.gz` | 代码、内置内容、不进仓库的购买资料整理稿、白瓷星轨的天使图 | 几十 MB |
| `library.tar.gz` | 题库、资料库文档、时政、全文索引、插图 | 1 GB |
| `materials.tar` | 只有题目截图要用的真题卷 PDF（全部资料 30 多 GB 不传） | 1.3 GB |
| `userdata.tar.gz` | 学习记录 `app.db`、职位库 | 很小 |

其他考试（软考等）的东西也在这几个包里：整理结果在 `library.tar.gz` 的 `exams/<考试 id>/library/`，
真题原文件在 `materials.tar` 的 `exams/<考试 id>/`，学习记录在 `userdata.tar.gz` 的 `exams/<考试 id>/app.db`。
按下面的命令解开就各归各位，服务器上切换考试和电脑上一样用侧栏顶部的切换器。

## 2. 传上去、解开

```bash
scp build/deploy/*.tar* root@<服务器 IP>:/tmp/
ssh root@<服务器 IP> "mkdir -p /opt/gongkao/app /opt/gongkao/data /opt/gongkao/materials \
  && tar xzf /tmp/app.tar.gz -C /opt/gongkao/app \
  && tar xzf /tmp/library.tar.gz -C /opt/gongkao/data \
  && tar xf /tmp/materials.tar -C /opt/gongkao/materials \
  && tar xzf /tmp/userdata.tar.gz -C /opt/gongkao/data \
  && rm /tmp/app.tar.gz /tmp/library.tar.gz /tmp/materials.tar /tmp/userdata.tar.gz"
```

## 3. 初始化（一次）

```bash
ssh root@<服务器 IP> "bash /opt/gongkao/app/tools/deploy/setup.sh <服务器 IP>"
```

装 Python 环境、建系统用户 `gongkao`（不用 root 运行）、systemd 服务（开机自启、崩溃自动重启）、Nginx 站点（默认 443 端口，地址栏不用写端口）。
腾讯云控制台 → 轻量服务器 → 防火墙，确认放通了 TCP 443。

## 4. 设置登录密码

```bash
ssh -t root@<服务器 IP> "sudo -u gongkao env GONGKAO_DATA_DIR=/opt/gongkao/data /opt/gongkao/venv/bin/python /opt/gongkao/app/main.py --set-password"
```

然后手机浏览器打开 `https://<服务器 IP>/`，输入密码。iPhone 上可以「分享 → 添加到主屏幕」。

## 日常

| 做什么 | 命令 |
|---|---|
| 看运行状态 | `systemctl status gongkao` |
| 看日志 | `journalctl -u gongkao -f`，详细的在 `/opt/gongkao/data/logs/app.log` |
| 更新代码 | `pack.py build/deploy code` → 传 `app.tar.gz` 解到 `/opt/gongkao/app` → 再跑一次 `setup.sh`（会重启服务） |
| 更新资料（电脑上重新整理过） | `pack.py build/deploy library materials` → 解开 → `chown -R gongkao:gongkao /opt/gongkao/data && systemctl restart gongkao` |
| 改密码 | 第 4 步的命令；改完所有设备都要重新登录 |
| 备份 | 每天自动备份学习记录到 `/opt/gongkao/data/backups`；整个 `/opt/gongkao/data` 打包下载就是完整备份 |

**不要随手再传 `userdata`**：它会用电脑上的学习记录覆盖服务器上的（服务器上做过的题、打过的卡就没了）。

## 安全

- 每个请求（包括页面、题目、资料）都要先登录；密码只存加盐的 scrypt 哈希；登录 Cookie 是 HttpOnly + Secure + SameSite=Strict，180 天。
- 同一个 IP 10 分钟内输错 5 次锁 10 分钟。设置页可以「退出所有设备」（换掉登录凭证）。
- 改数据位置、恢复备份、导入、整理资料、导出等管理类接口在服务器上一律不能用（和局域网手机一样，见 `lan.DENY_PREFIXES`）。
- 程序以 `gongkao` 用户运行，只能写 `/opt/gongkao/data`；购买的资料和题目只有 `gongkao` 用户能读。
- 电脑上的 AI Key 是用 Windows DPAPI 加密的，服务器上解不开；要用 AI 讲题，在网页的「设置 → AI 助教」里重新填。
